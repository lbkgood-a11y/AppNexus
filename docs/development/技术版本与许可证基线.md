# 技术版本与许可证基线

核对日期：2026-11-19。本页记录仓库采用的版本来源及变更要求，不将上游最新发布版或历史候选方案作为升级指令。

## 当前版本来源

| 层次 | 当前基线 | 权威来源与约束 |
|---|---|---|
| Java / Maven | Java 21；Maven 3.9.x | `backend/pom.xml` 的 Enforcer 分别限制为 `[21,22)`、`[3.9,4)`；发行版和镜像摘要由实际构建环境固定。 |
| Spring Boot | 4.1.2 | `backend/pom.xml` 父 POM；可管理依赖跟随其 BOM，不单独覆盖以追新。 |
| 后端显式依赖 | MyBatis Spring Boot 4.1.0、JSqlParser 5.4、Bouncy Castle 1.86、Testcontainers 2.0.5 | `backend/pom.xml` 的 properties；其他模块依赖以各 POM 为准。 |
| Spring Cloud | 未纳入当前根 POM 的 BOM | 不再将历史候选 2025.1.4 当作已引入依赖；需要时另行验证兼容性及实际用途。 |
| 前端模板 | 当前仓库保留的 vue-pure-admin 基线 | UI 与交互执行[前端规范](前端UI与代码生成规范.md)，依赖精确解析版本见 `frontend/pnpm-lock.yaml`，不套用上游 main 的声明。 |
| Node.js | CI 使用 24；workspace 允许 `>=24 <27` | `.github/workflows/verify.yml` 与 `frontend/package.json`；开发环境满足 engines，复现 CI 时使用相同大版。 |
| pnpm | 11.25.0 | `frontend/package.json` 的 packageManager；使用 Corepack 和提交的锁文件。 |
| Vue 技术组 | 各 workspace 的 package.json 与统一锁文件 | 如 admin 声明 Vue `^3.5.31`、Pinia `^3.0.4`、Vue Router `^5.0.4`、Element Plus `^2.13.6`；范围不代表实际安装版本。 |
| MySQL | `mysql:8.4` | 根 `compose.yaml`；当前标签未固定补丁或镜像摘要，不能据此声称生产构建已完全可重现。 |
| Valkey | `valkey/valkey:8-alpine` | 根 `compose.yaml`；实际命令集须验证 Spring Data Redis/Lettuce 兼容性，发布时锁定镜像摘要。 |

上述路径均相对仓库根目录。版本表用于定位当前来源；变更依赖时必须同步核对 POM、workspace 清单、锁文件、CI 和部署配置，避免表格与工程脱节。

## 依赖变更与验证

- 采用受维护的稳定版；通过锁文件、BOM 和发布镜像摘要保证可重现，不在生产构建中浮动安装。
- 新增或升级前核对维护状态、安全公告、运行时要求和上下游兼容性；没有实际核查证据不得写成“官方最新”或“安全扫描通过”。
- 后端验证受影响模块编译、装配、真实数据库迁移和安全路径；前端验证锁文件安装、类型检查、构建及受影响交互。具体门禁执行[交付检查](开发流程与交付检查.md)。
- 数据库及缓存变更须验证命令兼容、持久化、过期、恢复与会话撤销等实际使用能力，不以协议兼容宣传代替验证。
- 不恢复项目启动前的“建立最小工程”“是否采用 Boot 4”等待决项；新技术调整必须基于当前实现说明影响与迁移方案。
