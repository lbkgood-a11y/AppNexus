# 开发规范

生效日期：2026-11-19。适用范围：整个仓库的人工开发、AI 生成、修改、重构与代码审查。

本目录是开发约束的统一入口，由根目录 `AGENTS.md` 强制引用。开始工作前必须先阅读本页，再阅读本次任务适用的规范。违反适用的强制要求不得标记为完成交付。

本目录的架构说明细化既有后端标准，不改变其固定结构、依赖矩阵及验收要求。专项要求须同时满足；发现矛盾时先核对适用范围，在实现前明确并同步修正规范，禁止自行选择较宽松的条款绕过约束。用户对当前任务的明确指令按指令优先级执行，任务例外不得被默认为全仓新规范。

摘要用于按任务检索，不能代替专项正文。规范正文只保留当前有效要求与明确的能力边界；已被覆盖的条款、候选选型和当轮测试/部署日志移出正文。历史记录仅用于追溯，不能作为当前规则或验收结果。技术实际版本以当前锁文件、POM、CI 和部署配置为准，不将“最新规范”解释为自动升级到上游最新版本。

前端页面必须执行[全局布局规则强制继承](前端UI与代码生成规范.md#1311-全局布局规则强制继承)，包括 Token 语义、嵌入模式、公共布局覆盖边界和区块间距验收；存量差距以本轮回查记录为准，不视作已全面整改。

每次前端代码交付前，必须执行该节的全局布局验证清单：实际 DOM 宿主与布局属性透传、边框/圆角/边距计算样式、全局间距动态继承及多视口主题验证，并按交付门禁 C07 留证；静态检查与构建不能替代。

无专项要求的业务详情执行[详情与普通维护表单](前端UI与代码生成规范.md#133-详情与普通维护表单)，以客商管理详情为全局布局基线，已接通的变更记录从页头右上角按需打开。

标准左树同时执行[左树样式与默认布局](前端UI与代码生成规范.md#1321-左树样式与默认布局强制)：默认220px、收起48px，节点及响应式由公共模板维护。

对象通用能力的数据范围及字段执行同时遵守[对象通用能力执行](业务对象数据权限声明标准.md#对象通用能力执行)，任务准入不解除字段强制限制。

## 维护要求

所有接入业务对象必须唯一声明并在真实代码接入统一权限体系；遗漏声明、遗漏执行、绕过执行分别检查并作为交付阻断项，执行[统一权限模型强制接入](业务服务统一开发规范.md#31-统一权限模型强制接入)及[功能交付门禁](功能交付门禁要求.md)。对象默认范围与操作覆盖的目标模型、现有重复配置及自动检查覆盖边界见[授权配置与权限接入门禁梳理](../design/授权配置与权限接入门禁梳理.md)；该记录不代表页面或自动门禁已完成改造。

通用能力接入同时执行[业务服务职责](业务服务统一开发规范.md#2-服务职责)：业务对象契约、关联配置及专业能力配置保持唯一来源，对象运行通过同一 Provider 接入公共执行器，不新增逐对象专业能力接线。

数据权限组合授权（规则内AND、规则间OR）、公共行范围执行边界与已支持范围见[业务对象数据权限声明标准](业务对象数据权限声明标准.md)第 3 节；公共执行接口不能替代业务接入及可信租户条件。

- 新增开发约束在本目录建立专页，或更新已有专项正文，并在本入口登记适用范围和链接。
- 规则变更同步更新受影响的规范、入口和自动检查；历史设计与实施记录只说明当时状态，不能作为违反当前规范的依据。
- 测试只能证明其实际覆盖范围。尚未自动检查的要求仍需人工审查，不得描述为已获得全量自动保证。

## 本次整理与后续维护

2026-11-19 清理：技术基线改为仓库实际声明；前端合并表格引擎、主题、间距、详情列数和标签的最终规则；异常方案对齐已有公开接口与显式身份去重；数据权限的测试/部署过程移至历史记录。历史文件入口见各专项正文。

修改规范时删除被替代的正文，不持续追加互相覆盖的版本段落；规则、实施差距和历史验收分别表述。涉及参数时同步检查实现默认值；涉及命令时核对当前构建与 CI。不得为消除文档差距而降低安全或交付门槛。

本次实际检查、结果及未验证范围见[开发规范清理检查](../validation/开发规范清理检查.md)。

全局数据访问及未登记 Controller 的复查可运行 `node scripts/audit-data-access.mjs`，生成[数据访问与入口清单](../validation/全局数据权限与MyBatis迁移清单.json)。该脚本只枚举线索，不验证授权或宣告通过；必须继续按[检查记录](../validation/全局数据权限与MyBatis迁移检查.md)追踪真实调用链与正反向证据。

全仓MyBatis迁移的中立SQL范围元数据、业务固定Mapper及平台执行器归属见[迁移边界](../design/MyBatis全仓迁移边界.md)；业务模块不能为使用范围注解而正式依赖平台持久化实现，业务权限仍执行原专项标准。

对象交互的公共能力必须可被实际公共命令协议表达；仅专用API操作允许空capabilities，但对象/操作与统一准入不得省略。公共执行在记录读取及关联解析前拒绝此类操作，执行[完整声明规范](业务对象完整声明规范.md)；空能力不表示业务接口免授权。
