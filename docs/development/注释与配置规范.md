# 注释与配置规范

适用于前后端、脚本、数据库及部署配置。本页集中归纳[根目录 AGENTS.md](../../AGENTS.md)的现有强制要求，不降低其要求；后续变更必须同步两处。

## 代码与参数

- Java 使用 Javadoc，TypeScript 使用 TSDoc/JSDoc，PowerShell 使用帮助注释，SQL、YAML、Properties 使用原生注释语法。
- 模块、公开类型、公开接口及具有业务或技术约束的方法说明职责、边界、调用约定；参数、返回、异常、事务、并发和副作用按实际使用标准标签。
- 重要参数用中文说明含义、单位、范围、默认或缺省行为、环境限制及修改影响；标识符和标准协议保留原文。
- 安全、认证、授权、租户、幂等、缓存、并发和故障处理解释设计原因与约束，不逐行翻译代码。
- 注释与实现同步，禁止以注释代替实现或将待实现能力写成已实现；简单明确的局部操作无需重复说明。

## 系统配置

- 新增或修改配置项均有相邻中文说明，覆盖用途、单位、默认值；无默认值或必填时明确标注，记录环境、安全、联动及生效条件。
- 覆盖环境变量、端口、URL、数据库、缓存、会话、安全、密钥、迁移、限流和部署参数。
- 严格 JSON 等不支持注释的格式，在同目录或设计文档提供中文参数说明表，并在对应入口注明位置，禁止破坏格式。
- 密码、Token、私钥等敏感值不出现在注释、示例和日志中；使用环境变量引用或明确占位符，说明来源及使用约束。
- 第三方上游和框架原始生成文件可保留原注释，本地修改部分仍遵守规范；生成产物不手工维护。

## 交付检查

检查中文文档注释、重要参数、包说明及配置说明与真实行为一致，说明变更不能意外改变配置值或程序语义。缺少必要注释的新增或修改代码不视为完成交付。
