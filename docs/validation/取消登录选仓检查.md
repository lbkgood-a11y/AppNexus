# 取消登录选仓检查

日期：2026-11-26。管理端 `TenantSwitch/index.vue` 移除全局选仓组件装配。原组件在租户上下文变化、窗口聚焦及人员身份切换时读取选仓接口，并在已有候选且尚未选仓时弹出对话框。取消装配后，这些事件不再通过应用壳触发选仓。仓库、库区及库位业务页面继续使用各自的仓库选择。
