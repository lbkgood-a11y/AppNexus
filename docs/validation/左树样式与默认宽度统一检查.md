# 左树样式与默认宽度统一检查

日期2026-11-20；版本为当前工作区差异，保留其他既有改动。范围：标准业务左树，不改应用壳侧导航和专业画布。

## 排查与修改

检索 frontend/modules 下自有 Vue 的 tree-width/treeWidth/app-category-width、树头/节点/折叠 deep 覆盖（排除 node_modules），核对公共 templates.css 与 TreeListTemplate.vue，以及 admin 全局变量。

| 对象 | 问题及证据 | 处理 |
|---|---|---|
| 库区库位 StorageManagement.vue | 显式tree-width=260，与全局220不同 | 删除显式宽度，继承全局Token |
| 菜单 MenuManagement.vue | 树头52px、8/12padding，折叠按钮被业务CSS改为32px并加边框；节点单独维护主题 | 删除树头/折叠/节点视觉覆盖；新增业务按钮样式保留，它不是公共折叠按钮 |
| 组织 Management.vue | 复制树头、树内容padding及节点样式 | 删除重复视觉规则，统一公共节点主题 |
| 公共 templates.css | 树头/树内容在前后重复定义，普通el-tree无统一密度和选中态 | 合并基本密度，新增公共节点36px/13px、主题选中与hover、键盘焦点、粗指针44px |
| 字典 DictionaryManagement.vue | tree容器flex是检索/分页传高用途 | 保留结构，不定义另一套宽度/节点视觉 |
| 授权 AuthorizationCenter.vue | 多行角色说明需要自然高度、48px最小高度；容器flex用于独立滚动 | 明确写入规范的业务适配；不套用普通36px单行节点 |
| 主数据 Management.vue | 长名称省略、编码次级颜色 | 保留内容适配，与公共省略一致，无宽度例外 |
| MemberGrantEditor.vue | 人员选择列表使用category-width220 | 已继承Token，属于人员目录而非层级树；不改业务交互 |

当前标准业务TreeListTemplate调用无显式tree-width。treeWidth公共能力保留220–360px受控范围，只允许记录过具体业务理由的例外。默认220px，收起48px，>760px左右分栏；手机继承公共上下堆叠，树最大280px。全局变量既有220px无需新增配置。专业打印/流程设计器内部树不纳入普通范围导航替换，不改变画布功能。

规则固化至前端UI与代码生成规范13.2.1，同步README、前端摘要和交付检查。无新增组件、库、接口或业务准入；无数据库/事务变更。
