# 客商成员默认范围与授权来源验收

日期：2026-11-27

本轮归属平台统一授权。沿用客商唯一 Provider 和已有客商操作、角色操作及成员授权管理入口。V219 在现有成员授权分支表增加可空 JSON 列，按对象主资源键记录成员默认，原每操作策略保留为覆盖。角色继承分支仍实时读取角色范围，成员自定义分支不回退到角色范围。

## D01–D12

| 项 | 实现与复核 |
|---|---|
| D01 | 客商身份、归属和原 Provider 保留。配置属于平台 authorization。 |
| D02 | 沿用客商查询、创建、修改、启停和历史，以及成员授权读取、更新、解释操作。覆盖沿原权限 ID，客商列表与历史共用读取范围。 |
| D03 | 复用授权中心成员页签、授权解释和原路由。草稿按钮仅在统一保存时产生服务端副作用。 |
| D04 | 操作准入由现有 Controller 引用，可信租户和角色由现有服务端上下文取得。成员锁与角色版本前置校验。 |
| D05 | 同一角色分支按模式取角色或成员策略，操作覆盖优先，缺少可适用默认时拒绝范围。功能权限不随对象默认增加。 |
| D06 | 使用原字段保护。成员和角色默认只影响行范围，不新增字段授权。 |
| D07 | 客商已有类型化命令，页面启停已复用平台公共执行。审批、打印、消息接线本轮无新增。 |
| D08 | 角色、成员共用对象默认契约和适用规则校验。解释只返回配置来源、范围类型和状态。 |
| D09 | 客商编码规则不变，无新增发号。 |
| D10 | 原客商服务执行共享范围计划。页面启停使用公共对象入口，原固定接口与公共命令复用同一状态、版本和历史事务。成员写入、查询及授权解释的固定 SQL 使用事务范围许可。 |
| D11 | V219 保留旧数据，成员分支版本、角色版本、策略和审计同事务。旧客户端仍须提交完整逐操作策略。 |
| D12 | 隔离数据库与边界回归验证客商真实行范围和解释，浏览器验证授权编辑及样板实际读取。结果见下。 |
