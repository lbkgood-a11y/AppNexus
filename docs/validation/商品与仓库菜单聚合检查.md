# 商品与仓库菜单聚合检查

日期：2026-11-20。版本依据：当前工作区；仅 V130 菜单迁移、MenuManagementTest 新增断言及本记录属于本次修改，保留原有未提交工作。

目标：在“主数据管理”下增加“商品资料”“仓库资料”目录。商品依次为商品管理、商品明细管理、商品分类、计量单位、属性管理、属性模板；仓库依次为仓库管理、库区与库位。

归属：configuration 导航配置；公开入口沿用 NavigationQuery / `/bff/navigation`；由平台 persistence 维护 platform_menu。无新 Java 包、业务对象、操作、页面或依赖。迁移只调整既有内置租户菜单的父节点、排序、版本和修改审计，不修改路由、组件、权限、启停、显隐、创建审计或资源关联。新增目录不授予权限；统一导航查询按叶子资格裁剪空目录。系统迁移账号为 NULL，数据库生成 UTC 时间。
