# 收货整体流程与页面可操作性验收

本轮检查仓储收货从通知、到场、入库单草稿、采集与提交到库存入账的主要路径。后端能处理和现场页面能完成是两项验收，分别判定。

| 业务要求 | 已有证据 | 整体判定 |
|---|---|---|
| 通知和多车次 | 已验证通知签发、同一通知登记多车次、重复请求防重和模板自动关联。见《入仓通知车次登记验收》。 | 集成通过，真实租户依赖已发布模板。 |
| 工作台开单及分岗 | 已验证按待开单过滤、开草稿、进入原单、分岗读写及盲检字段隔离。见《入库单先开单后过账验收》。 | 集成通过。 |
| 玉米地磅、监卸和扣量 | 已验证毛皮差重、质检与监卸强阻塞、退车、扣量快照和正式库存量。见《入库质检公式扣重验收》。本轮重点检查页面在待质检时先过毛，以及过毛后继续登记采样。 | 服务端流程通过，页面证据见下。实际收货仍需正式模板。 |
| 煤炭暂估与异步化验 | 已验证采样、外部计量、待化验过账、合格放行和不合格冻结，不回退结束车次。 | 集成通过。 |
| 钢铁双计量、MTC 与多 LPN | 已验证核验附件归属、件数、实重或理计、磅差及多行分摊过账。浏览器提交过三卷结构化明细，并从同一车次选择质保书和外观照片实际核验。 | 逐卷录入与附件选择通过，真实摄像设备仍待联调。 |
| 磅票采集操作 | 共用现有磅票字段和 Element Plus 日期选择，将独立计量及入库单内钢铁双计量的 JSON 输入改为结构化字段。实重需要双票，理计隐藏实重票。日期转成 UTC，十进制按原 API 文本传送。 | 页面证据见下。 |
| 明细与计量引用 | 入库单能带入作业号和受控版本。通知行、库区和库位可在授权范围内选择，自动取得仓库及单位引用。 | 浏览器实测 1,250 kg 散货按 0.001 换算，数据库确认 1.2500 吨入账。 |
| 质检指标填写 | 后端从固定模板验证指标及范围。浏览器按模板字段提交了实际化验值。 | 通过。录入提示不返回合格阈值。 |
| 附件扫描 | 本机已接通 ClamAV，隔离浏览器验证 PDF 和 PNG 上传、扫描通过、拒绝及超时路径。 | 本机扫描通过。详见《收货附件扫描与现场设备联调验收》。 |
| 现场设备读数与抓拍 | 模拟源验证实时刷新、稳定状态、过期及盲检抓拍保护。 | 隔离通过。真实地磅及摄像头仍待现场联调。 |
| 现场指令和回执 | 浏览器实测按权限执行抬杆、叫号、打印，核对同车次回执、超时重试和跨车次拒绝。模拟打印实际生成带作业号的测试 PDF。 | 隔离通过。主服务真实指令通道保持关闭，执行器和打印机仍待联调。详见《收货现场设备指令与回执验收》。 |
| 模板管理 | 浏览器保存并发布散货模板，已签发通知登记车次时自动匹配该版本。 | 配置与发布入口通过。本机共享库仍需正式业务模板。 |

**结论：收货主链和现场设备模拟链路均已验证。** 真实设备联调和正式业务配置仍待完成。`v001` 继续等待正式参数。

## 本轮门禁

| 门禁 | 适用性与证据 |
|---|---|
| G01/G02、D01/D02 | 复用原入库单、磅单和质检单，没有新增业务、目录或模块。 |
| G03/G05、C01–C03、D03–D06 | 原独立 API 和统一操作决定继续控制可见性及提交。入库单读接口仅补计量和质检策略代码，不返回新增物流信息。 |
| G04、C05、D11 | 允许配置支持的到场作业先称毛重，页面不自行判定质量放行。版本、重量、时间、监卸及库存事务仍由后台检查。 |
| G06/G08/D12、C07 | 实际构建、业务和浏览器证据见下。 |
| G07/D08、C09 | 磅票字段、重量精度、原请求结构保留。模板键只用于控制页面的候选操作。 |
| G09、D07/D09/D10，C04/C08/C10 | 同一 Provider 及运行端口负责命令，未变更编码、流程、事件、迁移或 Java 包。 |
| C06 | 履行原有授权详情查询，沿用单据、作业及模板复合主键关联。 |

## 本轮运行证据

- 前端类型检查与构建通过。窄屏表单使用公共日期选择器和十进制输入。复用组合字段用于保证独立单据和入库单内相同的票据约束。
- 隔离库的真实浏览器从工作台进入入库单，待质检时登记毛重。空磅票提示必填且无计量写入。录入站点、票号、时间和 150.1234 kg 后成功提交，HTTP 实际提交保留四位精度并转换为 UTC。毛重提交后仍可登记采样。
- 同一浏览器验证了独立钢铁计量的实重票与理计切换。实重展示结构化毛皮两票，理计隐藏两票。验证三个视口及 0、8、24 px 区块间距继承，均无横向溢出。浅色、深色、跟随系统及中英文切换通过。
- 仓储完整集成及上述浏览器验证共 1 个测试用例通过，零失败、错误或跳过。证据见 `.local/receiving-usability-acceptance.log` 和 `.local/receiving-usability-gross.png`。
- 普通、无效日期、零重量、负重量、超四位小数、科学计数法和长度溢出均按预期通过或拒绝。页面改造没有写入共享业务库的测试单据。
- 本机已加载最终服务和前端构建，首页返回 200，后台与前端代理的匿名单据请求按预期返回 401。共享业务库验收前已发布模板、车次和入库单均为 0。
