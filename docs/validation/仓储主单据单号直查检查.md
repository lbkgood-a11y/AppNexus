# 仓储主单据单号直查检查

日期：2026-11-22。沿用现有仓储读取权限，补充按各主表业务 UUID（现有单据编号）的直接查询。使用固定 SQL 和可信租户联合键，关联从主单据正向读取。

## 范围与声明变更

| 对象 | 新专用读取操作 | 沿用准入及范围 |
|---|---|---|
| BulkWarehouseStockBalance | read_document。入仓通知、实收、确权、放行、过户、出仓通知、车次、实发及冲销 | 原库存追溯和租户 ALL 计划。按原主数据引用检验仓、货主、商品及相关主体。 |
| BulkStockRestriction | read_document。按冻结编号查原凭证及解除 | 原监管读取，通过原实收验证当前库存范围。 |
| BulkCoilOutbound | read_authorization_document、read_return_document。返仓发运复用 read_return_transit | 原余额和返仓读取。验证授权范围、返仓原出仓链与实际接收仓。 |

13 类主单按已有业务 UUID 精确查询。确权和放行使用实收主键。收货批次号可重复引用，保留原语义。通知及车次查询无需实收或配货关联。入仓通知正向读取接管、实收，车次正向读取配货、复磅。两类关联表最多返回首批 100 条，超出提示。返仓发运保留原逐卷历史，返仓确认可进入对应发运。
