# 单据通用能力验收清单

本清单为可重复的人工验收资源约定，不包含凭据，不自动创建人员、授权或生产业务数据。所有变更使用正式页面，所有用例使用单独前缀与独立单据，不办理其他人的历史任务。

## 前置资源

| 资源 | 必备内容 | 权威验证入口 |
| --- | --- | --- |
| 测试租户 | 已启用、单据获平台授权 | 平台单据管理与租户目录 |
| 管理员/申请人/主管/人事 | 分别保存角色及成员独立授权；禁止自审 | 授权中心有效权限解释 |
| 组织 | 申请人有效任职、主管有效负责人 | 组织管理及申请单组织选择器 |
| 单据契约 | 页面、行为、权限、API 一致 | 构建一致性测试、平台页面关联 |
| 行为策略 | 发布的 submit/print 策略，唯一匹配 | 工作台接入就绪检查 |
| 打印 | 兼容模板/场景，代理绑定同一租户 | 打印场景、代理身份自查、在线队列 |
| 设备 | 用户指定已授权启用队列 | 打印设备及预览设备选择 |

账号来源仅引用 Git 忽略的本机凭据文档，日志与截图禁止包含密码、Token、Secret。首次批准的授权变更不扩大到其他成员；不为测试关闭业务限制。

## 用例矩阵

1. 无绑定：草稿提交明确拒绝、业务状态不变；发布合法绑定后再用新请求提交。
2. 三天：主管同意后不生成 HR 待办，业务结果通过可靠交付回写。
3. 四天：主管同意后出现 HR，HR 同意后业务批准；确认实例和依据版本关联。
4. 驳回重提：任一审批人驳回，申请人修改；日期仍为原自然日，依据版本递增，创建新轮次并保留历史。
5. 撤回：申请人按规则撤回、结果回写后修改重提；旧任务原文权限失效。
6. 重复点击：同请求键不重复实例或输出，同键异内容拒绝；人工新打印与技术重试分开。
7. 授权：角色上限有权限而成员无授权时明确显示原因；新增或撤销成员授权后下一次操作重新判断。
8. 页面关联：移除列表打印、保留详情别名；列表不执行，详情保持合法；历史审批回调继续。
9. 断线恢复：客户端停止后就绪检查显示 LIVE 离线、任务保持真实状态；恢复同租户客户端后正常领取。
10. PDF 与实体：预览真实数据和正确日期；确认一次仅生成一个实体任务，已提交设备不等同物理出纸。
11. 权限/租户负例：其他账号不能查询单据可执行性、时间线或供数；其他租户客户端不能领取任务。
12. 布局：1440px、390px、深浅/系统主题、中英文；表格内部滚动、关闭及确认按钮可达。

自动回归入口：DocumentIntegrationTest、LeavePocTest、IntegrationClientTest、PrintingRuntimeTest、DocumentPageRegistrationTest、sidebarLocation.test、outputStage.test。人工结果须记录用例、真实资源标识和证据，不能用脚本直接改业务状态代替步骤。
