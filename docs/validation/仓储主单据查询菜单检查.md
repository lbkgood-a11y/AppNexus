# 仓储主单据查询菜单检查

日期：2026-11-22。基于当前工作区及既有 V163–V165 迁移。

在仓储管理下按入仓管理、货权与监管、出仓管理、返仓管理设置只读入口。独立入口复用已有追溯、库存监管、授权余额和返仓在途接口。现有作业工作区继续用于实际操作。

## 菜单与执行对应

| 分组 | 独立查询菜单 | 唯一 Provider 与操作 | 查询条件 |
|---|---|---|---|
| 入仓管理 | 入仓通知单、入仓确认单、入仓货权登记、入仓质量放行 | WarehouseStockBalanceDeclaration / BulkWarehouseStockBalance.trace | 实收库存 UUID，接管和计量引用随入仓查询展示 |
| 货权与监管 | 货权过户单、库存监管单 | WarehouseStockBalanceDeclaration / BulkWarehouseStockBalance.trace；OutboundStockDeclaration / BulkStockRestriction.read | 实收库存 UUID，监管查询保留冻结及解除凭证 |
| 出仓管理 | 出仓通知单、提货授权单、车次作业单、出仓确认单、出仓交接冲销单 | WarehouseStockBalanceDeclaration / BulkWarehouseStockBalance.trace；CoilOutboundDeclaration / BulkCoilOutbound.read_authorization_balances | 实收库存 UUID；提货授权按货主、仓库、商品及可选品规分页 |
| 返仓管理 | 返仓发运单、返仓确认单 | CoilOutboundDeclaration / BulkCoilOutbound.read_return_transit | 发运 UUID，逐卷清单和原关联历史包含改仓、短损、接管等事实 |

仓储模块保有数据、事务和已授权查询。平台模块登记固定页面及租户导航，前端通过宿主会话调用原 GET 接口。迁移只写平台菜单，保留旧工作区及菜单。作业相关记录沿原卷、授权和发运关联查看。基于实收库存追溯的页面仅覆盖已形成关联的记录，发运查询仅覆盖关联在途清单的返仓确认。未实收通知、未配货出仓通知或车次、单号直查以及脱离发运单的历史退回需要业务专用查询能力。
