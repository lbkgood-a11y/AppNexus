# v001 正式模板与现场接入核查

本机 `v001` 为已签发的饲用黄玉米通知，商品编码 `CORN`。关联合同号为空，通知和明细没有可确认的质检区间或扣重参数。模板表为空，当前租户没有可匹配的玉米、质检或扣重参数记录。仓库中的流程设计要求采用发布版本，历史验收数值仅用于隔离环境。

正式发布仍缺业务批准的指标代码、单位、有效与合格区间、扣水及扣杂基准和系数。正式实测还缺本车的实物化验、真实磅票和监卸凭证。核查未向 `v001` 写入模板、车次、计量或库存。

## 隔离浏览器验收

使用测试商品、通知、模板和单位换算执行玉米策略。该场景中的参数及实测值不得用于 `v001`。

- 浏览器发布测试模板，从已签发通知登记车次并开草稿，实测手工录入毛重、监卸确认、采样和化验、录入皮重、扣重和提交过账。
- 测试票据毛重 1,330 kg、皮重 30 kg、净重 1,300 kg。扣水 19.50 kg、扣杂 13.00 kg、现场扣重 17.50 kg，合计 50.00 kg。原单入账重 1,250 kg，数据库确认库存数量 1.2500 测试吨。
- 仓储回归含本次浏览器用例通过，零失败、错误与跳过。见 `.local/receiving-corn-isolated.log` 和 `.local/receiving-corn-isolated-result.png`。
