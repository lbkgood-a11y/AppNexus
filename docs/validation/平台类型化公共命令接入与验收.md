# 平台类型化公共命令接入与验收

公共平台入口为 `POST /bff/platform/business-object-executions`。它从安全链取得真实平台账号，复核目标操作原有平台权限和已登记入口关系，并按固定类型解码。平台认证上下文的 tenantId 必须为空。命令中的 targetTenantId 仅用于代管目标约束，原管理用例继续复核目标成员属于该租户。

请求沿用公共命令信封。平台目录原协议未使用记录版本，basisVersion 传 0。列表和创建省略 objectId，记录写入及敏感操作传目标 UUID。每次请求提供 UUID 格式的 Idempotency-Key；重试约束沿用原用例。示例为账号列表。

```json
{
  "objectType": "Account",
  "operationCode": "list",
  "operationId": "Account.list",
  "basisVersion": 0,
  "command": {"page": 1, "size": 20}
}
```

| 对象操作 | 原权限 | 原用例 |
|---|---|---|
| Account.list | identity.account:read | PlatformAdministration.users |
| Account.create | identity.account:create | PlatformAdministration.createUser，沿用原密码校验和编码 |
| Account.update | identity.account:update | PlatformAdministration.updateUser |
| Account.setEnabled | identity.account:enable | PlatformAdministration.setUserEnabled |
| Account.revokeSessions | identity.account:revoke_sessions | 近期 MFA 后 PlatformAdministration.revokeUserSessions |
| Account.issueRecovery | identity.account:reset_password | 近期 MFA 后 PasswordRecovery.issue |
| TenantMember.listManaged | tenant.member:read | PlatformAdministration.members |
| TenantMember.createManaged | tenant.member:create | PlatformAdministration.addMember |
| TenantMember.setEnabledManaged | tenant.member:enable | PlatformAdministration.setMemberEnabled |
| TenantMember.removeManaged | tenant.member:remove | PlatformAdministration.removeMember |

两条敏感命令和原专用 API 共用 MfaController.requireRecent。沿用既有第二因子启用条件、平台全局 MFA 策略和服务端 300 秒窗口。命令未授权、错安全域、未声明、缺端口或输入不匹配时拒绝。平台入口保留原 CSRF 安全链，响应禁止缓存。未新增业务权限，公共分发本身登记为业务对象的技术入口，真实权限取自动作。
