# 人员打印单据与任务目录公共命令验收

三个操作复用 `POST /api/business-object-executions` 的类型化协议。请求使用当前可信租户会话，`basisVersion` 为 0，`Idempotency-Key` 按公共入口提交 UUID。这三个操作没有目标记录键，`objectId` 留空。

| 操作和 operationId | command | 权限及数据范围 | 原用例 |
|---|---|---|---|
| PrintDocument.list | 空对象 | print.job:submit，当前租户且 created_by 为当前账号 | PrintSceneService.documents |
| PrintDocument.create | 原 DocumentRequest，sceneId、number、data | print.job:submit，场景限当前租户，保存主体由服务器决定 | PrintSceneService.saveDocument |
| PrintJob.list | 空对象 | print.job:read，当前租户任务 | PrintRuntimeService.jobs |

公共查询不接收身份、租户或任意过滤参数。单据创建使用原启用场景及原数据契约校验，在同一原事务生成单据并返回本人列表。重复单据号继续由原唯一约束拒绝。公共两种列表仅查询，不写单据、输出、任务或公共关联解析。原专用 HTTP 路由和用例保持，包括 `GET/POST /api/printing/documents` 与 `GET /api/printing/jobs`。缺命令登记或运行端口失败关闭。
