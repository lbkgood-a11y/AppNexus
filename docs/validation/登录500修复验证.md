# 登录500修复验证

日期：2026-11-21（Asia/Shanghai）。基准 f907874 的既有脏工作区，仅本次安全适配器差异纳入验收，其他未提交工作保持。

故障：本地后端63980因原生内存不足退出，前端代理无可用后端；退出前OAuth标准授权保存报`Column metadata not found for column 'attributes'`。独立调用框架OAuth2AuthorizationParametersMapper/RowMapper需要JdbcOAuth2AuthorizationService构造时填充的静态列元数据，MyBatis迁移后没有该初始化。

修复：MyBatisAuthorizations使用包内OAuthAuthorizationCodec，保留Spring Security 7.1.2标准33列、JSON安全模块及类型白名单，固定Mapper、表结构、轮换锁及外层事务不变。编解码基于Apache-2.0上游字段映射改编，源码保留版权、许可和修改说明。没有反射修改框架静态变量或初始化隐藏JDBC服务。本机启动脚本堆初始128MiB、最大512MiB、处理器数4，给数据库和原生内存留出空间；不是长期容量验证。
