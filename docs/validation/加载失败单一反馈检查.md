隔离 Spring Boot 与容器数据库验收补证。计量单位、人员列表以及客商、仓库、人员和商品详情的拦截 503 均只有一个内容区结果、零浮层；取消故障后重试命中真实 API 200。计量单位已有“瓶”记录时刷新失败，记录继续显示，只有一个顶部浮层。属性模板注入 403 时显示一条内容区提示，无浮层、无重试按钮。英文界面显示 “Service is temporarily unavailable. Please try again later.” 及 “Reload”，无浮层。

国别地区和行政区划首轮浏览器验收各收到同一资源的两条 503，并显示一条浮层加一条内容区结果。将首次挂载顺序收敛进公共左树模板的 treeReady 属性，分类及两类地理列表在有读权限且首次列表成功后启用树。独立树默认立即挂载。ProductCategory、CountryRegion、AdministrativeSubdivision 的运行入口与操作不变，后续查询、权限、结果及版本契约沿用原实现；无需对象声明或迁移变更。
