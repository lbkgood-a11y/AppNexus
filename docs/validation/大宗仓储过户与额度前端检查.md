## 浏览器业务结果

在 Chromium 实际访问 /#/warehousing/coil-title，使用隔离 MySQL 及真实认证与 CSRF。选货主甲、验收仓、热卷和 TITLE-SKU。过户前甲在库 **69,000 kg**、可提 **51,000 kg**，单据上限／占用／已出／剩余为 **100,000／7,000／0／93,000 kg**。冻结卷及占用卷显示对应标签，逐卷过户按钮禁用。可用卷提交同仓不动货过户给乙后，甲在库 **18,000 kg**、可提 **0 kg**，单据余额不变。乙查询到同一卷及 **51,000 kg** 在库、**51,000 kg** 可提。向两个真实余额 API 查询另一租户仓库均收到 403，库存响应无数据，缺少功能权限的账号直接进入页面被导向无权限页，调用查询也为 403。

## C07 浏览器布局记录

- 实际路由中的唯一内容宿主为 management-page main-content。无 Vue 属性透传警告或页面运行异常。对照仓库管理页面，两个宿主的外边距均为 8 px，取全局 --app-page-gap。
- 仓储工作区外框实测 1 px、圆角 8 px。数据区 padding 为 8 px，跟随 --app-content-padding。嵌入表面边框 0 px。全屏使用公共表格弹层，独立表面边框 1 px，验证进入和退出。
- 通过模板系统配置分别设定区块间距 0／8／24 px。在 1440×900、1024×768、390×844 三个视口共九次采样，堆叠 gap 同步变化，外边距及数据区 padding 始终 8 px。
- 在三个视口分别验证浅色、深色和自动模式。自动模式模拟系统深色并生效。视口及侧栏动画结束后实际文档均无横向溢出，钢卷行可滚动到达。无树导航，树展开和收起不适用。
- 布局证据来自浏览器 DOM 和 getComputedStyle。金额和业务结果则来自真实认证浏览器场景，未使用 mock。

## 执行方式

验证从排除原 target 的隔离后端副本执行。使用 Java 21、Maven 3.9.15、MySQL 8.4、Valkey、Node 26.13.0 与 Chromium 系统 Chrome。真实前端构建经本地代理提供，同源转发 /api 和 /bff。临时会话固定在独立租户，验收结束后回收。前端使用工作区已安装版本的命令执行：

```sh
node frontend/scripts/check-operation-bindings.mjs
cd frontend/apps/admin
./node_modules/.bin/vue-tsc --noEmit --skipLibCheck
./node_modules/.bin/vite build
```

操作检查通过，核对 271 个显式操作控件、399 个接口操作。类型检查及生产构建均退出 0。构建保留既有动态导入警告。页面筛选、A→B 过户、冻结与占用、跨租户库权限以及无功能权限账号的浏览器用例通过。隔离宿主使用 ProductBrowserFixtureTest#warehouseTitleBrowserHost 启动，按 product.qa.backend.port、product.qa.frontend.port 和 product.qa.dir 绑定临时端口和验收目录。

后端回归命令退出码 0，45 项全部通过。主数据 1 项、组合应用 21 项、架构 23 项，无失败、错误或跳过。菜单注册、接口准入、全表四审计列及真实在库整卷查询均在内。浏览器隔离宿主用例另 1 项通过，结束后由测试回收会话。
