# 类型化公共命令接入与验证

公共 HTTP 入口沿用 `POST /api/business-object-executions`。类型化请求包含 `objectType`、`operationCode`、`operationId`、`basisVersion`、`command`，按操作选择是否提供 `objectId`；编码写入使用原配置键。宿主认证链提供可信身份，命令内容不进入请求对象的调试输出。`Idempotency-Key` 仍要求 UUID。业务重试与唯一性由原用例处理。

客商分页请求示例

```json
{
  "objectType": "BusinessPartner",
  "operationCode": "list",
  "operationId": "BusinessPartner.list",
  "basisVersion": 0,
  "command": {"page": 1, "size": 20}
}
```

| 操作 | command 固定类型 | 原用例 |
|---|---|---|
| BusinessPartner.list | ListInput，支持列表和明细、字典、地理及权限候选视图；默认页 1、每页 20 | MasterDataManagement.list、dictionaryOptions、geographyCatalog 或 partnerAccess |
| BusinessPartner.create | MasterData.Input，objectId 缺省，basisVersion 为 0 | MasterDataManagement.create |
| BusinessPartner.update | MasterData.Input，objectId 必填，command.version 等于 basisVersion | MasterDataManagement.update |
| BusinessPartner.setStatus | MasterData.Status，objectId 必填，command.version 等于 basisVersion | MasterDataManagement.setStatus |
| BusinessPartner.readStatusHistory | HistoryInput，objectId 必填，分页缺省 1 和 20 | StatusHistoryQuery.list |
| CodingRule.list / save | 空命令 / CodingManagement.RuleInput；写入使用规则键和原 revision | CodingManagement.rules / saveRule |
| CodingEncoder.list / ruleOptions / save | 目标业务对象编码；保存同时携带原 CodingManagement.Input，objectId 为编码器键 | CodingManagement.configurations / ruleOptions / save |
| OrganizationUnit.listFlat / list / summary | 空命令，无记录键 | 原平面组织、领域组织及范围内摘要 |
| OrganizationUnit.createFlat / create | 固定名称或领域新增入参，服务端分配标识 | 原默认业务类型创建流程 / OrganizationStructure.createUnit |
| OrganizationUnit.rename / delete / inspectImpact | 组织 UUID，名称或空命令 | 原平面维护和组织影响查询 |
| OrganizationUnit.update / move | 组织 UUID，必填领域版本，与 basisVersion 一致 | OrganizationStructure.updateUnit / moveUnit |
| PersonDirectory.list | 空命令 | OrganizationStructure.persons |
| TenantMember.authorizationOptions | 空命令 | 原租户授权账号候选，先复核当前成员管理权限 |


响应在 `output.result` 返回原用例结果，更新和启停当前返回空 `output`。类型化命令无流程解析，`resolution` 为空。原记录能力的请求和返回保持兼容。专用 API 保留其展示富化和原 HTTP 响应。

对象唯一 Provider 声明操作和命令运行端口。缺端口、缺操作或端口类型表漂移由装配和调用检查拒绝。公共执行先执行真实功能准入与页面关系复核，宿主解码器按固定类型反序列化，拒绝未知字段及标量类型转换，业务用例负责真实租户、行范围、字段保护、版本和业务事务。未知字段及尝试携带租户或主体的输入不会被业务执行。未新增角色、权限码、策略存储或数据库结构。

## 此批之后的平台代管操作

平台代管后续接入及验收见[平台类型化公共命令接入与验收](平台类型化公共命令接入与验收.md)。以下为此批结束时的范围。

Account.list、create、update、setEnabled、revokeSessions、issueRecovery，及 TenantMember.listManaged、createManaged、setEnabledManaged、removeManaged。它们的原入口基于平台主体，使用独立平台权限，两个敏感账号操作还要求近期 MFA。当前公共入口绑定租户主体，平台命令需独立可信入口及真实 MFA 正反向测试。
