## API 变更决定

这是第一方后台页面使用的内部接口。当前仓库中仅入仓通知单列表消费旧参数，前后端作为同一构建版本同步替换，无并行兼容期。回退需同时恢复旧前端和旧后端。删除游标字段的动机是统一页码、跳页和授权总数。库存总览的旧协议未纳入变更。
