## 商品档案列表异常呈现

原截图对应后端缺失审计表登记引起的 HTTP 500，详见上一节。页面原来把同一次请求失败同时写入顶部浮层和列表错误态，本次给列表请求保留一个反馈入口。服务异常在原数据区显示安全文案及手动重新加载，普通 HTTP 403 或缺少列表操作时显示无权提示；MFA 文案仍沿用既有安全错误转换。HTTP 200 且无数据时保留空表，无法依据零结果推断数据权限拒绝。取消、陈旧响应和 HTTP 401 仍由既有请求、会话流程处理。分类、审批快照和暂存等独立失败沿用原反馈。统一异常规范同步允许关键列表在数据区单独承载异常。
