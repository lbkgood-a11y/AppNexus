## 场景

A/B 初配 51/49 t。车辆净载与总重分别实测单项超限。A 净重 53 t 在车辆限值内仍触发通知与提货授权超额，原 51/49 t 占用及锁保留。B 撤配 49 t 换入 47 t 后，旧装载证据拒绝，当前适用复核批准 53/47 t。另验证同仓同车第二个有货车次被拒。

A 已通过复磅后收到冻结，真实门岗 HTTP 返回 409，库存、权利、占用和交接流水保持。解除后再次提交仍复核所有条件。注入真实货权扣减失败时库存、流水及额度一并回滚。两车最终按实测核销 100 t，按 51/47 t 扣库存与货权账面 98 t，原换出的 49 t 卷可配。同键重放不重复扣减。

单仓同车按一个有货车次处理。授权岗位手动提交其核验的限载、有效计量和受控交接凭证。多授权共车、自动轴荷校验、门机联锁和交接冲销尚未接入。

## 执行记录
