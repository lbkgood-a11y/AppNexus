# 库存总览检查

2026-11-22，基线 5ac651d，本地 V164。库存总览按实收身份分页，仓库、货主和商品可选，多个条件取交集。库存为实收入账量减已出仓账面量，已全部出仓的实收不进入列表。待检按原实收单位展示，未登记有效货权时采用入仓货主。页容量 1–100，默认 20，游标为最后一条可见实收 ID。

现有货权和整卷页面承担定向查询及作业，新建库存列表页面复用 BusinessWorkspace、ManagementTable、Element Plus 及只读审计弹窗。无独立主题或布局样式。后端复用仓储余额应用及存储，只有仓储适配器读取仓储表，主档名称和可见性由主数据公开接口提供。
