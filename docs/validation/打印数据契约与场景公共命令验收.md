# 打印数据契约与场景公共命令验收

公共入口沿用 `POST /api/business-object-executions`，从现有认证链读取租户与账号。请求以原操作 ID 执行，`Idempotency-Key` 按公共入口提交 UUID。原专用 API 保留。

| 操作 | 请求 | 原权限与用例 |
|---|---|---|
| PrintDataContract.list | `command: {}`，basisVersion 0，无 objectId | PrintSceneService.contracts。沿用模板设计、模板读取、模板发布、打印提交或既有外部提交权限中任一。 |
| PrintDataContract.create | command 为 code、nameZh、nameEn、fields，basisVersion 0，无 objectId | print.template:design，PrintSceneService.createContract。沿用字段白名单、明细限额、保留编码和租户唯一性。 |
| PrintScene.list | `command: {}`，basisVersion 0，无 objectId | PrintSceneService.scenes。沿用模板读取、模板发布或打印提交任一权限。 |
| PrintScene.create | 原 SceneRequest，basisVersion 0，无 objectId | print.template:publish，PrintSceneService.saveScene。核验启用的已发布模板与场景契约匹配。 |
| PrintScene.update | 原 SceneRequest，objectId 为本租户场景 UUID，basisVersion 等于 command.revision | print.template:publish，PrintSceneService.saveScene。原记录锁、不可改编码、契约及乐观锁校验继续生效。 |

公共列表的任选权限由原用例与 Provider 共用同一权限集合，普通单权限命令和平台命令维持原判断。人员公共入口始终使用现有认证账号和租户，外部客户端仍走原独立安全入口。两条查询只返回原目录，未创建契约、场景、单据、输出或任务。声明与类型表不匹配、漏接或越权拒绝。
