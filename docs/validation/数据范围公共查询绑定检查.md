## 运行结果

- `java scripts/AccessBuildGate.java .` 退出 0，`git diff --check` 通过。
- 组合应用定向测试使用 `mvn -f backend/pom.xml -pl applications/monolith-app -am -Dtest=ScopedQueryLanguageDriverTest,BusinessPartnerDataAccessTest -Dsurefire.failIfNoSpecifiedTests=false test`。客商套件 3 项中 2 项通过，覆盖真实 MySQL 的 ALL、指定记录、漏绑和缺少写入许可。剩余旧客商闭环场景在准备授权数据时请求退役的组织权限，第一次报历史组织范围已退役，改用组织组合条件复核后仍由现行 DataGrantPolicySupport.retiredRule 拒绝，未进入该场景的后续查询。保留原测试及权限规则。套件退出 1，不能据此标记完整交付。
- 最终源码执行同一 Maven 命令并将 `-Dtest` 限定为 `ScopedQueryLanguageDriverTest`，退出 0，3 项通过。覆盖普通 Provider、动态脚本及 XML include，验证真实 MyBatis BoundSql 与参数映射。额外用 XML 探针确认共用条件的 list 和 count 均绑定。
