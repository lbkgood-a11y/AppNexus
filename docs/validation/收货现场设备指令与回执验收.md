# 收货现场设备指令与回执验收

工作台对当前到场、未结束车次提供抬杆、叫号和作业票打印。三个动作分别授权，并复核工作台详情和作业租户范围。状态查询还须有原动作权限。提交仅发出设备指令，终态以受信执行器的回执为准，车次业务版本和库存不受影响。

## 接入

私有指令目录由 `app.inbound.site.command-directory` 配置，默认空且关闭。每个受控文件位于 `<根目录>/<租户 UUID>/<作业 UUID>/`。请求文件为 `<命令 UUID>.request.json`，含 `job`、`attemptedBy`、`attemptedAt` 和 `expiresAt`。原始作业记录含租户、车次 UUID、作业号、动作、创建人及 UTC 时间。票据范围仅为作业票。

应用只支持独占目录的单写入进程。受信执行器按命令 UUID 持久去重，核对租户及车次绑定的设备，检查本地安全联锁并拒绝过期请求。完成后原子写入 `<命令 UUID>.ack.json`，填入相同 `tenantId`、`taskId`、`commandId`、`action` 及 `state`、UTC `acknowledgedAt`。终态为 SUCCEEDED 或 FAILED。结果不匹配的回执不改变指令状态。

等待回执为 8 秒。超时允许同一 UUID 重试，原动作、车次和创建信息保留，尝试时间和到期时间刷新。执行器如已实际执行，重试时应重报已持久化的回执。模拟执行器的打印产物为带作业号的测试 PDF，实际打印机和业务模板尚待现场接入。
