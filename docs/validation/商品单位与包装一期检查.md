# 商品单位与包装一期交付检查

日期：2026-11-21

结论：未满足交付门禁。

计量单位分组及通用换算归属 `ProductUnit`，商品多单位、包装规格和试算归属 `Product`。单位目录适用租户管理域，商品计量子资源继承父商品组织范围。数据库迁移保留现有单位、规格和 SKU 身份。

本次差异包含分组目录、单位筛选、同组换算检查、商品详情「单位与包装」页签、商品专属包装试算及 V133–V134。分组使用租户和原维度编码作为复合键，支持创建、重命名和筛选。V133 创建分组后增加外键。V134 为商品增加可空的计量配置，存量商品和 SKU 默认继承商品基础单位。迁移没有改写单位 UUID、商品基础单位、属性单位或 SKU。

商品计量配置以父商品版本整体保存，试算以服务器当前版本读取已保存规格。一个包装单位可以有多个规格编码。配置写入、父版本、审计及商品变更事实在同一事务。商品审批继续冻结同一商品快照，快照增加计量配置字段。首期采用商品级规则继承，SKU 级单独覆盖、单据过账及库存双计量留待对应业务接入。计量配置非空时，通过既有结构迁移更换基础单位会被阻止；先清空计量配置再更换基础单位，避免旧比例被解释为新单位。
