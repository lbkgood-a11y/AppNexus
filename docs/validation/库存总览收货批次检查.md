# 库存总览规格、SKU 和收货批次检查

日期 2026-11-22。基准为 5ac651d 加工作区已有库存总览改动。本次在仓储现有收货、总览和整卷追溯入口增加字段。批次号由收货人员填写，同一收货批次允许多条实收共用。前端收货表单必填，兼容调用方可以省略，数据库历史未知值保留 NULL。收货批次不参与库存核算或扣减键。规格和 SKU 展示来自主数据的授权读取，使用当前可见名称和编码。

| 对象和操作 | 变更对照与版本依据 |
|---|---|
| BulkInboundReceipt.receive | 原 Controller → InboundReceivingService → InboundReceivingStore。收货批次与原实收和库存同事务入账，字段是可选的兼容追加。沿用旧摘要格式重放无批次请求，批次变动视为请求冲突。V165 为原表追加列，原入仓流程版本无需调整。 |
| BulkWarehouseStockBalance.read_overview | 原 Controller → WarehouseBalanceService → WarehouseBalanceMapper。响应附加三个可空展示字段，路由、权限、分页和结算语义相同。SKU 及规格由仓储集成适配器调用商品结构公开读取接口。 |
| BulkWarehouseStockBalance.trace | 现有整卷履约与跨仓返仓库存追溯附加原实收批次号。按可信租户和实收 UUID 取得批次，沿用原操作对当前和历史仓库、货主及商品的复核。 |
| Product | 复用原公开授权读取，商品结构、权限、声明和持久化契约保持原版本。 |
