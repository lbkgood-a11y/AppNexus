# 客商档案对象默认范围样板

日期：2026-11-27

对象默认范围属于平台授权上下文。现有租户角色授权页面和三个角色授权 API 共享同一保存用例。客商业务模块继续提供唯一对象声明、原业务命令和受控持久化。默认按对象声明的主资源键存入角色 JSON 列，管理域和租户由角色校验确定。操作覆盖继续使用既有策略表。V218 仅新增可空列，历史记录缺省为空，已有操作策略不转换为默认。

## 专用入口复核

- 客商固定 HTTP 入口的记录、字典、地理和归属候选分支均复用原应用用例。公共命令在同一 Provider 绑定了等价的查询、新增、更新、启停和历史能力。固定接口存在兼容调用，仍待逐调用方核对后收敛。
- 入库工作台列表与详情已使用公共权限计划。详情由业务用例按不同对象分别查范围和保护字段，相关专用查询需复核其跨对象来源后才能调整。
- 本轮新增的技术接线复用 MyBatis 权限许可。只读范围解析许可可在只读事务内申请并仅用于 SELECT，和原可写技术许可不同类型。角色锁及默认配置更新消费同一目标角色许可。存量指纹表未扩写。
