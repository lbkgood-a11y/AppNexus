## 已实施的迁移

- 新增后端类型命名与分包专项规范，同步 AGENTS.md、开发入口、架构、模块命名、工程结构、摘要、流程及门禁，移除 jdbc 包永久保留的旧表述。
- 主数据存储 Java 包由 adapter.jdbc 改为 adapter.persistence，主数据 Controller 归入 adapter.web；根包公开契约、应用、领域、持久化与装配按职责迁移。
- 平台普通业务 Controller 迁入第一方、平台管理及合作方 API，部署组合中的操作目录与诊断 Controller 迁出，MVC 目录聚合迁入安全技术适配器。
- 平台 security、人员、请假、工作流、打印的固定 Mapper 迁入各自 persistence；XML 随真实 Mapper 类型归入对应模块资源目录，namespace 与源码引用同步迁移。
- 统一 SqlMapper 后缀，移除 Controller/Service 调用者后缀；主数据仓储、专用查询及实现名称按 Repository/Queries 统一，平台账号、组织、审计仓储端口迁入业务侧 port。
- 打印存储包及构建模块由 jdbc 统一为 persistence，artifactId 为 print-persistence-adapter；POM 和实际源码引用同步调整。
- 人员固定存取输出端口从 MyBatis 映射中分离；任务恢复拆为公开用例、纯应用实现和技术事务输出，合作方字典查询拆为公开用例及固定输出端口；主数据 HTTP 入口改用公开管理接口。

逐类型、包及资源对照以本目录“后端命名分包治理”系列 JSON 为准。清单只记录实际迁移，不表示运行或架构验收已通过。
