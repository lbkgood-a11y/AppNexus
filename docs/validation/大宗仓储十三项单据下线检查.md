# 大宗仓储十三项单据下线检查

日期 2026-11-23。依据当前工作区差异及 Flyway V181。

删除入场接管单、实收确认单、入仓货权登记、入仓质量放行、货权过户单、库存监管单、出仓通知单、提货授权单、车次作业单、出仓确认单、出仓交接冲销单、返仓发运单、返仓确认单。整卷履约、仓储货权与额度、跨仓返仓在途工作区也包含这些单据的入口，一并撤下。入仓通知仍可签发、分页及查询明细。库存总览沿用既有只读库存投影。迁移删除运行登记和授权，保留支撑历史库存余额的业务记录及审计，原 Flyway 文件维持原校验和。

仓储模块拥有单据、读模型和事务。平台仍拥有导航、统一对象目录及授权，V181 通过既有平台表回收仓储登记。入仓签发和列表继续使用可信租户、主数据引用核验、公共访问计划、事务内操作许可和 MyBatis 租户谓词。前端使用原宿主及管理工作区组件。
