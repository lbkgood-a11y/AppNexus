## 实际差异

- V195 建立平台附件上传策略和附件资料两张表。V196、V198 登记权限及导航，复用平台现有目录。
- 平台配置域拥有 AttachmentUploadPolicy 和 ManagedAttachment 两个唯一对象。前者运行于平台域，后者使用可信租户本人范围和独立平台台账权限。业务 ID 作为附件查询键，其他业务对象的 Provider、权限及业务入口无需变更。
- 上传从受控 HTTP 原始流进入应用用例，完成格式、限额和 ClamAV 协议检查后调用部署定义的私有存储。资料保留原始文件名、实际字节数、识别类型、业务 ID、对象键、状态和审计字段，幂等重试校验业务关联及内容摘要。五分钟写入租约通过令牌限制提交。未改变既有业务模块的文件入库路径。
- 管理页面在平台导航配置域。通用 UI 封装 Element Plus 上传、列表分页和反馈，应用 AttachmentPanel 负责接入真实会话、租户操作决策及 API。
