# 人员打印预检及状态公共只读命令验收

两项查询使用现有 `POST /api/business-object-executions`，通过可信租户会话，`basisVersion` 传 0，`Idempotency-Key` 按公共入口传 UUID。原专用 API 照常可用。公共命令直接调用原查询，不调用创建、确认、模板解析或任务用例。

| 操作 | 公共 operationId | objectId | command | 原用例 |
|---|---|---|---|---|
| PrintOutput.inspect | PrintOutput.inspect | 本人已保存的打印单据 UUID | mode 为 PREVIEW 或 SILENT；SILENT 提供启用设备 UUID | PrintOutputService.preflight，原 print.job:submit |
| PrintOutput.readStatus | PrintOutput.readStatus@personnel | 当前租户输出请求 UUID | 空对象 | PrintOutputService.status，原 print.job:read |

人员状态查询新增独立的 `PrintOutput.readStatus@personnel` 入口别名，页关联指向原 `GET /api/printing/outputs/{id}`。原共享操作标识 `PrintOutput.readStatus` 和原 `GET /api/printing/external/outputs/{id}` 使用原 Controller 及实际授权。外部路径不参与人员公共命令，旧主标识不能在公共入口替代人员别名。

公共预检复用原分层查询。场景或发布模板无效、设备缺失或不可用时返回明确拒绝。渲染节点或队列暂时离线仍按原检查返回诊断状态。原专用预检保持完整诊断响应；历史输出状态依旧按原租户和读取权限查询，不受后续场景停用影响。漏接声明、运行端口、命令及入口关联分别由原装配校验和公共入口拒绝。
