## C07 布局与权限浏览器证据

真实 Chromium 路由 /#/warehousing/coil-flow 的单根 management-page 承接 main-content。默认外边距 8 px、工作区边框 1 px、圆角 8 px、数据 padding 8 px，实际对应公共变量。嵌入式表格边框 0 px，全屏独立表面边框 1 px，进出实测通过。系统配置 0／8／24 px 在 1440×900、1024×768 和 390×844 的九组实测中，区块 gap 实时继承，页面外边距和内容 padding 保持 8 px。浅、深、自动三模式在同三视口实际运行，自动随模拟系统深色切换。作业表单六个筛选及提交入口在三个视口均可见。追溯行可滚动到达，实际文档不横向溢出。无树导航，展开/收起不适用。无 Vue 属性透传警告和浏览器异常。无功能权限账号直访被拦截，按该原卷直接查询 HTTP 403。
