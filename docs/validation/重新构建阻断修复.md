## 归属与变更对照

| 范围 | 原问题与调整 | 边界及验证 |
|---|---|---|
| 工作流测试 | 缺失 JDK/Spring 导入、实例仓储夹具被静态初始化调用 | 仅测试代码，继续使用真实 Mapper 和原事务管理器 |
| 主数据测试 | 遗留 JDBC 构造及跨包访问内部类型 | 输入校验调用公开领域规则；拒绝测试使用应用输出端口替身；集成测试装配同数据源 MyBatis Mapper；TenantGeographyTest 归入对应已有持久化包 |
| 打印核心 | 核心引用适配器模块中的纯应用类型 | PrintReceiptService/Store、TemplateEditingService/Port、TemplatePublicationService/Port 从 persistence 进入已有 core/application，Java 包名和调用方不变；无 Spring/JDBC/JSON 依赖；适配器实现输出端口，核心不反向依赖适配器 |
| 业务打印 | 实现已有 business 方法但公开接口漏声明 | PrintOutputManagement 补齐原 BusinessPrinting.Request 到原统一输出路径的方法；不新增 HTTP 入口或队列 |
| 打印存储参数 | 既有 Mapper 已收紧为 String，而查询端口仍使用 Object | BusinessPrintQueries 及实现同步使用 String；场景契约 code 在领域清洗确认为字符串后传入原存储端口，SQL与参数值不变 |
| 图标 | 消费源码时遗漏虚拟 SVG 模块声明 | 公共图标入口引用现有 unplugin-icons Vue 类型，不更换图标 |
| 组织构建 | 普通 tsc 无法检查 Vue，缺少资源类型 | 对齐现有 Vue 模块检查命令与开发依赖；页面命令回调重新检查当前选中项，防止回调时为空；无布局或样式改动 |
| admin 类型 | crypto.randomUUID 默认值将幂等键推导为模板字面量类型 | executeObjectCommand/Operation 显式标注 string，仍由原调用方传同一幂等键，缺省仍生成 UUID |
| 组合装配 | OpenAPI 装配导入已迁移的旧商品包 | 删除未使用的旧通配导入，保留已有 Controller 映射与 operationId |

业务上下文、Maven 模块、部署归属保持原状；不新增表、迁移、权限或专业能力。打印应用仍由原适配器及 monolith-app 装配，表所有权、可信 PrintContext、事务及数据源不变。新增测试目录仅对齐生产已有包，不引入业务上下文或构建模块。
