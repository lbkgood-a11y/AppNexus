# 收货附件扫描与现场设备联调验收

## 接入约定

- 本机 ClamAV 容器仅向回环地址发布 3310。应用上传继续先检查类型和内容，再走 INSTREAM 扫描，最后保存文件和可用元数据。验收用无害 PNG 签名只加载到独立扫描实例，超时由隔离代理注入，业务端点使用正常扫描实例。[ClamAV Docker 说明](https://docs.clamav.net/manual/Installing/Docker.html)
- 本机原件使用用户私有目录保存，路径以受信租户 UUID 和附件 UUID 生成。原子移动完成后才提交可用记录，路径不作为前端资源。仅 local 环境允许该模式，配置与已有云存储互斥。
- 现场接入采用可信采集程序原子落盘。部署配置 `app.inbound.site.directory` 默认关闭，配置为访问受限的绝对目录。采集端按 `<目录>/<租户 UUID>/<作业 UUID>.json` 保存快照。字段为 `tenantId`、`taskId`、`station`、十进制千克文本 `kg`、布尔 `stable`、UTC ISO 时间 `observedAt`，以及可选 Base64 PNG `capturePng`。单快照最多 256 KiB，抓拍宽高最多 1600×1200。读取要求内容的租户及作业与文件名、当前上下文一致。
- 现场面板每 3 秒刷新，超过 10 秒或超前超过 2 秒的读数判为过期。模拟配置明确展示标记。抓拍需非盲检、已授权查看作业身份且无身份字段限制。读数只展示，业务过磅仍走原单据命令。

## 门禁

| 条目 | 范围与证据 |
|---|---|
| G01/G02、D01/D02 | 复用既有附件对象、工作台作业与计量读权限。新增设备采集读取适配器及界面展示。 |
| G03/G05、C01–C03、D03–D06 | 现场接口引用已声明工作台操作并额外校验计量读权限，抓拍服从身份和盲检字段策略。附件上传沿用原对象、可信租户及业务 ID。 |
| G04/C05、D11 | 扫描拒绝和超时不发放可用附件。私有存储采用原路径幂等和原子保存。设备状态不触及库存事务及业务磅票。 |
| G06/G08、C07、D12 | 真实构建、协议、浏览器及本机部署证据见下。 |
| G07/C09、D08 | 现场读接口提供状态、采集时间、精确读数、稳定标记和授权 PNG。应用配置默认为关，模拟数据区别展示。 |
| G09、D07/D09/D10、C04/C06/C08/C10 | 沿用原操作与数据库结构。现场快照从私有目录读取，权限检查复用现有按作业主键查询。未追加审批、编码、打印或库存事件。 |

## 实测结果

- 本机真实 clamd 对正常 PDF、PNG 返回 OK，回环协议探针确认可接收超过应用上限的 21 MiB 数据。隔离 clamd 对无害标记图片按专用测试签名返回 FOUND。
- 已部署新构建。本机应用使用回环扫描和 local 私有文件目录，模拟配置留在隔离测试。首页 200，两个匿名访问路径按预期返回 401。测试签名实例和故障代理验收后已停止，正常扫描容器继续运行。
- 浏览器实际上传 PDF 和 PNG，两个均返回 200 并成为 AVAILABLE。隔离扫描引擎命中测试签名时返回 400，注入超时返回 503，两种失败均展示可重试入口。数据库及实际私有目录各有且仅有两笔获准文件。超时由测试断言限定为不少于 9 秒。
- 隔离采集的 860.2500 kg 稳定读数刷新为 860.3000 kg 未稳定。测试抓拍显示，过期后隐藏，盲检车次尚可见读数并隐藏抓拍。化验岗直调现场接口返回 403。三种视口、0/8/24 px 间距继承、主题及中英文通过。
- 前端类型检查与构建通过。应用 API 契约检查 2 项、快照检查 2 项、仓储集成及浏览器联合验收 1 项通过。证据见 `.local/receiving-attachment-device-certified.log`、`.local/receiving-device-simulated.png`、`.local/receiving-scan-browser.png`。
- 现场物理驱动、真实相机和地磅设备仍待联调。隔离数据未进入真实车次，`v001` 仍待正式参数。
