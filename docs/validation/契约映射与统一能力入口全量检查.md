## 实际范围与边界

1. 新增ObjectRecordMapping构建期映射及公共MappedObjectRuntime/工厂。字段、身份、版本、状态和轮次回执都由对象所有者代码提供，不从浏览器/JSON/租户配置接收SQL。请假和商品的手写read/approvalRecord/completeApproval已删除并改为映射；特殊主管/商品冻结规则仍归原业务。
2. 新增/api/business-object-executions及公共前端executeObjectOperation，迁移请假打印并删除其旧HTTP打印入口。提交仍保留原业务准备/冻结用例；尚未统一所有提交和编码前端调用，不能将只改打印描述为全部入口统一。
3. 对象配置新增契约派生的通用能力概览，链接既有流程/打印绑定及编码配置，不新增组件或第二套对象目录。复用vxe-table、el-tabs、InfoHint、原主题及中英文。
4. 删除对象手写取数/终态回执及旧打印HTTP接线；此前V129/V131已处理旧交付表/权限。本轮无新生产表或数据库迁移。全仓其他旧协议仍待专项清单，不宣称全面删除。
5. 第三对象在隔离数据库只声明契约和映射，不实现运行器/处理器；验证真实取数、跨租户、版本、状态转换及审计。演示表不进入生产部署。
6. 完成部分真实页面检查及构建/回归，未部署；受未完成入口及全站操作检查阻断。
