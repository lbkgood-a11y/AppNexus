# 业务对象旧声明兼容移除检查

| 实际差异 | 影响范围 | 声明对照及版本处理 |
|---|---|---|
| 移除旧对象、权限注解和非引用式操作解析；统一前置拦截器从注册表读取 Provider 权限；能力装配以操作标识校验 HTTP 引用 | 组合应用全部对象及 HTTP 操作，含前次迁移的 22 个对象、127 个前置引用，以及首批 OrganizationType 的 3 个前置引用 | 生产扫描无旧注解。原 Provider 契约继续覆盖对象、操作及权限；原操作 ID、路由、权限码、能力绑定和对象版本延续，无存量数据迁移。 |

| 检查项 | 适用性和证据 |
|---|---|
| D01 | 唯一对象来源为 Provider，重复对象走启动校验。 |
| D02 | MVC 继续以稳定 operationId 关联实际操作；未解析或重复引用由注册表拒绝。 |
| D03 | 保留原 MVC 绑定、页面、路由和入口元数据，取消旧注解的兼容解析。 |
| D04 | 平台与租户门禁从同一 Provider 取得权限，可信主体及拒绝错误码沿用原约定。 |
| D05 | 数据资源、行范围和 SQL 无差异。记录级越权专项不包含在本轮。 |
| D06 | 字段契约和字段执行无差异。字段保护专项不包含在本轮。 |
| D07 | 能力装配仍校验真实路由及操作标识；各能力契约无差异。 |
| D08 | 对象事实和能力输入输出契约无差异。 |
| D09 | 编码字段、规则引用与发号无差异。 |
| D10 | 前置拦截器与真实操作注册关联，原用例、执行器和适配器继续执行。 |
| D11 | 事务、版本、审计、绑定和迁移策略无差异。 |
| D12 | 以正式 MVC 组合验证、目录及架构测试为证。 |

C01、C09 适用，验证权限准入及原拒绝协议。C02、C03、C05 的原记录、字段与事务实现无差异，未逐对象回归。C04、C06、C07、C08、C10 不适用，无迁移、查询逻辑、前端、包依赖或能力变更。
