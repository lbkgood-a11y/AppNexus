# 大宗仓储返仓卷冻结与解除检查

2026-11-22。上一轮隔离库已清理，本轮在 Chrome 重建原两卷案例，使用同一票真实履约和返仓的 17 吨原卷完成冻结、解除及再次出仓。验证使用真实组合应用、MySQL 8.4 和 Valkey，测试宿主仅提供权限和主数据。

## 浏览器及数据库结果

1. 两卷首次实测出仓共 72 吨，跨仓接管并恢复原额度。17 吨卷从监管记录登记冻结并录入冻结凭证，返仓质检结束后仍为冻结。从该卷发起新出仓被拦截，向 51 吨卷的二次车次提交配货也被拒绝。
2. 51 吨卷先完成二次出仓，其新三级额度各核销 54 吨。操作员回到 17 吨卷的监管记录，从原冻结行发起解除，提交解除凭证。请求使用同一个冻结编号与原库存身份。
3. 17 吨卷解冻后点击「发起新出仓」，接收仓、货主 B 和原卷由系统带出。建立独立的新通知、授权和车次。配货占用 17 吨，复磅重算为 18 吨，门岗交接按账面扣库存及货权 17 吨，按实测核销 18 吨。
4. 从新交接定位返仓记录，刷新后按同一原卷查看冻结和解除凭证以及审计；已解除状态仍保留。无权限会话查询监管记录、提交解除均返回 403。
