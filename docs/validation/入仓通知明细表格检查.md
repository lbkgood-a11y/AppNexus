# 入仓通知明细表格检查

日期 2026-11-23。入仓通知签发页的通知明细复用客商详情同款 ManagementTable 和 ManagedDialog。草稿明细通过 UUID 关联，表格展示商品、品规、单位、计划量、批准上限、合同号和备注，操作列支持编辑及确认删除。应用弹窗写入页面草稿，签发时主从仍一并提交。公共表格在本地草稿场景关闭刷新入口，其余入口默认沿用原设置。基础信息首项、查询输入和查询结果统一显示通知单号。未填写时沿用服务端规则，以通知 UUID 作为单号。
