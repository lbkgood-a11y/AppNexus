## 执行记录

- 前端分别执行 `pnpm --dir frontend --filter @appnexus/admin typecheck` 和 `pnpm --dir frontend --filter @appnexus/admin build`，使用 Node 24。操作绑定核对使用 `node frontend/scripts/check-operation-bindings.mjs`。日志位于 `.local/event-workbench-*.log`。
- 后端使用 Java 21 执行 `mvn -T 2 -f backend/pom.xml -pl applications/monolith-app -am -Dtest=ReliableEventsTest,ApiContractTest,GlobalRecordAuditTest#ownedTablesHaveAllFourColumns -Dsurefire.failIfNoSpecifiedTests=false test`。首次真实迁移发现权限 action 仅允许字母、数字和下划线。新迁移和声明改为 `subscription_state` 后，在隔离 MySQL 8.4 空库成功执行 V1–V220。前次失败日志和修正后日志分别为 `.local/event-workbench-maven-final.log` 和 `.local/event-workbench-maven-verified.log`。
- 发布时应用 V220 后更新所有 Worker，再开放启停权限。仍运行旧版本的 Worker 不读取开关。回退前应先恢复暂停的订阅并排空旧版本与新版本的运行交叉期，保留已经写入的状态和管理审计。
- 领取查询在独立 MySQL 8.4 浏览器夹具中用 10,000 条事件和投递做 `EXPLAIN ANALYZE`，其中 1,000 条暂停投递的到期时间早于可领取投递。查询使用 `ix_delivery_claim` 和 Outbox 主键，检查 1,001 条候选后返回 1 条，验证暂停队列不会堵住其他订阅。证据为 `.local/event-workbench-qa/subscription-explain.log`。该样本不作为生产容量结论。
- 真实后端联调还发现订阅状态写入需要把平台范围参数绑定进 SQL，符合统一 MyBatis 门禁。状态写入现以仅匹配平台零 UUID 的固定谓词执行。复验使用独立 Maven 输出目录 `target-event-topology-qa`，避免共享输出目录影响运行时类。
- 最终前端由 Node 24 使用独立 `--outDir` 构建，类型检查、生产构建和操作绑定检查均退出 0。操作检查核对 346 个显式控件和 430 个接口操作。
- Edge 使用隔离平台管理员真实登录。1440×900 浅色、1024×768 深色、390×844 系统主题的页面宿主均为 `business-workspace main-content`，主区边框 1px、圆角 8px，外边距和数据内边距均为 8px。全局间距设为 0、8、24px 时图内间距同步变化，页面及图内均无横向溢出。截图及计算样式在 `.local/event-workbench-qa/subscriptions-*.png` 与 `subscriptions-layout.json`。
- 实际登录会话读取当前拓扑。目标订阅暂停、单投递人工重试、恢复均返回 204。暂停中重试后，消息详情显示执行已暂停。浏览器夹具关闭自动 Worker 和平台 MFA；真实领取、认证及其他门禁以组合回归覆盖为准。生产部署、生产负载和生产 MFA 链路未执行。
- 浏览器完成表格全屏、退出全屏、英文切换和详情关闭。页面无 Vue 属性或脚本告警。隔离 MySQL 查到暂停、重试、恢复的三条审计及对应中文原因，恢复后开关回到启用。证据为 `.local/event-workbench-qa/subscriptions-browser.json` 和 `subscription-browser-state.log`。
- 最终组合回归使用上文 Maven 命令并附加 `-Dappnexus.build.directory=target-event-topology-qa`，退出 0。14 项全部通过且无跳过，包括事件回归 11 项、OpenAPI 契约 2 项和四审计列全表检查 1 项。验证同一事件的旁路消费者继续领取、目标订阅恢复后可领取、匿名或无 CSRF 请求受阻、固定权限订阅无法停用，以及暂停和恢复原因同事务持久化。最终日志为 `.local/event-workbench-final-maven.log`。
