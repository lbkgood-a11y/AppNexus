## 浏览器证据

- 本机 Vite 8848，现有 admin 会话。商品管理 `/#/master-data/product` 的 `.product-page.main-content` 和客商管理 `/#/master-data/partner` 的 `.business-workspace.main-content` 均承接实际应用壳。
- 两个路由分别验证 1440×900、1024×768、390×844。宿主外边距与查询区内边距均为 8px。客商工作区边框 1px、圆角 8px、区块 gap 8px。商品树表最外层为布局容器，嵌入表格边框和内边距均为 0px。按目标视口重载后页面及查询区横向溢出均为 0。商品页直接把已展开应用侧栏的桌面会话缩到手机宽度时，查询区临时出现 48px 横向滚动，手机视口重载后消失。
- 商品页在系统设置中将区块间距切换至 0、24、8px，树表内容的计算行距依次为 0、24、8px，外边距和查询区内边距均保持 8px。查询折叠键盘往返保留输入，树栏键盘收起展开成功，表格全屏进入及退出成功。
- 商品页浅色、深色和自动主题下标签中心均与边框顶边相差 0px。浅色背景为 RGB 255/255/255，深色为 RGB 28/30/35，输入保留 1px 原生内阴影边框。中英切换后标签和查询、重置按钮正常显示。客商页末次重载复核标签点击关联输入，焦点标签颜色与主题主色 #006BE6 一致。
- 主题与尺寸分别验证。自动主题随本机呈现为浅色，未模拟系统外观切换。未持久化截图，计算值及交互结果记录于上。
