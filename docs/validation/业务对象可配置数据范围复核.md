# 业务对象可配置数据范围复核

复核基线为 `d1f0a42` 中 `ObjectExecutionAssemblyTest.allMigratedObjectsDeclareExecutedDataResources` 固定的 32 个对象。判断依据是管理业务的真实归属、权限主体与目标记录之间的关系，以及限制是否能覆盖读写和关联入口。

| 对象 | 归属及入口 | 配置结论 |
| --- | --- | --- |
| OrganizationRelation | 组织领域关系，两端均为租户组织 | 沿用组织单元配置，列表和删除要求两端均在范围内，创建检查两端 |
| Position | 组织领域岗位，岗位固定归属于组织 | 沿用组织单元配置，列表、创建和修改按所属组织判定 |
| PositionAssignment | 组织领域任职，任职通过可信岗位归属到组织 | 沿用组织单元配置，列表、创建和修改按岗位所属组织判定；人员档案维护入口仍待核对 |
| Person | 人员档案和明细，人员可在多个组织任职，账号与人员另行关联 | 应支持组织范围。待统一多组织任职、历史及无组织人员、直属维护与异动目标规则，补齐档案明细、账号关联、任职写入以及目录投影 |
| Warehouse | 仓库主档和仓储引用；物流组织属性是文本业务资料 | 应支持按仓库划分数据。待确定可信仓库组织归属或仓库记录范围，并覆盖仓储区域、库位和业务引用；不得用现有文本字段决定授权 |
| AuditEvent | 双域审计列表，事件面向该域审计管理员 | 如需委派局部审计，应采用受控目标或事件范围，待确定可委派边界及导出、检索约束；当前审计域权限沿用 |
| WorkflowInstance | 流程实例的参与人、发起人和管理查询 | 参与范围继续自动执行；跨组织委派的管理查询有配置价值，待原单据权威归属和实例管理联动 |
| WorkflowTask | 流程任务、指派关系 | 办理资格随任务状态和指派变化；管理侧是否开放局部任务查询与流程实例一起确定 |
| WorkflowJob | 内部作业、租约和受控运维 | 保持作业及运维准入，无通用角色组织范围 |
| WorkflowDefinition | 流程配置和版本发布 | 租户公共配置，按定义和发布功能授权 |
| PrintDevice | 打印设备和队列、机器接口 | 按设备分管有配置价值，待统一设备记录范围、设备选项、派发及代理凭据边界 |
| PrintDocument、PrintOutput、PrintJob | 打印单据、结果产物、任务和回执 | 需要覆盖来源业务范围及打印管理查询；待在提交、下载、补打和受控机器读取中统一关联来源，外部主体所有权仍独立强制 |
| PrintDataContract、PrintScene、PrintTemplate | 打印配置、场景和模板版本 | 租户公共配置；实际取数的范围属于来源单据操作 |
| ProductCategory、ProductAttribute、ProductTemplate、ProductUnit | 商品分类配置、属性、模板、单位和换算，供租户商品维护和引用 | 租户公共目录，按维护功能授权；商品档案已有独立数据范围 |
| OrganizationType | 租户组织类型和引用 | 公共类型目录，按维护功能授权 |
| OrganizationAuthorization | 组织授权管理操作，涉及角色上下限和目标主体 | 保持统一授权管理准入；委派资格由授权模型表达 |
| BusinessDictionary、TenantParameter | 租户字典、参数键及受控子项 | 共享配置目录，按功能、键白名单及租户边界 |
| PlatformRole、TenantRole、AuthorizationTemplate、PermissionCatalog | 平台或租户的角色、权限配置、模板和目录 | 属于统一授权控制面，按对应管理资格、目标域和授权上限控制 |
| TenantInvitation | 平台定向邀请及一次性凭证 | 平台管理准入和邀请目标绑定；凭证交换执行一次性校验 |
| NavigationMenu、BusinessObject | 导航配置及双域对象目录 | 按管理域、目标绑定和启停权限维护；用户导航仍由其有效准入派生 |
