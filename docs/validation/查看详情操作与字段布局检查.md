## 仓库详情分列回归修复

截图显示仓库查看态在桌面宽度仍逐字段占用整行，且状态标签撑满可用宽度。公共样式原先对 `.is-readonly-view` 的字段和审计区域强制使用块级排布，同时列方向 Flex 默认拉伸状态标签。本次移除该块级覆盖，恢复主详情模板原有分列，状态标签按自身内容宽度显示。查看字段边框继续为 0，页面按钮条件沿用本记录前文。

- G01、G02、G07、G09 与 D01–D11 复核范围为公共样式和说明。受影响对象为复用模板的客商、仓库、人员、商品及 SKU。对象、操作、路由、授权字段与后端契约均无差异，无声明版本或迁移。
- C01–C06、C08–C10 未触及操作绑定、权限、数据、写入、查询、架构、部署配置及能力执行。适用的操作绑定静态校验沿用项目脚本。
- C07 的 Edge 样式回归使用仓库详情的模板层级及公共 CSS。1698×816、1440×900、1024×768、600×768、390×844 下查看和编辑分别一致为 6/6/4/2/1 列，0/8/24px 间距均继承，字段边框为 0px，各宽度下状态标签窄于字段，无横向溢出。1698px 时标签 77px、字段 270px。上述验证为独立 DOM 样例。
- G04、G05、D12 和 C07 的登录态真实路由、实际宿主计算样式、主题语言及授权回归未验证。
