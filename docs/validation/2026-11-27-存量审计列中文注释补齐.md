## 执行命令

在 `D:\AppNexus` 执行。四列门禁日志为 `%TEMP%\appnexus-audit-comments-test.log`。单列主键门禁日志为 `%TEMP%\appnexus-audit-comments-primary-key-test.log`。

```powershell
mvn -f backend/pom.xml -pl applications/monolith-app -am '-Dappnexus.build.directory=target-global-audit-review' '-Dtest=GlobalRecordAuditTest#ownedTablesHaveAllFourColumns' '-Dsurefire.failIfNoSpecifiedTests=false' test
mvn -o -f backend/pom.xml -pl applications/monolith-app -am '-Dappnexus.build.directory=target-global-audit-review' '-Dtest=GlobalRecordAuditTest#ownedTablesHaveSingleIdPrimaryKey' '-Dsurefire.failIfNoSpecifiedTests=false' test
```
