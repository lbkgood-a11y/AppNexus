## 真实页面证据

- Chromium 通过正式 admin 应用壳打开 `/#/master-data/partner`，后端为隔离 Spring Boot、MySQL 和 Valkey。租户管理员和普通只读成员均用真实服务端测试会话。只读成员列表有数据、没有导出按钮，直调准入接口返回 403。匿名返回 401，已授权账号返回 204。
- 文件按 `.xlsx` 下载并由 openpyxl 读取。23 条验收客商分两页导出 20 和 3 行，无跨页编码重复；用户隐藏编码列后，再次下载的文件没有该列。全屏模式同样可下载；中英文导出按钮可识别。openpyxl 应用读取器默认样式。
- 在 1440×900、1024×768 和 390×844 三个视口及浅色、深色、跟随系统三种主题下，使用应用壳偏好切换 0、8、24 px 各一次，共 27 组计算样式。真实内容宿主为 `.business-workspace.main-content`。外边距 8 px、边框 1 px、圆角 8 px、工作区宿主内边距 0 px，嵌入表格容器边框和内外边距均为 0 px。工具栏底部间距随设置取 0、8、24 px，页面横向溢出均为 0 px。客商页面为平面列表，树展开验证不适用。
- 单独以 Enter 键触发下载并读回 20 行；加载完成后焦点落在页面 body。0、8、24 px 三次设置下，查询区和数据区内边距均保持 8 px，与内容内边距 Token 一致。
