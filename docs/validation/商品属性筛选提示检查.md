- 在 `frontend` 执行 `pnpm --filter './apps/admin' typecheck` 和 `pnpm --filter './apps/admin' build`，均退出 0。运行环境为 Node 22.18.0，pnpm 提示仓库要求 Node 24–26，Vite 构建有配置兼容与动态导入警告。针对改动文件执行 `git diff --check` 通过。
