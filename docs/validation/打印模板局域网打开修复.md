# 打印模板局域网打开修复

验证日期 2026-11-25。状态为待验收，产物仅在本地构建。

## 修复与复现

在 Edge 从局域网 HTTP 访问开发服务的 `/print-controls-check.html`，修复前 `isSecureContext=false`、`typeof crypto.randomUUID === 'undefined'`，设计画布等待超时。回环 HTTP 地址上画布可加载。打印管理使用同一标识能力生成模板编码，打印流程组件在初始化时也调用它。

打印域统一用 Web Crypto 安全随机字节生成 UUID v4。模板和场景等编码保留原前缀，输出标识仍使用原传递方式，画布消息继续匹配指定 iframe 窗口和随机会话标识，API 继续发送原 CSRF 与幂等请求头。
