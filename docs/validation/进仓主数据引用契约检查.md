## 执行记录

仓库根目录，Maven 3.9.15、Temurin 21.0.11。使用已缓存的数据库与 Valkey 镜像，测试命令关闭 Ryuk 镜像拉取依赖。命令退出码 0。

```sh
TESTCONTAINERS_RYUK_DISABLED=true mvn -f backend/pom.xml -pl architecture-tests -am -Pcontainer-tests -Dtest='MasterDataMySqlTest,ProductV1IntegrationTest,ArchitectureRulesTest,ServiceLayerBoundaryTest,PackageDocumentationTest,TypePlacementRulesTest' -Dsurefire.failIfNoSpecifiedTests=false test
```

实际执行 27 项，通过 27 项，失败、错误及跳过均为 0。主数据 1 项、组合应用 3 项、架构 23 项。报告位于对应模块的 `target/surefire-reports`。组合应用用例验证正式装配、位置和商品归属、停用、跨租户、无权限、预期版本冲突、基础单位直收、单位规则换算、包装换算和证据单位错配。仓储写入、主数据与过账的并发协调和生产部署未验证。
