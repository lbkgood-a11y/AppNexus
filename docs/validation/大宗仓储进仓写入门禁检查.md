# 大宗仓储进仓写入门禁检查

日期 2026-11-21。范围为组合应用中的签发、接管、实收及待检过账，以及通过首阶段验证后接入的货权登记和质量放行。测试使用隔离 MySQL 8.4 和 Valkey，运行 Maven 3.9.15、Java 21。没有生产部署。

| 门禁 | 适用性与证据 | 结果范围 |
|---|---|---|
| G01 | 进仓详设及实际 Controller、三个 Provider 对照 | 单行通知按独立接管范围分批实收，接管、实收、过账、权利和质量分开记录 |
| G02 | 正式模块组合，出站只调用公开主数据接口；仓储表与迁移独立归属 | 架构测试验证实际生产类，适配器负责 MyBatis 和事务 |
| G03 | 三个对象、五个操作接统一声明与 AccessPlanning，SQL 使用可信租户拦截 | 仅显式仓储权限及全部数据范围可执行，按原主数据权限进一步核验仓库及货主 |
| G04 | ProductV1IntegrationTest 的煤炭案例及真实质量放行 HTTP 调用 | 120 t 限额，两个 39 t 实收，43 t 超收拒绝，42 t 失败后可重试 |
| G05 | 同租户无权限与跨租户调用，验证主数据归属及版本；凭证与状态引用固定 | 相同操作重放仍检查权限、仓库和货主，陌生记录拒绝 |

| G07 | 新公开接口文档、中文列注释及稳定错误码 | 保留来源凭证、基础单位及换算依据 |
| G08 | 独立测试环境状态和未实现能力 | 未部署，无 UI、打印、工作流或出仓可用性查询 |
| G09 | 下表复核声明及真实入口 | Provider、MVC 引用、授权执行器、可信 Mapper 和事务可逐层追溯 |

## 适用范围

外部权利和质量依据由已授权岗位核验后登记。本阶段存证据引用，有效净重等现场事实通过受控岗位提交；地磅、样品及外部登记系统直连仍是后续工作。按整条已过账实收范围登记权利和放行，部分范围先拆为独立接管及实收。放行只转换质量状态，出仓分配仍须实现货权、质量、监管和占用的联合检查。
