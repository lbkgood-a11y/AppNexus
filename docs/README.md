# 项目设计文档

当前阶段：第一期设计基线已确认，进入正式框架功能开发。PoC 仅用于隔离验证具体技术不确定性，不代替正式功能交付。

- [单据类型与行为契约详细设计](design/单据类型与行为契约详细设计.md)：类型、投影契约、行为执行器、配置发布、专业能力绑定及请假迁移的详细草案。
- [单据服务集成契约设计](design/单据服务集成契约设计.md)：能力配置与关联中心边界、平台/租户治理、统一业务服务接入端口及关联事件约定。

- [打印服务设计与选型记录](design/打印服务设计与选型记录.md)：在线设计优先、HiPrint 候选、导出缺口、许可及安全门槛、工程目录与验证计划。

- [外部集成客户端实现与验收](design/外部集成客户端实现与验收.md)：固定租户客户端、双密钥、幂等、限流和调用审计。

- [租户参数国际化审计与邀请增量](design/租户参数国际化审计与邀请增量.md)：参数默认值、精确展示、受权审计及邀请激活。

- [工作流服务详细设计](design/工作流服务详细设计.md)：平级服务工程、组合启动、内嵌 Flowable、跨服务约束及当前交付范围。

## 维护约定

1. 用户确认后，将决定同步到对应设计文档，不能只保留在聊天或讨论记录中。
2. 未确认方案明确标记为草案，不将建议视为定稿。
3. 已确认原则与接口、表结构等详细设计分别标记成熟度。
4. 决策变化时更新设计基线，并在讨论记录中说明替代关系。
5. 未来按领域形成详细设计文档，明确模型、聚合、一致性约束、接口及权限；在确认前不作为实现依据。
6. 后续工程与模块命名遵循[后端工程详细设计中的命名规范](design/后端工程详细设计.md)，保持简短、统一和可预测。

- [组织管理员初始化与授权验收](design/组织管理员初始化与授权验收.md)：一次性管理员配置、组织管理与成员授权的部署流程和验收记录。

- [租户用户成员组织操作流程](design/租户用户成员组织操作流程.md)：平台开通、用户/成员管理、主要组织归属、单租户自动进入与多租户切换，以及官方产品参考。

- [工作流服务构建交付](design/工作流服务构建交付.md)：首批实现矩阵、业务契约、迁移配置、验证与未完成项。

- [流程设计器布局调研与改造](design/流程设计器布局调研与改造.md)：独立菜单、官方资料调研、编辑器布局和验证范围。
