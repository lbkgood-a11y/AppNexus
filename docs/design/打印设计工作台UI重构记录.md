现有功能为默认组件拖拽、原生按类型属性、原生表格编辑、多面板、固定文字、契约字段插入、纸张设置/旋转、自动排布、示例预览、同步、保存、关闭确认。HTML/脚本虽在默认库中有入口，但原有校验不允许保存，本次明确提示限制，不放宽安全契约。

推荐并采用：Vue/Element Plus 负责标题、工具栏、状态和保存；iframe 保留资源节点、物理纸张与原生属性面板。模板已有布局和通用组件不适用于上游依赖全局 jQuery/原生 DOM 的挂载点，因此仅在既有隔离适配内部组合资源标签和搜索，不引入第二套业务组件体系。

原组件节点只移动不重建，保留 tid 与上游拖拽绑定。属性标签切换通过 hidden 保留原始控件，实时更新仍走 HiPrint。复制仅使用会话内存，删除需确认，粘贴/删除重建进入相同快照历史；表格的原生选择与行列操作继续使用原生上下文菜单（getSelectEls 不返回表格），不会伪装成已支持全部表格工具栏操作。

zoom 使用 panel.zoom(value,false)，并恢复原 scale 配置；限制为 25%—200%，默认视图 100%。不对纸张施加外层 CSS transform，不转换元素 pt 坐标或物理 mm 尺寸。适应画布按当前面板宽度和可用视口计算；多面板统一视图比例，但不会修改模板各自的纸张规格。

## 未实现与风险

- 不接入虚构业务数据源；仅显示父级当前服务端注册契约。未选择时提供说明，不注入仓库/客户等假字段。
- 动态表格复用已有契约 columns 插入和预览能力，不另建无效组件入口。
- 来源选择、通用格式化、日期/数字格式、空值处理是规划能力，仅说明，无可点击假表单。
- 辅助线继续沿用原生元素定位提示，不增加未经证实的独立辅助线开关。
- HTML 与脚本扩展仍受原安全策略限制。
- 原生 getSelectEls 不包含表格，因此表格选择计数与工具栏对齐/复制/删除不承诺覆盖表格；使用原生属性与表格菜单。若要统一应另行验证上游公开选择事件/API，不能根据 CSS 私自推断对象身份。
- 上游私有 DOM 类名用于目录重组、标尺显示，升级 HiPrint 时必须回归。跨页纸张不同宽度时适应比例以当前面板为准。
- 保存期间与属性操作的并发、慢网络及权限失效仍需真实会话回归；保存失败继续由原父页错误机制反馈，不清除脏状态。

## 加载失败修复

字段契约来自 Vue 响应式状态，直接作为 initialize 的嵌套 payload 传入 postMessage 会触发 DataCloneError，导致 iframe 被初始化异常清理。消息边界新增 messagePayload，将内部 JSON 消息转换为普通对象后发送；不放宽 sandbox 或改变模板协议。新增真实 Vue reactive 对象回归，验证原消息不能结构化克隆、转换后可以且数据隔离。加载未成功前不再显示“已保存”。修复后打印模块 22 项测试与管理端类型检查通过；登录后的实际页面重试仍需验证。

## 第二轮：空间与层级优化

本轮修改 TemplateDesigner.vue、PrintManagement.vue、frame.ts、index.ts、新增 workbenchStyle.ts，以及中英文文案；不修改引擎、模板或保存契约。

- 外部窗口仅保留通用“设计模板”标题；对象名称在内部 50px 模板栏显示一次，保存/取消保持原权限及关闭确认。
- 主工具栏固定 50px，不再换成多行。编辑常用操作使用 text 按钮；画布菜单容纳纸张设置、旋转、标尺、网格和对齐；更多菜单保留快捷制作、自动排布和同步；示例参数移入 Popover。
- designOnly 的整行 Alert 改成模板栏提示标签与 Tooltip。溢出错误仍有明确提醒。
- 左栏默认 232px，轻量图文列表、分类间距 22px，折叠为 48px 图标轨道。右栏默认 288px，独立折叠至零宽。视口小于 1100px 初次进入时收起两栏，不自动缩放纸张。
- 两侧列宽使用外壳 CSS 变量；资源栏 180—300px、属性栏 240—380px，拖动考虑画布 400px 保留空间，键盘方向键每次 16px。窄屏隐藏拖动手柄，仍可折叠。
- 原生属性行在各自原父容器中归入可折叠语义分组：基础、位置尺寸、字体文本、边框背景、打印分页。位置尺寸采用双列，未知字段回归基础组。只移动原节点，不生成新字段或移入其他原生 Tab；原生纸张与元素属性的切换仍由 HiPrint 管理，不根据平台不完整的选择计数推断表格状态。
- 底栏固定 40px，移除中键操作的常驻长提示，缩放按钮统一轻量尺寸。工作区自己滚动，去掉画布容器最小 320/360px 高度，允许真正占据剩余空间。纸张尺寸、pt 坐标及原生 zoom 计算均不变。

验证：打印模块 22 项测试通过；管理端类型检查通过。实际浏览器仍返回登录过期页面，因此 1440×900、1920×1080 的登录后实际设计器、折叠拖动、原生属性分组后的事件与打印尚未完成验收，不能用 CSS 尺寸声明代替实测。全仓操作门禁仍被其他已存在页面的未登记交互阻挡，本轮未增加相关错误。生产构建结果见最终说明。

风险：属性分组依赖上游 DOM 行和标签，尤其需回归表格专属属性、纸张分页以及原生 Tab；此次不开放组合功能（没有经验证的引擎组合 API），不新增无效按钮。后续 HiPrint 升级需核对 DOM 结构。恢复真实登录后必须完成两种桌面分辨率、深浅主题与元素编辑验证再视为 UI 验收完成。

## 快速制作右侧停靠改造

移除快速制作 ManagedDialog，复用 Vue 外壳 canvas-area 的右列停靠表单（380px、窄屏最多 48%），不覆盖纸张。由于原属性面板处于 opaque iframe，不能直接挂载 Vue 表单到其中，因此用受控 quickPanel 消息临时收起原属性列并记住其折叠状态；关闭恢复原状态和原 DOM 控件，不重建设计器。停靠期间隐藏原属性展开按钮，防止出现两套右栏。

三个等宽 Tab 保留原输入状态；字段通过当前契约名称分区、搜索、单选后调用原 insertField，未新增原先不存在的字段拖拽协议。文字使用原 insertText，不新增字体等空配置。纸张打开时以真实当前宽高显示自定义状态，选预设更新尺寸、自定义允许编辑，调用原 paperTemplate 应用机制。修复状态轮询覆盖未应用宽高的问题。内容独立滚动，固定标题与底栏；取消/关闭只收起，应用保留面板便于继续操作。
