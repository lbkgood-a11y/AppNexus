# 数据权限与字段脱敏修复

日期：2026-11-09。本文描述本批实际接入范围，不代表完整权限中心已经交付。

## 入口和使用

授权中心顶部提供功能权限、角色默认数据范围、字段与脱敏、主体角色；租户授权中心另有成员数据权限。

先分配主体角色，再到成员数据权限选择成员和已分配角色，配置组织精确范围、组织及下级或当前租户全部，填写原因后保存。到期时间以界面本地时间选择、以带偏移的 ISO 时间提交，后端存 UTC；留空为长期。角色默认数据范围只在首次分配时复制，后续改动不扩大已有成员授权。不同角色分支不能拼接操作与范围。

字段与脱敏首批接入平台账号 `identity.account.email` 和 `phoneNumber`，支持强制隐藏和脱敏。限制对所选角色的有效账号生效；多角色取更严格限制，普通角色不能绕过。平台账号列表、创建和修改响应在服务端处理，受限联系方式只读，回传遮盖值不会写库。查询不支持联系方式搜索，避免通过计数推测受限原文。账号名及显示名不属于本批字段限制。

租户当前没有接通安全字段的资源目录，字段页明确说明；不提供假的手机号、身份证等配置。业务字段的可写、查询能力、记录条件脱敏、临时原文审批和自定义算法尚未接入。

## 模型与迁移

V25 新增成员授权头、权限快照、组织范围值；租户与成员角色关系通过复合外键约束，迁移一次性复制现有关系与策略。角色减权运行时立即与快照求交；角色增权不自动进入快照。成员停用删除当前角色/快照和兼容直授权并推进授权版本，恢复不恢复撤销权限。历史保留在审计。

V26 新增角色强制字段限制，不产生新的功能权限。字段限制独立于普通授权并集，使用服务端受控目录校验，不允许任意属性路径。

精确组织与组织子树分别计算后合并为精确集合；递归查询固定租户，使用 UNION DISTINCT 消除重叠及循环重复。旧组织授权回退使用完整权限码白名单，不能仅按动作后缀映射其他资源。组织 SELF 无执行语义，不再作为可选元数据返回；组织创建只允许 ALL。

成员解释读取与鉴权相同的授权快照，标记到期、角色减权、主体停用、缺少范围及不支持范围。旧直授权仍属于兼容来源，尚未整合进角色解释；页面持续提示解释边界。新成员授权接口复核管理权、可信租户、目标归属及 CSRF，保存复核成员版本与角色版本。

## 页面与组件

复用 BusinessWorkspace、Element Plus Tabs/Select/Form/DatePicker，未引入新 UI 库。新增 MemberGrantEditor 是独立成员授权任务组合：现有 SubjectAuthorization 只保存角色 ID，无法表达独立分支范围、到期及成员版本，因此以独立组件封装，使用同一工作区表面。角色与成员授权为不同聚合，分别明确保存，不伪装跨聚合原子提交。页签草稿保留、路由离开确认、保存禁切目标与失败禁写。

## 验证与边界

新增真实 MySQL 测试覆盖同角色不同成员范围、角色扩大不扩权、到期拒绝及解释、精确组织与子树混合、旧授权资源边界、服务端脱敏、遮盖值防写回及查询计数。新增无身份、外租户、普通成员及无 CSRF 的独立授权接口检查。已有角色、权限目录和组织授权测试保留回归。

本批验证结果：角色与授权 10 项通过，权限目录 3 项通过，原组织鉴权 2 项及组织授权管理 5 项通过，架构测试 2 项通过；admin 类型检查、Node 24.22.1 工作区构建及后端打包通过。独立授权测试同时覆盖成员停用恢复不能带回旧权限。合跑曾因测试先撤销再断言原权限的顺序错误失败，纠正后角色测试全部通过；此前不同测试类公开 URL 配置不一致引起的上下文冲突通过单独验证目录解决，不修改认证配置绕过校验。
