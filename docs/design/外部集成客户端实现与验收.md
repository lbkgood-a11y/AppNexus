# 外部集成客户端实现与验收

日期：2026-11-10。已接入客户端管理、标准 Client Credentials、固定租户只读字典及幂等字典引用登记；契约和全量验证继续完善，不将后续集成业务资源视为已交付。

## 主体及管理边界

集成主体不等于账号或租户成员，不通过系统账号冒充用户。平台管理在租户列表打开「集成客户端」，创建时固定绑定当前有效租户；默认 `dictionaries:read`，可显式增加 `dictionary-references:write`。scope 只接受已实现集合，不能通过配置虚构业务能力。

新增 `IntegrationClients.vue` 是租户管理弹窗内的场景组合：已检查 `BusinessWorkspace`、`ManagementTable`、`ManagedDialog` 及 Element Plus，直接复用。既有用户/成员组件具有不同身份和字段，不能承载机密客户端的一次性密钥生命周期，因此新增最小组合组件，不增加 UI 库或布局体系。

管理写入沿用平台强制 MFA、CSRF、权威管理员行锁及版本检查。密钥 32 个随机字节，以 Argon2id 哈希保存在标准 OAuth 注册表；原文只在创建或轮换响应显示一次，组件卸载释放，不放日志、URL 或浏览器持久存储。当前管理目录每租户上限 100 条，尚未提供完整分页。

## 标准 Token 和接口面

客户端以 HTTP Basic 向 `/oauth2/token` 申请 `client_credentials`，生产必须 HTTPS。签发 5 分钟不透明 Access Token，不签发 Refresh Token。每次签发和访问均复核客户端、租户状态及授权版本；停用、scope 变更、密钥轮换推进版本并删除旧授权。

`/v1/**` 独立无状态 Bearer 链只接受 `PARTNER_CLIENT`，不接受 Web Cookie 或原生用户 Token。客户端 Token 不能访问第一方 `/api/**` 或平台 BFF；主体绑定不能从请求体、URL 或任意 tenantId 请求头变更。生产仍需部署入口 Host 隔离与 HTTPS 验收。

## 双密钥轮换

新密钥创建后，前一密钥哈希保留固定 600 秒认证过渡窗口；旧 Token 立即撤销，两把密钥在窗口内均可重新获取当前授权版本的 Token。过渡窗口内拒绝再次轮换，避免第三把密钥替换未完成迁移的前一把。过期前一密钥默认拒绝，不以客户端时间判断。

OAuth 客户端认证的编码器才支持该策略；账号密码编码器保持原有 Argon2id。过渡哈希通过当前 OAuth 注册哈希及客户端表连接定位，不能跨客户端匹配。V39 字段存放哈希和 UTC 截止时间，不保存旧密钥原文。

## 已开放资源

- `GET /v1/dictionaries/{code}/items`：仅固定租户下启用、未删除的字典和字典项。分页 `page` 默认 1、最大 100000，`pageSize` 默认 20、范围 1–100。固定联表对两个表均施加租户谓词，计数沿用相同条件；公开 DTO 只有 code/value/name，不含内部标识、操作者、授权、密钥等字段。
- `POST /v1/dictionary-item-references`：通过稳定字典编码及项业务值登记调用方业务引用。`Idempotency-Key` 为 16–128 位字母数字及 `._:-`，作用域为客户端和本操作。规范化字段摘要、引用登记和幂等记录同事务提交，客户端权威行锁使相同客户端的并发写入串行化。同键同参数返回原 201/Location/结果，同键参数变化返回 409。字典与项锁阻止引用登记和删除/停用竞态；不存在/外租户/停用项统一 404。
- `GET /v1/dictionary-item-references/{id}`：只查询本客户端固定租户的登记。跨客户端与不存在统一 404。该引用记录参与既有字典项删除保护。当前不提供撤销引用 API，幂等记录保留至显式迁移，不能自动清理后重放业务效果。

## 共享限流与审计

每个客户端 60 秒固定窗口最多 60 次请求，由 Valkey Lua 共享计数；超过返回 429 和 `Retry-After: 60`。计数不可用时拒绝。所有已认证合作调用进入统一过滤器，先保存开始记录，再进入业务；完成更新 HTTP 状态。进程崩溃留下 status=0 表示未确认，不记为成功。审计失败拒绝新调用；响应已提交后的完成记录故障可能留下未确认状态，不能宣称跨 HTTP/数据库原子提交。

`X-Trace-Id` 由平台生成 32 位随机追踪标识，通过 MDC 关联技术日志。审计仅保存固定租户、客户端、稳定操作码、追踪标识、HTTP 状态和 UTC 时间，不保存原始 URL、请求正文、密钥或 Token。认证失败在进入已认证过滤器前被拒绝，尚未形成匿名调用审计目录。
