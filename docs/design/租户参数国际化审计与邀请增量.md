# 租户参数、国际化、审计与邀请增量

日期：2026-11-10。以下记录正式接口、默认值和边界；不将页面入口或数据模型当作全站完整接入。

## 租户参数

V43 创建固定租户参数和追加审计。`GET /api/configuration/parameters` 只允许当前有效成员读取非敏感展示参数；`PUT /api/configuration/parameters/{key}` 复核可信租户、成员及 `organization.permission:grant` 管理能力。首次版本 -1，创建后零，更新按当前版本 CAS，冲突 409。参数更新和审计同事务，审计不存原值。

| 参数 | 中文说明 |
|---|---|
| `display.time-zone` | IANA 展示时区，默认 Asia/Shanghai；只格式化时间点，不修改业务日期、UTC 存储或授权有效期。 |
| `display.currency` | ISO 4217 三位币种，默认 CNY；展示建议，不重算业务金额，不覆盖原始币种，不执行汇率折算。 |
| `display.page-size` | 建议每页条数，默认 20 条，范围 10–100；实际接口仍执行各自上限，不扩大权限范围。 |

只有上述登记参数可维护，不能通过通用配置保存密钥、数据库连接、SQL 或任意脚本。个人中心偏好页复用 Element Plus 表单；有效成员只读，管理者可保存，失败保留输入并禁写至刷新。默认币种、页大小尚未在所有业务页面消费，不宣称全站统一默认已完成。

## 展示格式与汇率依据

`@appnexus/localization` 增加 `formatInstant` 和 `formatMoney`。时间点要求 ISO Z/偏移证据，业务日期字符串不做时区转换；无效展示时区回退 UTC。金额直接分组服务端十进制字符串，最多 18 位小数，不经过 JavaScript Number，不四舍五入或折算，保留原始币种。安全日志和会话列表已使用租户展示时区。

`ExchangeEvidence` 是不可变历史汇率依据模型：原/目标币种、精确正汇率、业务日期、审核来源、UTC 采集时间、结果小数位 0–8 和明确舍入规则。同币种汇率必须为 1；模型不提供联网选率、折算或持久历史维护服务。金额/时间格式测试 2 项通过，覆盖超浮点精度及业务日期不偏移。

严格 JSON 新增 `@appnexus/localization: workspace:*` 仅复用工作区格式能力，不引入新实例或第三方库；说明位置为本文。锁文件已同步，`pnpm install --frozen-lockfile --offline` 验证通过。

## 统一审计读模型

`GET /bff/platform/audits` 由权威平台管理员查询，tenantId 缺省仅平台事件；指定租户时固定查询该租户。`GET /api/audits` 仅当前可信租户且具有授权管理能力，客户端不能覆盖租户。固定 UNION 各分支独立租户谓词，分页 page 默认 1/最大 100000，pageSize 默认 20/最大 100。

当前合并平台操作、租户字典、参数和集成调用元数据，仅返回来源、事件标识、操作者标识、动作、目标标识、traceId、状态和 UTC 时间。不返回姓名/联系方式、密码、Token、权限 JSON 或业务原值；没有采集 traceId 的历史事件保持 null，不虚构关联。个人中心新增审计摘要分区，复用表格及分页，403 显示明确无权反馈。

真实 MySQL 审计测试验证 A/B 隔离、traceId 保留和无权拒绝。角色/组织等其他审计源、归档保留、防篡改以及全局匿名失败事件尚未全部归并，不宣称完整合规审计已完成。

## 邀请与激活

V44 邀请固定绑定已有账号和租户，凭证 256 位随机、仅保存 SHA-256 摘要、24 小时有效。平台成员表单可选签发邀请，标识/凭证只显示一次并通过受控渠道交给本人；不自动发送邮件或短信，不信任未验证邮箱。未接受前不创建有效成员或角色。

本人通过 `POST /bff/account/tenant-invitations/acceptance` 提交标识和凭证，认证账号必须匹配。服务端按租户、账号、邀请锁定，复核状态/期限/摘要，并在同事务创建或复用成员、消费邀请、追加审计。重新加入复用历史成员 ID，清理角色快照，不恢复旧授权。平台可撤销待接受邀请，新邀请替代同账号同租户旧待接受邀请。

本人个人中心资料分区提供接受表单，不从 URL 自动消费，避免链接预取副作用。签发和接受都保留 CSRF；平台签发受默认强制 MFA 约束。专项真实数据库测试 2 项通过，含错账号、重放、过期、撤销、替换和复用身份。陌生邮箱注册、邀请通知投递和完整撤销列表 UI 尚未交付。

新增表单均组合已有 Element Plus 和场景布局；没有引入 UI 库。登录后新增参数、邀请、审计的深色/英文/三视口完整浏览器验收仍待执行。
