# 字典管理视觉样板

本次样板仅覆盖 `/configuration/dictionaries`，用于评估保留 Element Plus 时的视觉改善空间。沿用 vue-pure-admin 应用壳，不新增 UI 库或自定义组件。

## 组件与实现

复用 TreeListTemplate、ManagementTable、ManagedDialog、AppIcon 与 Element Plus。通过已有 navigation 和表格单元格插槽增加页面标题、分类编码和记录说明；编辑条目弹窗显示当前字典上下文，降低多字典编辑时的辨识成本。

页面使用主题语义变量区分侧栏、选中项、表头和编码，统一标题、辅助文字、行距及弹窗操作区。样式限定页面与弹窗内容类名，不修改公共组件及全站主题。新增说明文案同时提供中文与英文。数据、权限、会话和提交接口保持原有契约。

## VxeTable 局部试用

经用户明确授权，字典管理使用局部 VxeDictionaryTable 替代 ManagementTable 的表体。原因是评估现有 el-table 封装未提供的纵向虚拟滚动及原生列宽拖动能力；不作为其他页面引入新 UI 的默认规则。保留 Element Plus 按钮、提示和编辑弹窗及已有权限操作插槽。

表体高度 480px；超过 50 行开启纵向虚拟滚动，新增序号列和密度切换，列宽允许拖动。现阶段未移植公共表格的列显隐及全屏功能，不表示已完成全局替换。主题采用局部 Vxe 变量映射，语言跟随现有 i18n。

依赖声明在 configuration/package.json；vxe-table 提供表格，vxe-pc-ui 提供其 UI 运行时，xe-utils 提供工具依赖。锁文件已更新。新组件类型检查与 admin 生产构建通过；浏览器视觉和性能实测尚未完成。

## 字体与配色

按用户要求参考 Vben 官方 design-tokens/default.css 的系统字体策略、中性前景/弱化背景/主要操作使用主色的层级。页面与编辑表单采用系统字体栈，中文回退 PingFang SC、Microsoft YaHei，不下载字体；标题 20px/600、分区标题 15px/600、正文 14px、表头 12px/500、辅助说明 13px。字体样式覆盖 Teleport 内编辑表单。

颜色仍从 Element Plus 语义变量派生，选中分类使用 8% 主色与当前背景混合，表头和悬浮使用中性填充混合；保留 success/danger 的业务语义。该局部试验不复制 Vben 固定色值，不替换用户全局主色和主题状态。未完成登录后视觉验收。

## 视口高度

应用壳改用 100dvh，固定/非固定头部模式均在壳内分配剩余高度；普通页面在内部内容容器滚动，避免 body 二次滚动。非固定头部模式改为 flex 容器，导航固定保留在视口内。字典样板逐层传递 min-height:0 和 flex，分类与表体独立滚动；Vxe 表体取消固定 480px，使用 auto 自适应。窄屏筛选区最多占内容区 45%，超出可内部滚动，防止表体被挤出。

本次要求指页面级滚动条，不隐藏表格及长表单必要的内部滚动入口。类型检查通过；浏览器视口验证尚未完成。

### 高度反馈修正

此前 Vxe height=auto 与包含工具栏的父容器互相参与高度计算，存在持续扩展风险。改为独立的 flex 剩余空间容器，表格绝对定位并使用 height=100%，使表格尺寸不再反向撑高父容器；固定头部模式同时约束 scrollbar view 高度及 min-height。模块类型检查和生产构建通过，浏览器验证因会话过期停在登录页，尚未完成持续高度采样。
