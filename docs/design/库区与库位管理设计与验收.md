# 库区与库位管理

## 业务与页面

用户已确认固定三层关系：仓库 → 库区 → 库位。入口为主数据下的“库区与库位”，路由 `/master-data/storage`；仓库档案继续在原仓库页面维护。

同一工作区提供仓库、库区分页检索与“库区管理／库位管理”切换。库区查询限定当前仓库，库位查询限定当前库区；没有选定直属上级时不查询全租户记录，新增按钮禁用。切换仓库清空旧库区和库位范围。父级目录每页20条，有真实分页，不截断大型目录。筛选重置保留父级。

复用现有 Management、BusinessWorkspace、ManagementTable、ManagedDialog、RecordAuditDetails、AppPagination、FloatingError 与 Element Plus Select/Tabs。StorageManagement 仅为页面组合，没有新增基础UI组件或独立视觉体系；其职责是处理跨对象父级选择、分页和上下文清理，现有单对象 Management 通过可选父级上下文和导航插槽复用。

## 对象、字段与约束

两个独立主数据对象为 StorageArea、StorageLocation，分别声明 list、create、update、setStatus。权限资源分别为 `masterdata.storagearea`、`masterdata.storagelocation`；动作 read、create、update、set_status 独立授权。

| 字段 | 约束 |
| --- | --- |
| code | 必填，1–64个ASCII字母、数字、点、下划线或短横线，首位字母或数字；租户内同类唯一，创建后不可修改 |
| name | 必填，去除首尾空白后1–200字符 |
| parentCode | 必填，库区引用仓库编码，库位引用库区编码；创建后不可修改，禁止隐式迁移子树 |
| areaType | 仅库区提供；可不指定，收货区、作业区、良品区、次品区、包材区、虚拟区、成品区对应固定英文业务码 |
| capacity | 单位吨，可空表示未记录；非负十进制，最多18位整数、6位小数，以字符串传输避免浮点损失 |
| remarks | 可空，最多500字符 |
| enabled | 新建默认启用；启停使用独立权限与确认，不混入编辑输入 |
| version | 初始0，成功修改或启停递增1；旧版本409，失败不推进审计 |
| audit | 可信账号、数据库UTC微秒时间；详情只读，不进入提交契约 |

后端每次复核可信租户成员和独立权限。父级引用用 `(tenant_id,parent_code)` 复合外键限定同一租户，前端隐藏不能替代后端校验。新增必须引用启用父级；启用下级必须先启用父级。上级仍有启用下级时停用返回 `STORAGE_ACTIVE_CHILDREN`，要求先停用下级。锁定直属父行与当前行，使创建/启停并发串行；父级不可修改避免并发重挂载。

归属无法访问或不存在均按相同失败处理，不暴露其他租户存在性。编辑停用父级下的历史资料允许保留原归属，重新启用仍须检查父级。没有删除或库存迁移功能。

## 接入与迁移

V118 创建 `md_storage_area`、`md_storage_location`，首次 CREATE TABLE 即包含 created_by、created_at、updated_by、updated_at，账号列BINARY(16)、时间列TIMESTAMP(6)，全部中文列注释。复用原服务事务写入可信账号和数据库时间；创建信息不被更新覆盖。

迁移新增8项独立权限、租户管理员角色及授权快照关系、导航菜单与两个对象的资源映射；普通角色不自动获得权限。新租户沿用现有租户管理员初始化器读取权限目录。父级选择还需仓库读取权限，维护库位还需库区读取权限，不提供免授权目录。

严格JSON公开入口说明（`frontend/modules/master-data/package.json`）：新增 `exports["./storage"]` 指向 `./src/StorageManagement.vue`，供应用壳经公开包入口装配页面；无新增环境变量、端口或部署配置。
