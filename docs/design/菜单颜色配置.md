# 菜单颜色配置

应用壳设置面板新增“菜单颜色”，复用 vue-pure-admin 的 ReSegmented 与 responsive-storage，不新增组件。适用于纵向、横向、混合导航及菜单浮层；不修改业务工作区、权限或接口。

| 参数 | 缺省值 | 说明 |
|---|---|---|
| configure.menuColor | auto | 本地展示偏好，无单位、非必填；auto 跟随全站浅色/深色/系统主题，light 固定浅色菜单，dark 固定深色菜单。即时生效，刷新后保留；旧缓存缺失时按 auto 处理。只改变应用壳导航，不改变 Element Plus 主色，无凭据或安全配置影响。 |

实现通过 data-menu-color 覆盖模板已有导航 CSS 变量；深色页面的导航背景同样引用这些变量，避免覆盖独立菜单选择。中英文使用现有语言资源。
