# 打印场景与模板匹配规则

日期：2026-11-11。状态：已确认产品方向，待实现；本文不表示现有接口已支持规则匹配或输出策略。

## 1. 场景定位

保留场景配置，作为稳定的业务打印入口。同一场景支持按业务条件适配不同打印模板，未来承载默认设备、输出方式及允许调用方覆盖的规则。业务调用方提交场景编码和已授权业务数据，由服务端解析最终打印方案。

当前实现为场景绑定单一模板、数据契约、默认份数和启用状态；默认份数仅在人员打印页面初始化，外部调用仍必填。场景标识维护已补充：列表展示并复制编码，展开详情及编辑弹窗只读展示并复制 ID；编码创建时可填写，保存后前后端禁止修改。多模板匹配、默认设备、默认输出方式及覆盖权限尚未实现，不在页面提供无效配置入口。

## 2. 同场景多模板

场景由稳定编码、名称、独立的数据契约、默认模板、启用状态和模板规则组成。模板规则包含名称、启用状态、优先级、匹配条件和目标模板。场景数据契约不随规则目标模板切换，所有候选模板的发布契约必须与场景契约一致；不同契约应建立不同场景，后续如需字段转换另行设计。

例如“出库单”场景可配置：客户编码属于指定集合时使用客户专用模板，业务类型为调拨时使用调拨模板，其他情况使用默认出库模板。客户、业务类型等字段必须已经注册在场景契约中；示例不表示当前内置契约已有这些字段。

| 参数 | 约定 |
| --- | --- |
| 场景编码 | 必填，在租户内唯一；作为业务集成稳定标识，创建时可填写，保存后不可修改 |
| 数据契约 | 必填，无默认值；场景的输入边界，默认模板及规则模板均须兼容 |
| 默认模板 | 必填，无默认值；未命中任何启用规则时使用，必须为本租户启用且已发布的模板 |
| 规则名称 | 必填，无默认值；用于配置识别和匹配结果解释 |
| 优先级 | 正整数，无单位；数值越小越先匹配，新增默认排在最后；同场景内不可重复，禁止依赖数据库返回顺序 |
| 规则启用状态 | 新建默认关闭；关闭的规则不参与匹配，保存前明确展示状态 |
| 匹配条件 | 启用规则必填；首版仅支持契约顶层文本字段的等于、属于集合，同一规则条件全部满足才命中；缺失字段不匹配，按原文本精确比较，不隐式转换数字或日期 |
| 目标模板 | 必填，无默认值；只允许本租户启用、已发布且契约一致的模板 |

服务端先校验租户、场景启用状态、调用权限及数据契约，再按优先级选择第一条匹配规则；没有命中时选择默认模板。命中规则后目标模板失效应明确报错，不能悄悄改用其他模板造成单据格式错误。配置保存和任务提交时均需验证模板可用性。

条件使用结构化白名单，不接受 JavaScript、SQL、任意表达式、网络数据源或任意字段路径。人员入口从本人可访问的服务端单据取值；外部入口按已有专用权限和契约校验提交快照，规则不扩大调用方的业务数据权限。

## 3. 后续输出策略边界

未来在场景层引入默认设备、默认输出方式、默认份数和按参数声明的覆盖权限；模板规则首版只选择模板，避免同时引入多层策略覆盖。

| 后续参数 | 目标约定 |
| --- | --- |
| 默认设备 | 可缺省；仅允许本租户已授权启用设备；实体打印最终无有效设备时明确报错，不擅自选择第一台设备 |
| 默认输出方式 | 新场景建议默认 PREVIEW，需实现时显式配置；SILENT 直接实体打印，PREVIEW 需确认，PDF 仅导出，接口枚举调整需同步兼容设计 |
| 默认份数 | 整数 1—99，单位为份，默认 1；后续统一由服务端解析，预览文件仍生成一份 |
| 允许覆盖项 | 默认不允许覆盖；分别声明设备、输出方式、份数的覆盖权限，调用方传入禁止覆盖的参数应明确拒绝 |

上述为待实现的目标语义，不改变当前外部接口必填 mode/copies 等约定。模板选择由服务端规则负责，调用方不得通过任意 templateId 绕过匹配。预览确认阶段也必须重新检查设备授权并遵守覆盖策略。

## 4. 快照、并发与追溯

创建请求时固定场景配置版本、命中规则及其版本、实际模板发布版本、业务数据快照和最终输出参数。任务详情应能说明选择了哪个模板、命中了哪条规则，或是否使用默认模板。

重复幂等请求返回原有解析结果；场景或规则更新后不能重新匹配已有请求。预览确认使用已固定的模板和数据，不按最新规则重新生成另一种单据。场景、规则编辑使用版本冲突校验，保存配置不改变已创建任务。

## 5. 配置界面与交付边界

场景列表采用标准列表，场景编辑复用 ManagedDialog 和 Element Plus 表单、表格，在同一场景内维护基础信息、默认模板及模板规则；规则支持新增、编辑、启停和调整优先级。沿用 vue-pure-admin 主题、国际化和状态反馈，无需新增 UI 库或自定义规则引擎组件。

提供不创建打印任务的规则试匹配能力，使用符合契约的数据展示命中规则、所选模板及默认回退结果；不能以试匹配入口绕过单据数据授权。

实施时将现有场景模板迁移为默认模板，已有场景无规则时保持原有模板选择行为。验收覆盖多规则优先级、未命中回退、缺失字段、规则关闭、契约不一致、模板失效、租户隔离、配置冲突、幂等重放及预览确认快照稳定性。未来输出策略独立验收，不将设计预留描述为已交付功能。
