## 技术与参数

就绪检查只授权租户管理人员；数据源不可用明确失败，不把错误当离线成功。渲染在线阈值沿用既有 120 秒，来自队列心跳，仅为瞬时提示，不保证下一次一定成功。工作台必须以发布配置为准，编辑草稿不改变检查目标。

PDF.js 本地 Worker 仅渲染认证下载内容，不装配脚本执行或第三方数据传输；单文件最大 20 MiB、最多 100 页，避免预览无界资源消耗；渲染失败可重新读取文件重试。只使用现有 Element Plus Alert/Tag/Table，无新 UI 体系。

客户端源脚本更新后需使用更新后的下载包；现有正在运行的客户端不被自动重启或换绑。本批不自动授予权限、不修改用户已发布策略，不为验证再次实体出纸。

## 验证原则

真实数据库回归覆盖三/四天分支、拒绝、撤回、重提、幂等、跨租户及任务权限失效；新增就绪、可用性及时间线授权断言。打印测试模拟心跳超时和恢复，使用真实表和正式服务，不伪造实体设备完成。

新增输出阶段单元测试保证 PREVIEW_READY、DEVICE_SUBMITTED 和物理完成不混淆。客户端身份使用真实 OAuth Token 端点验证固定租户与专用 scope；PowerShell 脚本进行语法检查。人工未重做的分支不能标为浏览器验收通过，自动测试与人工证据分别记录。
