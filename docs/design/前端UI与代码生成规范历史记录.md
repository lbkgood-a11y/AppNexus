## 全局字体及配色调整（用户明确指定）

全站字体和配色改为参考 Vben 官方设计 Token 的系统字体和中性色；布局、交互及组件继续使用 vue-pure-admin / Element Plus。此项覆盖本文先前对字体与配色须完全沿用模板的限制。全局入口为 apps/admin/src/style/index.scss，reset.scss 引用 --app-font-family。浅色页面灰底白面，深色为中性灰，侧栏不再跟随模板彩色背景预设；用户主题主色、灰色及色弱模式保留。默认 EpThemeColor 为 #006BE6，仅缺省偏好用户自动采用，已有偏好不强制覆盖。

参考：https://github.com/vbenjs/vue-vben-admin/tree/main/packages/@core/base/design/src/design-tokens 。本次生产构建检查不替代实际页面、深浅色及响应式验收。

### 表格工具顺序

全站列表工具栏从左到右统一为：业务操作 → 刷新 → 密度 → 列设置 → 最大化/还原。公共 ManagementTable 与字典 Vxe 适配遵守同一顺序、图标及国际化文案。列设置提供显隐、重置、上下移动/拖动排序及左右固定；至少保留一个业务列。列设置仅是展示偏好，不能替代服务端字段授权，不跨账号/租户持久化。

### 页面横幅显示偏好

系统设置 → 界面显示 → 隐藏页面横幅，默认关闭（显示横幅），由模板 configure.hidePageBanner 持久化到现有展示偏好存储；不影响会话、安全及业务数据。业务纯展示横幅使用 data-page-banner 标记，目前字典标题横幅已接入。禁止标记含导航、查询、必需操作的区域，以免隐藏功能。隐藏后横幅容器不占高度，下方表体自动重新分配空间。不强行隐藏所有 PageHeader，避免连带隐藏操作按钮。应用类型检查和生产构建通过；开关浏览器交互尚未验收。

### 字典样板推广为公共业务视觉

全站业务页面以当前字典样板为视觉基准：20px 标题、13px 辅助说明、中性表面、主题色轻装饰、8px 卡片圆角、紧凑表格和分页。公共 BusinessWorkspace 自动展示可隐藏的纯展示标题横幅；TreeListTemplate 默认树宽 220px，导航插槽仍由调用方控制。PageHeader 仅标题文案可隐藏，操作区及面包屑保留。

公共 ManagementTable 默认小密度、横向行分隔、12px 卡片留白，工具顺序仍为业务操作/刷新/密度/列设置/最大化。ManagedDialog 统一标题、正文和页脚密度。业务直接使用 Element Plus 的页面通过全局语义样式统一表格、卡片和表单文字；流程设计器、打印画布等保留专用布局，不强行生成列表壳。全站表格统一切换为 VxeTable：普通管理列表复用 ManagementTable，弹窗、展开行和可编辑明细通过 @appnexus/ui 公开入口使用 VxeTable/VxeColumn；保留 Element Plus 表单和按钮，不改变请求、权限或分页契约。

验证：admin 完整类型检查、生产构建通过。尚未完成全部页面的逐页浏览器验收，不能视为所有页面视觉及交互均已验收。

### 圆角与分类宽度 Token

--app-card-radius 默认 8px，公共卡片与字典卡片统一引用；--app-section-gap 默认 12px，公共页面区块引用；--app-category-width 默认 220px，TreeListTemplate 缺省引用，显式 treeWidth 仍限制 220–360px。单位均为 px，定义于 admin/src/style/index.scss。字典不再显式指定分类宽度。控件圆角保持 --app-control-radius，不等同于卡片圆角。

应用壳统一视口高度，但普通页面目前仍采用内容区滚动；字典额外适配了分类/表体独立滚动。该差异尚未完成全局迁移，不应宣称所有页面高度行为一致。

### 公共管理页剩余高度布局

应用内容区中的 BusinessWorkspace、TreeListTemplate、StandardListTemplate 统一传递 flex/min-height:0。横幅、导航、工具栏和分页不伸缩；分类独立滚动，数据区占剩余高度，ManagementTable 通过 ResizeObserver 测量分配后的表体高度。限制只作用于 viewport-page-host 内，弹窗中的表格仍按内容高度布局。查询及反馈区域超高时可内部滚动，不隐藏内容。非标准页面、设计器与画布保留原布局；未经逐页浏览器验证不视为已完成全站验收。

区块间距修正：BusinessWorkspace 横幅、导航、反馈、查询和数据表面使用统一 --app-section-gap 分隔，不再以相邻上下 padding 累加代替区块间距。独立树模板横幅与内容区同样引用该变量；字典样板删除摘要区 14/20px 固定外边距，并修正局部 padding 覆盖。卡片网格及仪表盘也统一区块 gap；字段间距和操作按钮间距不属于区块间距，不强行等同。构建通过，尚未完成本轮全站视觉验收。

### 查询操作按钮间距

查询与重置按钮统一使用 8px 间距，由公共 management.css 管理。按钮组使用 management-filter-actions；若按钮组为 el-form-item，内部 el-form-item__content 同样使用 8px gap，并清除 Element Plus 相邻按钮默认 margin，避免间距叠加或按钮贴合。本轮为 CSS 修正，尚未完成浏览器逐页验收。

### 静态说明的统一入口

静态使用说明、能力边界及字段解释统一复用 @appnexus/ui 的 InfoHint，默认仅显示 information 图标，点击或键盘激活后通过 Element Plus Popover 阅读，移动端同样点击查看。错误、警告、成功结果以及含补救操作的动态提示保留 Alert。现有 Element Plus Popover 提供弹层能力，但各页面独立组合无法保证触发方式与窄屏宽度一致，因此以最小公共组合组件统一；已用于授权、对象目录、菜单、租户、工作流和打印说明。文案继续使用原国际化资源，不改变权限或接口行为。尚未完成逐页浏览器验收。

### 查询区折叠统一入口

BusinessWorkspace、TreeListTemplate、StandardListTemplate 的 search 插槽统一由内部 SearchPanel 包装，默认展开，右上角提供收起/展开按钮；收起使用 v-show 保留表单实例，不清空条件、不触发请求。角色及租户页面移除重复的局部折叠入口。已有模板未提供通用查询折叠容器，因此以 Element Plus Button/CollapseTransition 最小组合实现，避免页面各自维护。按钮使用既有国际化及 AppIcon，aria-expanded/aria-controls 表达状态与目标。

查询区标题由 SearchPanel 的固定标题行统一呈现，左标题、右折叠图标；收起后仍保留标题。BusinessWorkspace/TreeListTemplate 缺省使用业务名称生成查询标题，searchTitle 可指定已有业务文案，未提供业务名称的独立模板使用“查询条件”。页面不重复渲染同义查询标题，对象上下文名称与操作仍保留在表单内容区。

### 公共分页入口

业务分页统一使用 @appnexus/ui 的 AppPagination，复用 Element Plus，默认小尺寸、右对齐并显示真实总数。支持容量切换的列表默认提供 20/50/100 条；固定容量接口不显示容量选择。ManagementTable 未提供分页插槽且持有完整平面数据时自动本地分页，每页默认 20 条；树及显式展开列表保持完整层级，服务端分页继续由调用方提供总数与请求。此封装用于消除各页面分页配置分歧，不新增 UI 库。类型检查通过；逐页浏览器交互仍待验证。

### 全局标题标记与横向页签

查询标题 management-filter-title 和表格标题 management-table-title 统一使用 4px × 18px 的主题色竖条，颜色引用 --el-color-primary，标题间距 8px。公共 management.css 负责维护，业务页面不重复添加。

横向页签沿用流程工作台的 44px 标题高度、选中加粗和 Element Plus 原生活动条；普通线条页签移除重复底线，保留窄屏滚动及内容区域。卡片页签保留其原生边框，纵向导航不受影响。公共工作区与树模板同步高度；不更改页签切换、请求或权限契约。本轮类型检查通过，尚未逐页完成浏览器视觉验收。

组织结构页采用与业务字典相近的左树右表模板：沿用默认分类宽度、12px 区块间距、紧凑树节点及主题色选中态；保留组织上下文操作与岗位/任职双表，不将层级数据改成平面分类。双表区域可滚动，分页栏不收缩；AppPagination 尊重显式 layout，未传入时仍按是否绑定容量更新事件决定是否显示 sizes。类型检查通过，浏览器主题、窄屏与分页交互尚待验收。

### 全页面间距补齐与截图反馈（2026-11-16）

本节覆盖前文关于 main-content 外边距 12px、公共内容 padding 12px 和字典独立双表面的旧描述。范围包含所有路由页面，不能仅调整公共组件后将局部覆盖页面视为已完成。

| 参数 | 当前缺省值 | 用途及影响 |
|---|---|---|
| --app-page-gap | 8px | 所有路由内容外边距；与视口剩余高度计算联动，避免底部保留旧的 24px 高度扣减。 |
