# 第一期交付范围与验收基线

版本：1.0；日期：2026-11-06；状态：已确认。

## 1. 目标

第一期交付可运行、可验证的平台底座，不交付 SCM、WMS、巡库等业务系统。预留契约和扩展点不等同于已完成功能。

## 2. 工程底座

交付 Maven 多模块后端、pnpm workspace 前端、Spring Boot/MyBatis/Flyway/Valkey、统一错误与校验、OpenAPI、结构化日志/追踪标识、Testcontainers 及架构测试。

验收：

- 前后端可一条命令构建，CI 可运行单元、集成、架构和契约测试。
- 未声明权限的 Controller/Mapper 不能通过构建或启动校验。
- A/B 租户在 CRUD、分页、计数、联表和异步任务中不互相泄漏。

## 3. 认证与会话

交付本地账号密码，Web BFF 会话/Cookie/CSRF，移动端 Authorization Code + PKCE，外部集成 Client Credentials，TOTP/恢复码/step-up，密码找回，会话/设备管理，注销/撤销/强制下线，租户选择/切换，以及一个企业 OIDC 身份源 PoC。

验收：

- 账号、成员或租户停用后访问按已确认边界及时失效。
- 移动端 Refresh Token 重放可检测并撤销设备会话；Web Token 不进入浏览器 JavaScript 存储。
- 密码模式和 Implicit Flow 不可用；认证日志不泄露密码、Token 或恢复码。

## 4. 租户管理

交付租户创建/编辑/启停，首位管理员，成员邀请/激活/禁用/移除/重新加入，系统/功能开通配置及最后有效管理员保护。

验收：

- 同账号在同租户仅有一个成员身份；移除保留历史，重新加入复用成员标识。
- 租户停用阻断新请求和后台任务；开通范围约束下层授权。
- 并发操作不能导致租户没有有效管理员。

## 5. 组织、岗位与任职

交付组织类型/独立类型树、组织单元/关系、岗位、任职、负责人，以及移动/停用/影响检查。只交付后续审批选人所需的组织查询契约，不交付完整工作流服务。

验收：

- 组织编码租户内唯一；移动不能跨租户、跨类型或形成循环。
- 岗位归属组织；一人可多岗，同岗可多人。
- 离岗后不再被新的岗位/组织负责人选人规则命中。

## 6. 角色与权限

交付角色、授权记录、授权委派、强制限制、策略模板、`AccessPlan`、行/字段/单元格/脱敏权限、权限预览、版本及缓存失效。完成 A 级单表和 B 级固定联表；C 级复杂聚合只交付一个安全验证样例，不交付通用报表平台。

验收：

- 租户边界不可绕过，多条授权不跨授权拼接，强制限制优先。
- 无权原值不返回前端；查看、编辑、查询、排序、导出和打印相互独立。
- 安全收紧对新请求立即生效；Valkey 故障受限回源，无法验证时拒绝。

## 7. 配置、国际化与审计

交付简体中文/英文，语言/时区/日期/数字/金额格式，租户字典/参数，登录/登出/安全/操作审计、受权查询/脱敏及 `traceId` 关联。汇率折算只交付契约与历史依据模型，不交付完整汇率服务。

验收：

- 展示偏好不修改业务日期/金额结果；翻译缺失统一回退。
- 审计查询不跨租户，不保存密码、Token 或敏感原值，并可与技术日志关联。

## 8. API 与集成底座

交付 `openapi-app.yaml`、`openapi-partner-v1.yaml`、`openapi-platform.yaml`、命名 lint、破坏性变更检查、集成客户端、幂等、限流与调用审计。

验收：

- 外部契约不泄露内部字段；重复写入不重复产生业务效果。
- 客户端停用/授权版本变化后旧 Token 被拒绝；各 API 接口面不互相越权。

## 9. 可靠事件与后台任务

交付共享库 Outbox、多实例租约领取、消费幂等、分类重试/人工处理、权限失效事件与基础后台任务框架。

验收：

- 事务回滚不产生可消费事件，重复投递不重复修改状态，租户事件不跨租户处理。
- Worker 崩溃后租约可恢复，超过阈值转人工处理而不静默丢失。

## 10. 不进入第一期

- SCM、WMS、巡库等业务系统。
- 完整工作流服务/工作台、单据中心、业务编排、通用报表/打印、多渠道消息中心和完整主数据平台。
- API Gateway、注册中心、配置中心和消息队列。
- SAML、SCIM、passkey 产品化、社交登录、通用搜索平台、微前端与多地域容灾。
- 单租户恢复工具的完整产品化；但必须明确其风险和后续接口边界。

## 11. 实施顺序

1. 技术 PoC：认证、共享表租户/权限 SQL、字段策略与 Outbox。
2. 工程骨架与 CI。
3. 账号、会话、租户与成员。
4. 组织、岗位与任职。
5. 角色、授权与权限管线。
6. 国际化、配置与审计。
7. 第一方/外部 API 联调。
8. 安全、容量、迁移与故障验收。
