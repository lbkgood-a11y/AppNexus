# 外部打印接口与统一预览

外部客户端在租户集成客户端中选择“外部打印调用”，仅授权 `print:submit`。OAuth Token 使用 Client Credentials + HTTP Basic 获取，不能用打印代理的 `print-agent:operate` 代替。租户固定来自凭据，接口正文不接受租户 ID。外部系统负责其业务数据授权，服务端按场景契约白名单校验快照，不执行 SQL、URL 数据源或脚本。

## 调用

`POST /api/printing/external/outputs`，Headers 使用 `Authorization: Bearer <access-token>`、`Idempotency-Key: <UUID>`、`Content-Type: application/json`。凭据和 Token 不写入 URL、日志或前端持久存储。

```json
{
  "sceneCode": "outbound",
  "sourceId": "OUT-001",
  "data": {"documentNumber": "OUT-001", "items": [{"itemName": "物料", "quantity": "2"}]},
  "mode": "PREVIEW",
  "deviceId": null,
  "copies": 1
}
```

| 参数 | 中文说明 |
| --- | --- |
| sceneCode | 当前租户启用场景编码，必填，无默认值；模板和契约由场景确定 |
| sourceId | 外部单据标识，1—128 字符，必填；不是授权查询入口 |
| data | 已授权快照，字段必须属于契约；文本最多 2000 字符，明细最多 500 行 |
| mode | 必填，SILENT 直接入设备队列；PREVIEW 只生成 PDF，确认前不会出纸 |
| deviceId | 当前租户启用设备 UUID；SILENT 必填，PREVIEW 可在确认时选定 |
| copies | 必填，整数 1—99；预览 PDF 固定一份，确认打印时使用此份数 |

响应包含 `id`、`jobId`、`mode`、`state`、`pdfReady`、`confirmedJobId` 和 `previewUrl`。异步生成仍需要在线渲染代理。

- `GET /api/printing/external/outputs/{id}`：当前调用客户端的请求状态。
- `GET /api/printing/external/outputs/{id}/pdf`：认证读取预览 PDF，未完成返回 404；不提供公开文件链接。
- `POST /api/printing/external/outputs/{id}/confirm`：JSON `{"deviceId":"设备UUID"}`，携带幂等 UUID；请求行锁与唯一确认任务防止重复出纸。

同幂等键同参数返回原请求，同键异参返回 409。外部客户端只访问自己的请求，不能管理场景、设备、模板或领取代理任务。网页预览地址要求用户登录当前租户并具有任务读取权限，确认另需任务提交权限。不可将预览 URL 当作免登录分享链接。

## 统一界面

人员录入入口通过 `/api/printing/documents/{id}/outputs` 提交，仅传 `mode/deviceId/copies`，快照读取自本人服务端单据。人员查询、PDF 和确认使用 `/api/printing/outputs/{id}` 对应路径。网页 `/#/print/management?output=<请求UUID>` 与业务入口共用 PrintPreview，显示生成状态、认证 PDF、选机及“确认打印”。关闭预览不会自动打印。静默模式不会打开预览窗口。

模板发布版本和数据快照在初始任务固定；确认打印复制同一快照，不重新读取变化的单据。当前代理会按同一引擎渲染固定快照，不保证升级渲染引擎后的像素完全一致；设备驱动缩放和物理边距仍需实际设备验证。

验证记录（2026-11-11）：本机后端已部署并执行 V56。真实 MySQL/Valkey 隔离测试共 7 项通过（PrintingRuntimeTest 与 IntegrationClientTest），覆盖静默/预览、未完成禁止确认、同键异参、重复确认去重、请求归属与 Token scope 隔离；前端类型检查、打印模块 14 项测试和生产构建通过。本轮未取得登录后预览窗口的浏览器视觉验收和实体打印证据，不将自动化结果描述为生产验收完成。
