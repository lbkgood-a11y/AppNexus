# 六边形职责改造第二批执行记录

日期：2026-11-19。状态：实现与验证中。范围是商品单位换算、工作流模型校验、打印代理回执及平台业务对象租户目录桥接；不代表商品全聚合、全部工作流或打印运行时已经完成分层。

## 1. 用例归属与真实实现

| 用例 | 公开入口与应用 | 领域与输出适配 | 事务及授权 |
|---|---|---|---|
| 单位换算列表、新增、启停、计算 | api.product.UnitConversions；application.product.ProductUnitConversionService | domain.product.UnitConversionRules；UnitConversionStore；JdbcUnitConversionStore；MasterDataConfiguration 装配 | 每次实际功能授权，可信租户条件；两端单位按 UUID 顺序锁定；反向往返校验、CAS 与四审计保持原事务 |
| 工作流草稿及发布前模型校验 | workflow.application.WorkflowModelValidation | 原 WorkflowValidator、WorkflowCondition；运行时提供已授权能力和代码生成业务视图 | 纯只读，不创建部署或任务；保存、发布仍由原事务执行器处理，不把校验成功当授权 |
| 打印代理回执 | printing.application.PrintReceiptService | core.PrintJobLifecycle；PrintReceiptStore；JdbcPrintReceiptStore | 原 PrintRuntime.receipt 作为 Spring 事务入站装饰器，锁、JSON 结构一致性核验及状态写入同事务；应用复核权限与原领取代理 |
| 业务对象桥接的租户存在性 | tenant.TenantDirectory | MyBatisTenantDirectory、TenantAccessMapper | 只供已授权配置用例读取；只检查存在，与租户启用及成员权限分开判定；安全桥接不再直接使用 JDBC |

单位换算公开 JSON、URL、结果及错误码保持，原技术构造器删除，生产与真实数据库测试统一使用组合装配入口。固定 SQL 从原实现迁移，启用时读取两端单位使用含维度的同一行锁查询，不改变按 UUID 加锁顺序。系数存储异常仍在适配器转换为原冲突码；不接受 SQL、表名或客户端审计参数。

打印回执仍先授权，再解析标识与状态，再延迟校验结果 JSON，最后锁定任务；幂等必须同代理且 JSON 结构一致。未知或已经送入队列的结果不能退回可安全自动重印的失败状态。公开 PrintRejection 在技术入口转换为原 PrintFailure，保持现有 HTTP 错误映射。原代理领取、PDF 上传及产物下载尚未迁移。

工作流校验应用位于现有 workflow-core Maven 工程中的独立 application 包，纯 core 包不反向依赖它；未增加空 Maven 层。能力输入输出白名单、本业务 NUMBER 字段、审批终态和撤回绑定校验从原运行时整体提取，保持错误顺序及代码目录来源。
