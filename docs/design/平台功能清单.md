# 平台功能清单

采用 BusinessWorkspace + ManagementTable 树形表格，不分页拆散父子关系，不新增视觉体系。路由 /platform/features，读取需 configuration.menu:read 与平台管理权，不提供编辑代码定义入口。

## 两种视图

按页面查看：管理域 → 页面 → 操作。按业务对象查看：真实对象 → 操作，显示对象分类、模块、操作编码/ID、权限要求、真实方法/路径、附加业务约束。对象包括账号、租户、成员、组织类型/单元、岗位、任职、字典、打印模板/场景/设备、流程定义/实例/任务等；不能以控制器名称推断。

页面数据来自 /bff/platform/menus/features（NavigationPages），操作来自 /bff/platform/operation-catalog（MVC + OperationBinding/Provider），完整对象来自 /bff/platform/object-catalog（唯一对象声明与 Provider）。与数据库菜单组织和用户有效授权分开；修改角色不会改变构建目录。

支持中英文、关键字、管理域筛选、全部展开/收起、刷新及公共表格工具。查询匹配保留祖先；失败清除旧目录并显示错误。动态树行使用稳定唯一 ID，列宽调整只影响当前展示，不持久化权限或字段偏好。

业务对象目录 /platform/business-objects 只管理已声明审批/打印等配置能力的 Provider 对象；不把所有系统对象都变成可配置审批对象。完整登记统一在功能清单查看，配置页面有明确范围说明。注册不等于用户获权，也不代表具体对象状态可执行。

启动校验拒绝未登记对象、重复权威、未知页面、不完整权限和错误 ID。页面对象筛选、动态控件、管理员正向/普通用户反向与主题/响应式证据见《架构重构查缺补漏审查》。
