# 菜单图标选择器

菜单新建与编辑通过应用壳插槽接入现有 ReIcon/IconSelect，领域模块不深层导入模板组件。复用模板的 Popover、Input、分页和图标网格，改用 Element Plus Button 提供键盘操作，不新增 UI 库或平行组件。

原模板依赖外网 Iconify，且返回冒号名称，与菜单离线渲染使用的斜杠名称不一致。因此选项限制为 offlineIcon.ts 已注册的本地图标，保持现有 Remix Icon 与历史 Element Plus 菜单兼容，不提供导航无法渲染的图标。未知历史名称保留原值，直到用户主动选择或清空。搜索按名称忽略大小写，每页 35 个；搜索重置页码，打开时定位当前值。保存期间禁用交互。

文案接入中英文，边框和选中状态使用 Element Plus 主题，弹层最大宽度限制为视口减 24px。图标选择与清空仅修改草稿，保存仍走原有 API、权限、CSRF 与并发流程。

验收证据：类型检查、构建结果见本次交付说明；真实浏览器的新建/编辑、取消、清空、深浅主题和移动端尚待验证，不以静态检查代替。
