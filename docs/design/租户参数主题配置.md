# 租户参数主题配置

## 使用对象与边界

页面面向当前租户中具有 TenantParameter.save（configuration.parameter:save）准入的管理员。沿用既有菜单 TENANT 管理域、独立权限及真实 PUT 接口；不以平台管理员身份替代租户角色。页面先查操作能力，再读编辑数据，无权显示明确反馈。非敏感参数的既有 GET 接口继续供成员读取展示设置，不改成管理员专属，避免破坏日常使用。

## 组件与信息组织

复用 @appnexus/ui 的 TreeListTemplate 左主题右配置、ManagedDialog 与 RecordAuditDetails，不新增组件或视觉体系。三个固定主题为：区域与显示（币种、时区），列表设置（建议每页条数），地图服务（公开 Web Key、固定安全代理路径）。参数键与默认值继续由后端定义，不支持新增任意配置。

币种使用可搜索 ISO 4217 选项，时区使用可搜索 IANA 标识，每页条数采用 10–100 整数输入，Web Key 为 32 位十六进制或空。代理路径只读。界面展示当前租户，字段说明紧随控件；审计收进只读弹窗，避免 UUID 和记录时间挤占主要配置区。中英文及主题变量沿用现有机制，窄屏复用模板响应式。

## 保存与故障

每个主题统一提供保存和放弃修改，仅提交该主题的改动；切换主题保留其他草稿。原接口逐参数执行乐观锁与 CSRF 校验，不支持批量事务，因此逐项保存，成功项立即更新基线，失败停止后续请求，明确提示部分保存，不伪装成全有或全无。失败保留输入，禁用继续写入并要求重新加载。写入期间占用现有 beginTenantWrite，阻止切换租户。展示格式在成功写入后刷新。

## 验收边界

执行前端类型检查、构建及操作引用检查；真实浏览器的管理员保存、普通成员拒绝、冲突、深浅主题与 390/1024/1440 视口仍需验证，交付说明明确最终执行结果。不用静态检查代替真实安全验收。
