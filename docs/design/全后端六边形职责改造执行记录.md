## 1. 本轮已落地边界

| 业务/工程 | 公开入口 | 应用与领域 | 输出与装配 | 事务与授权 |
|---|---|---|---|---|
| 业务对象配置 | api.BusinessObjectManagement | application.configuration.BusinessObjectService；domain.configuration.ConfigurationRules | ConfigurationStore、ConfigurationTransaction、ConfigurationCodec；adapter.jdbc.configuration；bootstrap.BusinessObjectConfiguration | 配置、发布、幂等解析和追加审计保持原 REQUIRED 事务；对象、平台与租户维护权在应用执行路径复核 |
| 编码协助 | api.CodingManagement；原跨模块 BusinessCoding 契约 | application.coding.CodingService；domain.coding.CodingRules | 原 CodingStore 与 JDBC 实现；编码到配置通过公开输入端口桥接 | 原锁、序列、回执、撤权及规则冻结语义不变；HTTP 不再依赖具体应用类及其嵌套输入类型 |
| HTTP 与声明 | adapter.web；adapter.registration | 不拥有业务状态转换 | bootstrap 装配 Controller、声明及真实用例 | 原 URL、JSON、错误码、可信请求上下文和 CSRF 保持 |
| 系统部署 | applications/monolith-app | 不拥有业务规则 | 原组合源集及配置从平台工程提取，artifactId 为 monolith-app | Java 启动包暂留原位置保持扫描和测试发现；尚未提供微服务独立运行证明 |
| 跨模块架构 | architecture-tests | 检查实际组合生产类 | 原平台架构检查提升到 backend 根级 | 保留旧检查并扩展公开协议、配置输入端口和源码包说明检查 |

配置输出端口按 27 项固定业务记录操作命名，不接收任意 SQL。SQL 文本、参数顺序、锁、版本和异常协议保留；应用仍使用部分原存储快照 Map，后续可进一步类型化，不能将当前端口视为通用数据库执行器。

本轮没有修改数据库迁移、表结构及前端。跨模块本地事务尚未转换为分布式一致性；不提供“换为 HTTP 即完成微服务拆分”的承诺。

## 2. 每包说明与生成约束

为所有实际自有 Java 源包提供中文 package-info.java，包括正式、测试、Java 数据迁移和隔离 PoC；已有工作流核心说明保留并补充。说明包含职责、边界、依赖及实际迁移状态。历史混合包明确保留未完成事实，禁止把旧实现写成标准层。

PackageDocumentationTest 扫描所有 main/test Java 源文件所属包并检查标准 Javadoc；源扫描未命中直接失败。只包含命名路径的父目录不创建空包。说明覆盖不表示架构合规，仍需依赖及业务测试。

| 范围 | 真实现状与后续工作 | 关闭证据 |

### 4.1 本轮实际结果

首轮全量 clean verify 执行到组合应用，应用报告 208 项：3 项断言失败、1 项错误、1 项浏览器专用夹具按条件跳过。其他执行到的模块已完成对应规则、真实 MySQL、工作流及编码测试。该命令最终失败，不能表述为全量 verify 通过；后续模块未执行不能套用旧报告。

四项失败分别为：字典客商夹具缺少必填组织；对象目录测试仍假定组织没有 Provider 管控能力；策略目录仍假定只有组织资源；撤权测试仍删除旧成员范围快照而非角色功能权限。已核对原真实声明与授权执行实现，更新测试准备与契约断言，未放宽生产授权、归属或审计约束。撤权通过正式角色权限用例执行后验证旧 Cookie 创建被拒绝。
