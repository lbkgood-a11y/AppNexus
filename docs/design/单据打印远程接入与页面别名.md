# 单据打印、远程接入与页面别名

日期：2026-11-13。本批为通用能力扩展，不新增订单/合同业务，也不把数据或业务执行集中到单据服务。

## 打印

Action.interaction 声明 PRINT/CONFIRMATION 并提供 reference 及 fields；打印行为的 Binding 保存 sceneCode，不能夹带审批流程。工作台按当前租户和该投影契约查询真实启用场景与兼容发布模板，保存/发布再次校验；V65 为解析记录增加场景和契约字段。PRINT 解析不创建任务。

新增 BusinessPrinting 公开 Java 端口，场景查询与打印请求由打印适配器实现，复用 PrintOutputs 的快照、幂等、预览和任务机制。业务服务授权取数后提交 Request，打印再次校验操作权限、场景归属、投影契约及数据 Schema。不提供浏览器任意业务 JSON 入口。没有真实打印提供器或兼容场景的单据不伪造可用打印按钮。

## 多页面别名

请假单提供实际业务样例：登记 leave.request.v1 打印字段目录，列表 LeaveRequest.print 和详情 LeaveRequest.detail.print 共享 print 动作。本人原文访问及 print.job:submit 权限都成立后，业务生成不含请假原因和申请人敏感信息的投影，只请求 PREVIEW。管理员先用该目录建立真实模板/场景，再发布绑定；未配置时明确失败，不生成演示模板。模板数据接口通过装配层 PrintDataContractProvider 读取统一交互契约的字段投影，业务不独立登记另一份目录，打印实现不依赖请假模块。

Action 保留唯一 actionCode 和规范 operationKey，增加 OperationAlias 列表。列表页、详情页等入口可登记不同 operationKey 和真实 PageOperation，工作台均可选择；业务服务统一调用同一 actionCode 解析配置。别名不新增权限，不增加处理器，也不创建另一套业务状态。

同一行为的策略仍统一匹配，不能为两个别名各保存一条全匹配策略导致重复命中。别名仅用于声明、展示和接入追溯，不能改变同一动作的业务语义；需要不同处理时应登记不同动作。未知或重复别名阻止声明激活/保存。

## 远程 SDK 与认证

新增 document-client JAR，使用 JDK HttpClient 和公开契约，支持服务端绑定解析和现有外部打印提交。详细参数与接入步骤见 backend/contracts/document-client/README.md。

新增 document:resolve 专用 OAuth scope，复用现有 client_credentials、固定租户、短期不透明 Token 和即时撤销；只有精确的 POST /api/documents/integration/resolutions 允许该主体调用。服务端不接受客户端传入账号/租户声明，不将服务身份冒充人员，不开放配置管理权限。集成服务被授予可信供数权限，必须在其业务入口验证最终用户和单据；授予 scope 应只给受信业务服务。

SDK 不跟随重定向、不自动重试写入，HTTPS 为远程默认要求；Token Supplier 由宿主注入，错误仅包含安全码和状态，不输出原文及密钥。幂等解析保留服务客户端身份，不能换用另一身份将解析引用当凭证。

本批远程协议范围是解析和打印，不宣称远程业务注册、Flowable 原文供数回调、远程审批结果交付或分布式事务恢复完成；已有工作流 Java 接口保持组合部署支持。
