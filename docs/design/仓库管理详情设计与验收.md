## 高德同源安全代理实现（2026-11-17）

固定入口 /api/maps/_AMapService；/configuration 先校验当前租户公开 Web Key 及服务端对应密钥，仅返回公开 key/serviceHost。SDK 的 /v4/map/styles 使用 webapi.amap.com，/v3/vectormap 使用 fmap01.amap.com，其余 /v3、/v4 API 使用 restapi.amap.com；仅 GET，禁止任意域名、点段、编码路径和重定向。全部请求经过真实会话、有效租户成员和 masterdata.warehouse:read 门禁，客户端 key 必须等于当前租户公开参数，客户端 jscode 不予采用。浏览器请求只使用已有 /api 同源反向代理，不新增公网入口。

| 服务端环境变量 | 中文说明 |
|---|---|
| APP_AMAP_SECRET_DIRECTORY | 默认空表示代理未配置；指向静态资源目录以外的安全目录。文件名为32位公开 Web Key，内容为该 Key 对应32位 jscode。不同租户可使用不同 Key 和密钥文件。目录与文件仅服务账号可读；不得提交源码、写入租户参数或日志。修改目录需重启，密钥文件原子替换即时生效；拒绝符号链接和大于256字节文件。 |

本机可使用已忽略目录 .local/amap-secrets；部署管理员以安全文件方式提供密钥，禁止通过聊天或公开示例传递真实值。仅配置 Web Key 不代表配置完成。服务端缺失文件返回 AMAP_PROXY_NOT_CONFIGURED，前端明确提示对应安全密钥缺失。代理路径固定显示 /api/maps/_AMapService，不再要求租户管理员填写任意路径，V94 统一已有旧路径。代理不新建表；无可信主体的迁移允许 updated_by NULL，保留创建信息。

连接超时5秒、每请求超时15秒、单响应上限8MiB、每进程并发上限16，超限429；上游失败返回受控502，禁止返回异常 URL、重定向、Cookie、认证头及含安全密钥的上游响应。代理响应 no-store，禁止透传上游响应头。生产网关应限制请求频率并避免记录出站完整查询串。

代理前缀依据高德 JS API 2.0 官方安全密钥文档保留 _AMapService，不使用任意替代后缀；文档：https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode 。

### 地点查询 JSONP 类型修复

实测官方 /v3/place/text 在 platform=JS 下查询“厦门”返回 OK；带 callback 时正文为 JSONP，但上游 Content-Type 为 application/json。原代理透传类型并带 nosniff 导致浏览器拒绝执行脚本。代理现只允许合法 JavaScript 标识符或点分标识符作为 callback，严格检查响应以该回调加左括号开头、右括号结尾后返回 application/javascript，保留 nosniff。异常回调或包装拒绝，不全局放宽安全头。自动回归覆盖成功 JSONP 类型和非法回调。

查询成功自动将地图缩放到首个候选（12级）并标记，候选列表仍保留，点击候选以16级精细定位；确认和保存语义不变。真实上游探测只输出状态码、返回数量和内容类型，不输出 Key、安全密钥或查询完整 URL。
