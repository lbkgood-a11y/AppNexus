# 待决设计事项

更新日期：2026-11-05

本文仅收录尚未锁定的问题；已确认基线以各专项设计与讨论记录为准。未决参数不影响进入技术 PoC，但未经验证不得锁定为生产默认值。

## 当前讨论：核心领域与聚合

身份认证、租户管理、组织管理、权限管理四个核心领域的聚合划分已确认，分别包含两个、三个、五个、五个聚合。下表列出已确认边界及仍需细化的问题。

| 领域 | 已确认聚合 | 主要待决问题 |
|---|---|---|
| 身份认证（聚合已确认） | 账号、会话 | 全局账号与租户策略边界、认证资料、会话撤销 |
| 租户管理（聚合已确认） | 租户、租户成员、租户开通配置 | 内部结构、成员生命周期、在途任务停用与恢复机制 |
| 组织管理（聚合已确认） | 组织类型、组织单元、组织关系、岗位、任职 | 组织关系约束、事务与并发控制、生命周期详细规则 |
| 权限管理（聚合已确认） | 角色、授权记录、授权委派、强制限制策略、策略模板 | 聚合内部结构、跨聚合一致性、接口及已确认规则的执行机制 |

岗位关系已确认：岗位归属组织，租户成员通过任职关系关联岗位，支持一人多岗、同岗多人，暂不对岗位分类；具体聚合边界、唯一性约束及任职生命周期仍待设计。

账号与租户成员分离、角色授予租户成员已确认。组织节点作为独立聚合、组织领域五个聚合通过标识引用及应用层协调已确认。其他领域的聚合边界及分层结构仍需细化确认。

## 工程与技术

已形成[后端工程详细设计草案](后端工程详细设计.md)。其中提出的具体模块、事务算法和接口机制仍待审阅，不替代已确认基线。

- 第一期一个平台基础应用已确认；各领域 Maven 模块依赖及未来拆分边界待设计。
- 已确认[技术版本与许可证候选基线](技术版本与许可证基线.md)；精确版本仍须通过 PoC 锁定，MySQL 分发方式及实际依赖 SBOM 尚待确认和验证。
- MyBatis、Spring Security、Valkey、Flyway、Outbox、OpenAPI 及结构化日志的选型基线已确认；租户行级隔离、统一权限管线、查询分级、平台作用域与共享库 Outbox 已确认。具体 SQL AST 编译库、低样本阈值、Outbox 批量/租约/重试参数待 PoC 锁定。
- 租户行级隔离在缓存、文件、后台任务、搜索和单租户导入导出中的具体执行机制。
- `AccessPlan` 条件节点、完整授权并集、强制限制收口、条件复杂度上限及默认拒绝原则已确认；具体 JSON Schema、数值上限和查询成本阈值待 PoC 确定。
- 字段能力独立、按命中记录合并、展示级别、强制限制收口、替换值写入、查询推断防护及导出/打印重新决策规则已确认；条件字段投影与 DTO 编码方式待 PoC 锁定。
- 权限版本组成、`PermissionSnapshot`、Valkey 缓存键、版本优先失效、安全收紧再校验、故障回源与默认拒绝已确认；具体 TTL、回源并发和长任务重校验间隔待容量测试锁定。
- 安装升级、备份恢复、容量及可用性目标。
- Integration API 已确认 OAuth 2.0 Client Credentials、双密钥轮换、短 Token、可选 mTLS、幂等、三层限流/额度和调用审计；Token 精确有效期、废弃周期及 API Management 引入批次待运维目标确定。
