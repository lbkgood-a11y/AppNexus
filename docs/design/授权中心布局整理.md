# 授权中心布局整理

日期：2026-11-09。

## 选型与调整

沿用 BusinessWorkspace、ManagementTable、Element Plus Tabs/Form/Select，未新增组件或 UI 库。角色配置属于同一对象编辑，采用上下布局：任务页签、角色上下文、筛选与分组配置、统一授权摘要与保存。原三栏布局使角色选择和摘要长期占用大量宽度，改为顶部角色选择和底部保存区。功能权限按资源分组，桌面使用两至三列，手机单列；已知资源使用业务名称，未知资源保留原标识。功能、默认范围、字段规则继续共享原草稿与原子保存。

主体角色页保留列表与编辑两个任务区，优化列宽、筛选背景与间距；有效权限解释用分隔线与编辑区区分。成员数据权限页将成员、角色选择并排，操作范围横跨内容区，期限和变更原因明确排列；手机单列。

未修改接口、权限规则、角色快照、有效期或草稿确认逻辑。保存失败禁写、角色切换确认、路由离开保护保持原实现。本批没有向真实账号写入授权。
