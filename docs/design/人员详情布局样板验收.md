# 人员详情布局样板验收

日期：2026-11-16。按用户截图优化人员详情，并作为未来主数据/基础数据页面的强制布局样板；具体要求已写入《前端UI与代码生成规范》“主数据与基础数据详情样板”。

实现：复用 TabbedDetailTemplate 增加显式 master-data 模式、content/system 插槽。人员基础与详细信息共用一份 el-form；姓名/编码/状态页头、真实姓名首字摘要、可折叠详细资料、独立只读审计行和原明细页签。折叠仅 v-show，不卸载字段，不绕过版本、权限或校验。公共 templates.css 提供样板类、主题变量和四/二/单列响应式，PersonnelEditor 只保留业务状态提示。新图标 history 复用 Remix Icon time-line 本地 SVG，注册在 @appnexus/icons，不深层引用模板。

未新增后端字段、接口、权限、数据库迁移、模拟生产入口或系统配置。原保存/取消、失败保留输入、CSRF 和租户隔离契约保持。

浏览器布局检查使用临时隔离入口 personnel-layout-preview.html，渲染实际 PersonnelEditor 和公共组件，注入纯示例数据，不请求业务接口、不绕过真实认证或写入开发库。入口在验证后移除，未注册为产品路由，也不随生产入口打包。

- 1440×900：四列表单，独立系统信息和页签；观察截图位于 .local/personnel-layout-desktop.jpg。
- 1024×768：两列，根 scrollWidth 1009，视口宽 1024，无页面横向溢出。
- 390×844：单列，根 scrollWidth 375，视口宽 390，无页面横向溢出；页头按钮自然排列，详细资料折叠按钮命中区不少于 44px。
- 展开/收起：按钮 aria-expanded 和文案正确变化，折叠后没有残留空白正文 padding。
- 英文＋深色：字段、区块标题及审计显示完整，沿用原主题变量；System 继承原主题，未单独操作系统主题切换。

本轮不将隔离视觉验证视为真实管理员/普通用户后端交互验收，不宣称其他存量主数据页面已全部改版。检查日志为 .local/personnel-layout-*.log；最终结果见追加记录。
