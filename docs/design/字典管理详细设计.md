# 字典管理详细设计

版本：1.0；日期：2026-11-08；状态：第一期已实现基线。

## 1. 范围与边界

本功能管理租户业务字典，不管理开发期系统枚举、业务参数、客商、仓库、物料或业务异常目录。字典和字典项的稳定编码创建后不可修改；字典项另有稳定业务值，展示名称可以调整。业务新增选择只使用启用项，历史数据仍可解释停用项。

第一期只开放当前租户自助管理。平台代管、公司/组织覆盖、批量导入导出、关键配置审核发布属于后续扩展，不在界面提供无效入口。

## 2. 权限与租户隔离

- HTTP 路径为 `/api/configuration/dictionaries`，租户和成员只来自 `TenantExecutionFilter` 验证后的会话上下文。
- 读写均要求当前有效成员持有未撤销、未过期的 `GRANT` 能力；写事务锁定授权记录，避免并发撤权后继续提交。
- Mapper 使用 `TenantAggregateScoped` 白名单并在每条 SQL 中显式引用 `__verifiedTenant`；前端传入的标识不能改变租户范围。
- 菜单展示只改善体验，后端授权是最终边界。冲突与拒绝返回稳定业务码，不暴露 SQL、索引名或其他租户数据存在性。

## 3. 数据模型与约束

`tenant_dictionary` 保存字典类型；`tenant_dictionary_item` 保存同字典内的树形字典项；`tenant_dictionary_item_reference` 供业务模块登记引用；`tenant_dictionary_audit` 保存追加式变更审计。

- 字典编码在租户内永久唯一，软删除后不复用。
- 字典项编码和业务值在同一字典内永久唯一，软删除后不复用。
- 上级必须属于同一租户、同一字典；服务层检查循环，复合外键再次约束跨字典父子关系。
- 字典非空时不能删除；字典项存在下级或引用时不能删除，应改为停用。
- 所有编辑携带 `version`，条件更新失败返回并发冲突，禁止静默覆盖。
- 审计只记录租户、对象、操作者、动作和时间，不记录凭据、Token 或业务敏感原值。

## 4. 前端方案

页面选择《前端 UI 与代码生成规范》的“左树右表”模板：左侧字典类型确定右侧字典项范围，右侧包含查询、工具栏、列表和统一弹窗。层级项通过上级选择和“新增下级”维护；没有将字典项自身改造成树形表格，是为了保留编码、业务值、状态、排序等多列的清晰比较，并复用现有 `TreeListTemplate`、`ManagementTable`、`ManagedDialog`、Element Plus 与 `AppIcon`。

页面覆盖首次加载、空字典、空字典项、查询无结果、请求错误、保存中、停用、删除冲突与并发冲突；中英文文案同时交付。稳定编码和值在编辑态只读，避免界面暗示允许修改历史语义。

## 5. API 摘要

| 方法与路径 | 用途 |
|---|---|
| `GET/POST /api/configuration/dictionaries` | 查询、新增字典 |
| `PUT/DELETE /api/configuration/dictionaries/{id}` | 编辑、删除字典 |
| `GET/POST /api/configuration/dictionaries/{id}/items` | 查询、新增字典项 |
| `PUT/DELETE /api/configuration/dictionaries/{id}/items/{itemId}` | 编辑、删除字典项 |

所有写请求要求现有 CSRF 保护。删除版本通过查询参数提交，其余编辑版本在 JSON 正文提交。

## 6. 验收基线

- 两个租户使用相同编码互不影响，当前租户无法读取或修改其他租户对象。
- 无管理能力的成员读写均返回 403；租户上下文缺失返回 `TENANT_REQUIRED`。
- 重复编码/业务值、跨字典上级、循环层级和过期版本被拒绝。
- 有下级或已登记引用的字典项不能删除，停用后仍可被历史数据解释。
- 后端编译和数据库迁移通过；配置模块类型检查通过。应用整体类型检查还须同时满足仓库其他在建模块的公开导出完整性。

### 操作平铺展示

字典项操作列固定为 240px，编辑、新增下级、删除复用 Element Plus link 按钮并横向单行展示，按钮间距统一为 8px；删除仍使用原有确认和权限约束。中英文共用该布局，窄屏由现有表格内部滚动承载，不新增组件。
