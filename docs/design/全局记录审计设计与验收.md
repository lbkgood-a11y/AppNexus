# 全局记录审计设计与验收

日期：2026-11-16。范围：全部自有持久化表的四个记录审计字段、可信写入、授权后的只读投影及前端审计详情。本文区分源码实现、自动验证与本地运行环境状态，不代表生产部署完成。

## 1. 字段与数据迁移

统一列名为 `created_by`、`created_at`、`updated_by`、`updated_at`；API 以 `audit.createdBy / createdAt / updatedBy / updatedAt` 返回只读元数据。账号 UUID 与人员、成员、机器客户端分开；数据库时间使用 UTC 微秒时间点。历史未知保持 NULL，不能用迁移时间、迁移账号或当前查看人回填。

| 模块 | 自有表数 | 新迁移 |
|---|---:|---|
| platform-service | 55 | V80__global_record_audit.sql |
| business-object-service | 8 | V81__global_record_audit.sql |
| leave-poc | 4 | V82__global_record_audit.sql |
| master-data-service | 13 | V83__global_record_audit.sql |
| workflow-service | 8 | V84__global_record_audit.sql |
| print-service | 10 | V85__global_record_audit.sql |

合计 98 张自有表，已有字段保留，新迁移只补缺列。oauth2_*、Flowable ACT_*/FLW_* 和 Flyway 自身表由上游维护，不直接变更。已有追加式审计日志仍保留；四字段不是完整操作历史或删除历史。

## 2. 写入与事务

`RecordAuditDataSource` 在 Boot 启动迁移结束后启用，缓存已具备四列的自有表结构。Flyway 历史迁移期间不启用运行时补写，避免污染原历史事实。共享 JDBC 装配覆盖 JdbcTemplate、MyBatis、PreparedStatement 的批处理以及普通 Statement；复用原连接和业务事务，不使用数据库触发器、数据库会话操作者变量或额外提交。

`RecordAuditSql` 使用 JSQLParser 对自有表 INSERT VALUES、多行 VALUES、INSERT SELECT、UPDATE 和 ON DUPLICATE KEY UPDATE 补充缺省审计表达式；不改变业务 WHERE、占位符数量及顺序。已有服务显式写入的可信审计参数保留。冲突更新只推进修改信息，创建信息不覆盖；更新联表时新增列带目标别名。新增不支持的自有 SQL 写入形状须扩展解析和真实数据库测试，不能静默放行。

`SecurityRecordAuditActor` 从认证上下文读取真实账号 UUID，拒绝匿名和 PARTNER_CLIENT 机器主体作为用户账号；没有账号的系统执行保留 NULL，不能沿用上一请求主体。被代表人员仍由既有业务字段记录。主数据五类执行器同时显式使用 VerifiedTenantContext，使直接用例调用也具有真实账号记录。

## 3. 读取与前端

模块通过 `RecordAuditSource` 在原 GET 方法声明固定表、键、响应路径和租户编码。组合层 `RecordAuditResponseAdvice` 在原授权和平台字段脱敏之后，为原响应中已经返回的对象分批读取最小四字段；每批最多 200 条。租户来自 VerifiedTenantContext；平台代管仅使用该原接口已授权的固定路由租户变量。没有自由表名或自由对象 ID 的额外 HTTP 查询端点，也不递归业务正文中的任意 id。

当前声明覆盖账号、租户、成员、组织类型/组织/关系/岗位/任职、平台及租户角色、菜单、字典/条目、参数、邀请、集成客户端、平台任务、对象目录、工作流定义/实例/任务详情、打印场景/单据/模板/设备/任务、请假单据等 32 个原 GET 方法。五类主数据由本模块列表查询直接返回四字段。技术表及没有独立读取页面的关联表不新增无意义管理入口，持久化四列仍覆盖。

ManagementTable 对服务端已携带 audit 的记录提供“查看审计”只读详情；字典专用虚拟表格复用相同详情。主数据编辑详情、工作流任务及实例详情也复用该展示。切换列表清空已选记录，审计不进入编辑草稿或写请求。

组件选型：先检查已有 ManagementTable、ManagedDialog 和人员详情中的 el-descriptions。新 `RecordAuditDetails` 仅提取跨领域复用的四字段描述列表与时间格式化，原人员私有片段不能被其他业务模块深层导入，因此将最小组合放在 @appnexus/ui；没有引入新 UI 库、主题或交互体系。中英文进入现有 locale，颜色及窄屏沿用 Element Plus。时间缺失显示“历史未记录”，账号缺失显示“系统执行或历史未记录”，不推断具体操作者。
