## 1. 代码交付

- `ProductStructureService` 支持 CUSTOM 规格的 TEXT、INTEGER、DECIMAL、BOOLEAN、DATE、SINGLE_SELECT、MULTI_SELECT 结构化属性。绑定商品固定配置中的 SPEC 模板项及不可变属性修订；必填、精度、有限规则、同修订启用选项与自定义枚举规则由后端校验。主档没有规格时不强制制造规格或 SKU。
- `V119__product_custom_specification_values.sql` 扩充类型化规格值，增加枚举选择明细、租户/父值/修订/类型复合外键、多值互斥 CHECK、选择唯一索引及单选生成列唯一约束。新表首次 CREATE 包含四审计字段和中文注释，不修改既有V116。
- `ProductV1Service` 的历史与审批冻结快照包含规格属性、选项标签和单位；读取不会用新模板重新解释历史。
- 前端复用 `ProductAttributes`、ManagementTable、ManagedDialog 和 Element Plus；CUSTOM 动态表单、只读规格查看、组件独立数量列、正数量校验、中英文和组合替换事件翻译均已实现。只读规格和 SKU 不显示无意义数量列。商品档案简介已移除旧“只支持无规格”文案。
