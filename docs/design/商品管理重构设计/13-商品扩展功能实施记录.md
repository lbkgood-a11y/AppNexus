## 实现范围及边界

| 能力 | 本轮实现 | 边界 |
|---|---|---|
| 单位换算 | 同租户同维度显式直连关系、精确系数、独立启停CAS、只读计算返回exact和按目标精度HALF_UP的display | 不自动反向、多跳、跨维度或商品包装换算；系数不可覆盖，停用旧关系后可新增同方向修正关系；重新启用重验反向一致性 |
| 商品图片 | PNG/JPEG真实解码、尺寸检查、重编码PNG去原元数据、真实数据库二进制存储、原商品权限读取、元数据审计、解绑及商品历史 | 无通用文件服务可复用，新增商品自身受权存取能力，非模拟上传；上传即事务绑定，无临时文件。5MiB/张、4096px/边、1600万像素、10张当前图片；不支持SVG/任意URL。解绑保留历史，不提供物理清理接口 |
| 规格/SKU | NONE/STANDARD/CUSTOM独立模式；SPEC模板/固定修订；标准规格结构化整数/小数/布尔/单选组合及规范串SHA256唯一；自定义名称及描述；显式可选SKU独立编码/归属、启停和有效性 | 不自动给每条规格建SKU。当前标准组合不接受文本/多选/日期；自定义规格本轮为自由描述，不承诺自定义多类型结构化SPEC值或批量笛卡尔积生成。规格、SKU身份不删除或回收 |
| 结构迁移 | 既有签名预览及幂等命令增加规格模式、全部退出规格ID，摘要包含新增字段；配置/形态/单位/模式变更必须确认退出当前规格 | 退出规格与SKU身份保留，SKU有效性随规格退出失效；旧V1内部调用省略模式时保持当前模式，不隐式清空后续结构 |
| 组合商品 | COMPOSITE形态、组成商品版本快照、基础单位数量、组成关系停用及重新录入、同租户图锁与环检查；启用须组成有效且版本未变 | 商品自身档案组成，不包括采购销售库存拆装、价格分摊。修改组成先停用父商品；停用关系保留历史，重新录入可修正数量与依据版本 |
| 审批 | 独立ProductApproval业务记录/Provider，复用WorkflowStarter、WorkflowTaskAccess、BusinessObjectBindings；完整快照冻结、有效任职组织、稳定请求键、可信终态幂等及审核历史 | 不另建审批引擎，不自动绑定请假流程或选择审核人。现有引擎开启、对象激活、租户策略及适配流程发布后才可提交；未配置失败关闭。批准不自动启用，修改版本须重审；申请人与有效任务受限原文读取仍复核权限 |

新页面均组合现有ManagementTable/Vxe、ManagedDialog、Element Plus、InfoHint、主题变量和国际化。新增ProductImages/ProductStructure/ProductApprovals是现有组件的领域组合：公共模板不负责图片授权、规格父子CAS或审批快照，因此只扩展领域行为，没有创建第二套UI库。查看模式不会提供上传、结构写或审核提交。

## 数据库与接口

- V113__product_unit_conversion.sql：单位换算及convert独立权限，启用方向生成列唯一键；显式正系数CHECK、同租户复合外键、首次CREATE完整四审计列。
- V114__product_images.sql：商品图片真实内容、SHA256、格式/尺寸/字节CHECK和商品复合外键；首次CREATE完整四审计列。
- V115__product_extended_modes.java：读取MySQL约束元数据，只替换V1规格模式、形态及模板用途CHECK；要求每项恰一个原约束，不修改历史Flyway文件。
- V116__product_specifications_components.sql：规格、规格值、SKU、组成关系；稳定父子归属、当前标准组合唯一、正数量CHECK、SPEC作用域复合FK及主档PRODUCT作用域生成列FK；所有新表首次CREATE完整四审计。
- V117__product_approval.sql：审核申请、冻结快照、同商品处理中唯一、账号范围请求键唯一、submit_approval独立权限；首次CREATE完整四审计。

新增固定HTTP入口位于ProductUnitConversionController、ProductImageController、ProductStructureController和ProductApprovalController；均沿用现有Cookie/CSRF及可信上下文，不接收客户端租户/账号。OpenAPI扩展方法名固定前缀区分。写入不自动重试；图片及结构父CAS、明细、审计、历史同事务。审核端口只依赖公开workflow/business-object契约，不读取Flowable表。

图片只有原商品读取权才能访问，Content-Type固定重编码PNG、nosniff/no-store；无需上传授权临时票据或临时磁盘目录。审核中的商品普通写、图片和规格组成写均在父锁后复核冻结，前端提示不代替后端限制。审核节点办理只验证有效任务，只有匹配终态实例的EXECUTE能写结果；同终态交付ID可重放，异载荷拒绝。
