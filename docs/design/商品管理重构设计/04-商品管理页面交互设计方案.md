## 2. 档案列表

```text
应用壳/面包屑/标签
商品档案                              [新增商品]
商品名称 [        ] 商品编码 [        ] 分类 [树选择]
商品形态 [全部] 规格模式 [全部] 状态 [全部]  [查询][重置]
[可折叠更多条件：模板可搜索属性；只在选择适用分类后显示]
编码 | 名称 | 分类 | 形态 | 规格模式 | 基础单位 | 状态 | 操作
...
真实总数                                      每页20 / 分页
```

名称、编码可同时过滤（AND），编码默认精确/前缀选择明确展示；keyword兼容API不混淆新字段。分类筛选可选“含子分类”，默认建议包含，需后端按同租户树计算。筛选提交回第一页，重置回默认但保留用户列偏好；按code,id稳定排序。条码、描述、所有质量指标不默认占列；更新时间/审计可放列设置或只读详情。实物缺单位的历史记录显示“待完善”；允许无单位的服务显示“未设置（服务允许）”，不能强塞占位单位。

操作优先横向“详情、编辑、启用/停用”；结构迁移为低频更多项，有独立权限。详情所有read用户可用，不强迫具有编辑权才能查看。状态操作需确认对象和后果，不使用难以表达多状态的开关。仅停用，不提供未经定义的删除入口。

## 3. 新增与编辑

```text
新增商品 / 编辑商品              状态、模板版本、待完善提示
基础信息
  编码* 名称* 简称 分类* 商品形态* 规格模式* 基础单位（按形态/配置标必填）
  品牌 产地 描述 图片（能力接通后）
基础属性（模板分组）
  材料组 / 技术参数组 ... 按发布配置呈现
规格管理（STANDARD/CUSTOM才有）
  标准：选参与组合的属性值→预览→选择需要的组合→保存
  自定义：[新增规格] 名称、说明、按模板输入；可不建立记录
  规格行：属性摘要 | 独立编码（可选） | 规格状态 | SKU状态 | 操作
质量指标（有配置才有）
其他扩展（有配置才有）
[保存草稿] [取消]（已保存后独立启用）              编辑时：[保存修改][取消]
```

新建先选分类，再读取固定配置集和模板版本；无可用配置时可保留未绑定的草稿，启用时提示分类未发布配置，由有权管理员处理，不能回退硬编码字段。配置允许空模板，空配置不是加载失败；NONE可仅填主档。分类选择后的新草稿必须记住解析到的revision ID，提交复核该版本可用，遇并发退役/停用报冲突让用户选择，不能悄悄换最新模板。

草稿可暂不填业务必填属性，但编码/名称及基本输入格式需合法；启用时执行完整校验并定位首个错误。分类、商品形态、规格模式不预填猜测。按D02推荐：实物启用前基础单位必填，服务可空；固定配置集service_unit_required=true时服务也必填。未选择形态时不得猜测规则；后端和前端共用该配置约束，单位为空时不生成虚构单位。

动态属性：文本显示长度说明；整数/小数显示单位、范围和小数位，非法精度直接错误，禁止JS浮点改值；Boolean用明确是/否或可空选择，未填不能默认false；单选Select、多选Select multiple，允许自定义时提供明确“自定义”入口且存储为自定义值，不自动新增枚举。日期DatePicker按自然日处理。必填由el-form规则显示，false和0合法。单位标签固定，换单位不是格式化操作。

标准组合生成先服务端计算条数，超过初建议500条则要求收窄选项，禁止先在浏览器生成巨大数组；预览去重、支持勾选要保留组合，不要求保存完整笛卡尔积。SKU编码是独立显式操作，可批量输入但不默认生成；新增SKU需具备权限。规格停用不移除行，已有SKU显式展示受阻状态。

CUSTOM允许没有规格记录；一旦新增必须有有效说明或属性，空行保存时明确提示移除/补齐，不无声丢弃。NONE隐藏规格区，切换前有规格时先走结构迁移对比，不把隐藏字段当作已删除。

## 4. 切换分类、模式与模板升级

```text
当前配置 A/v1  →  目标配置 B/v2
保留：同稳定属性、同类型、同单位，值无需修改
需补填：新增必填项
待处理：旧枚举不可用、数值范围变化、单位/类型不兼容
将退出当前视图：旧字段、旧规格（保留变更快照）
[取消切换] [返回编辑目标值] [确认迁移并保存]
```

商品配置升级一次切换完整category_config_id及四类模板槽位，缺失槽位表示不使用，不按单个Tab混用新旧版。BASIC/QUALITY/EXTENSION只在主档区，SPEC只在规格区；品牌仅维护主档，不生成动态字段。未保存新建草稿切换分类时同样先预览，兼容值可带入，不兼容值展示原值和原因；确认前草稿保留旧值，取消恢复。离开页面提示未保存更改。已存在商品提交目标数据、原商品version、源/目标配置ID及显式处置，后端重新计算兼容性；客户端预览不是写入授权。启用商品的分类、形态、模式、单位及配置集变更，按05§7.2统一先停用；DRAFT不需要假停用，DISABLED可直接迁移。普通文本和已有定义下的属性值修改不要求停用。无权限用户只读差异，不能看到不可操作保存按钮。

## 5. 详情与变更

标题商品名称、编码、状态；摘要分类、形态、模式、单位。Tab为基础信息、商品属性、商品规格、质量指标、变更记录；无规格模式不出现商品规格Tab，无质量模板不出现质量Tab；CUSTOM没有记录显示“尚未维护规格”，不制造空SKU。

详情按商品固定版本展示字段名、单位、枚举标签；旁边提示“有新版本可迁移”，不能以新版本重新解释旧值。旧分类改名/移动时显示当前分类路径并提供档案绑定时路径；被停用分类有明确标签仍可读。所有字段使用描述列表，禁止disabled输入框伪装只读。

变更记录按版本倒序分页：操作者、时间、操作、原因、前后值、模板版本、规格/SKU状态差异；不存在的旧历史显示“历史未记录”。记录审计独立显示创建/最后修改四字段，不冒充完整操作历史。附件访问每次复核权限，不长期保存签名URL。

## 6. 配置页面

| 页面 | 布局和流程 |
|---|---|
| 商品分类 | 左树/右列表详情；新增同级/子级、编辑、显式移动、停用；禁止仅拖动即保存；绑定区分四用途，选发布版本，预览影响商品数后发布新配置 |
| 属性管理 | 按分组/类型/状态筛选；定义编码和语义，编辑草稿修订；数值单位/scale/范围联动，枚举稳定码与名称；发布时显示引用影响；有引用只新修订 |
| 属性分组 | 属性页内管理入口，简单ManagedDialog；改组不改变已发布模板快照 |
| 属性模板 | 列表按用途/状态筛选，进入版本列表；草稿编排分组与属性修订、必填/可搜索/自定义/组合开关，发布前预览；已发布只读并可复制新草稿；质量用途自动标识质量指标 |
| 计量单位 | 单位列表和编辑弹窗；类型/精度/状态；换算子页或Tab，源/目标维度匹配，系数及方向明确；禁止显示商品包装换算配置 |

配置发布提示“影响后续新建或显式升级，不自动修改已有商品”，显示受影响分类/商品数量时必须具备对应读取权，不为影响分析泄露跨租户明细。新分类通过配置即可使用，不发布前后端代码。

## 7. 全状态验收要求

首次加载骨架，刷新保留旧数据并显示loading；无记录与筛选无结果分开提示。字段错误原位显示；业务拒绝用公共浮层，不插入挤压布局的错误块。401走sessionLifecycle，403清理不再有权的正文；409保留草稿并提供最新值对比，不能自动覆盖；429遵循Retry-After；网络失败允许重试读取但不自动重放写入。写超时结果不明时先按ID/编码读取核实结果。

所有文案进入zh-CN/en；图标用@appnexus/icons AppIcon语义映射；主题用Element Plus变量。验收浅色、深色、System，1440×900/1024×768/390×844；手机单列表单和表格容器内横向滚动，保留核心操作。键盘焦点、真实标签、必填与错误关联、确认框焦点恢复、颜色之外的状态文字必须可用。本阶段未执行上述浏览器验收。

## 8. 第二轮整改：操作矩阵与图片前置条件

### 8.1 商品修改操作矩阵的页面投影

唯一操作判定表见[05业务规则§7.2](05-商品管理业务规则与状态流转说明.md)；页面投影如下，不能另设一套判断。

| 区域/操作 | 启用态体验 | 写入约束与反馈 |
|---|---|---|
| 名称/品牌等普通资料、BASIC/QUALITY/EXTENSION现有定义下值 | 可编辑 | Product.update、version CAS、普通差异历史；不是结构迁移 |
| 分类/形态/模式/基础单位/完整配置集 | 只读并显示“停用后迁移”入口 | 单独Product.migrateStructure；预览后显式提交，version+structureRevision；不静默代为停用 |
| 规格非关键说明 | 可修改 | ProductSpecification.update；父商品version |
| 无SKU的规格关键值 | 可修改、服务去重及必填验证 | 同配置定义下属于普通规格值修改；不改structureRevision |
| 曾建立SKU的规格关键值 | 不提供原地保存 | 引导先停用商品、退役旧规格、建立替代规格和新SKU；不能保留旧码绑定新含义 |
| SKU启停 | 显式确认，展示父级阻断原因 | ProductSku.setStatus；统一父商品version，不新增SKU自身CAS |
| SKU编码/父归属 | 始终只读 | 无改码/重绑接口；替代创建不是原身份修改 |

DRAFT已有已保存绑定的结构变更也走预览/迁移；未保存新建草稿只在本地确认切换，最终create落完整选择。Product.setStatus仅改变生命周期，不因拥有编辑或迁移权而自动获得启停权。按钮绑定上述operationId，权限码只用于服务端授权映射。

矩阵区分了“定义不变的数值修改”和“定义/归属变化”。同单位下将质量热值由6000修正为6100是普通值修改；把热值单位或属性定义从能量换成另一个量纲是结构迁移。该例不构成硬编码行业字段。


### 8.2 图片能力边界

图片仍保留产品设计、排序、主图和详情展示位置，但在实施前必须确认文件服务公开契约：文件创建/临时上传、租户与对象授权、文件类型和大小限制、临时文件TTL、未引用清理、永久引用删除/保留、缩略图与访问URL有效期。未核实前不提供上传按钮、不创建模拟上传API、不把图片作为核心商品保存前置；核心商品可无图片启用。若文件服务不具备临时清理或授权引用能力，首期只交付无图商品管理，后续单独评审接入。

### 8.3 草稿与动态筛选

草稿列表支持“未归档/已归档/全部”和“仅我创建”筛选，后者只缩小授权范围；默认显示未归档。闲置30天仅提示，默认不自动清除；NULL历史更新时间不推断。人工归档前提示“保留草稿、编码和历史，归档后不可编辑或启用”；恢复后重新获取配置和版本，保留原绑定，不自动升级。只对DRAFT展示归档/恢复操作，有manage_draft授权且通过CAS才能执行。永久删除和编码回收没有入口，见03§8.4、05§7.4。

列表不把整个分类的历史模板属性一并混用。必须显式选择一个已授权category_config_id（显示分类+配置revision），才能添加动态属性条件；不选择时仅主档固定字段过滤。固定分类可含子分类，但动态条件模式只选该配置集对应商品，不跨子分类/新旧版本自动拼接。界面显示“当前仅筛选配置版本rN”，切分类/配置时先确认清除不适用筛选条件，不能继续发送旧模板项。

建议读取接口增加categoryConfigId和attributeFilters参数，均属设计建议：attributeFilters最多3项，每项templateItemId、operator、values；不接受SQL路径或JSONPath。后端必须按所选配置确认searchable、类型、操作符、值数与单位，并拒绝未知项，不能忽略非法条件返回更大结果。已知列表page/size沿用1起、默认20、最大100。

可用操作符及SPEC同规格EXISTS语义见03§8.4。TEXT/自定义枚举文本不提供动态筛选；历史快照和退役规格不参与；只查询标准枚举选项，自定义文本不参与并明确提示。字段来源标签明确“商品属性/质量指标/规格属性”，SPEC多条件必须命中同一条当前启用规格。保存失败与筛选失败不能伪装无记录成功。

## R3.1契约同步

本文件的V1契约同步[10 R3.1修订](10-商品管理R3.1契约修订说明.md)：草稿create仅code/name必填，模式由V1固定NONE，形态/配置/单位可空、已填始终合法；启用独立完整校验。status与新增structure_state正交，旧enabled=true映射历史启用但LEGACY_PENDING不属于完整新商品。结构预览/执行采用独立OpenAPI operationId、源version/structureRevision/config及固定目标四槽绑定，幂等请求结果与业务同事务，手动重放规则见10§3。旧规格original逐字保留并显式审查，不自动推NONE。发布四槽必须显式键/null，空配置集合法、零项模板不可发布。新增结构请求表和legacy字段纳入03逻辑全表审计约束、09的17表V1建议基线；均未实现或验证。


R3.1页面补充：未绑配置、已发布四槽皆空配置、含属性配置须分别显示；旧true+LEGACY_PENDING显示旧档启用/结构待确认，只有查看/停用/处置审查入口；原文放独立只读历史规格区，不因选NONE而隐藏。结构预览变更输入需重预览；保存中禁止双击，超时先读取，允许显式同key恢复但不自动提交；replayed结果仅提示原结果并重新读取最新商品。
