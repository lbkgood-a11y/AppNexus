# 六边形职责改造第五批执行记录

日期：2026-11-19。状态：实现与验证中。范围为商品属性存储重写、只读结构预检及追加历史事件存储。

| 职责 | 归属 | 边界 |
|---|---|---|
| 属性原审计读取与删除重写 | adapter.jdbc.JdbcProductAttributes | 固定所属表、可信租户和父商品；准备值先由应用验证，原创建账号/时间及历史NULL保留，原事务内删除重写 |
| 只读预检协调 | application.product.ProductPreviewService / ProductPreviewPort | 原入口先检查迁移及读取权限、输入格式，readOnly事务中读取源、验证目标和退出项，最后签发无持久化证明；端口无写入能力 |
| 商品追加历史 | adapter.jdbc.JdbcProductHistory | 同事务获取原快照协议、附加原因并固定SQL追加历史，不覆盖原事件、不记录预检token；CAS失败及技术异常回滚 |

本批不改SQL、参数顺序、历史迁移或HTTP协议，不拆事务，不连接共享开发库。ProductV1Service保留这些技术适配的组合入口，复杂规则JSON解释器与结构写入仍为过渡协作，不宣称商品全链路无技术耦合。

新增预检测试覆盖未确认退出项不签发证明、启用目标不完整时标为不可执行；真实商品MySQL测试增加父版本/修改时间及历史事件数量不变的预检检查。原商品完整流程继续验证创建审计保留、跨租户拒绝、结构CAS、预检绑定、并发同键重放与事件。

架构门禁要求新增预检与两类存储适配真实存在；现有应用向内依赖规则及中文包说明检查继续生效。本批未新增包，已同步现有包职责说明。

验证结果待命令完成后填写，不以编译通过替代真实数据库验收。未部署、未浏览器验收，未修改前端或数据库结构。
