# 统一导航编排实现与验收

日期：2026-11-09。本批直接扩展原菜单管理，不新建导航管理入口；未改变现有业务 API 的授权边界。

## 管理员操作

进入原「菜单管理」，继续维护父级、名称、图标、顺序、显示和启用状态。目录用于分组；本系统页面从已注册页面中选择，系统同步带入路径、管理域和基础权限；外部链接填写 HTTP/HTTPS 地址，在新标签页打开。BUTTON 兼容保留，仅描述权限，不生成导航。

例如在租户「仓储管理」目录中增加外部 TMS 地址，适用域选当前租户。该入口仅供当前有效成员显示，不授予 TMS 权限；需要限定本系统资格时，可关联已有租户权限码。外部应用 SSO、应用开通同步和租户个性覆盖尚未接通，不提供无效选项。

排序值越小越靠前；同值按 code、id 的稳定字符序排列。每个父级独立排序，过滤后保留相对顺序，不按角色重新排序。主页等基础应用壳入口保留静态位置。

## 数据与接口契约

追加 V27，未改动已发布迁移。历史菜单 scope_type 默认 PLATFORM，避免被静默开放给普通成员；初始化当前已交付业务页面的默认导航，历史记录保留供管理员调整。未注册旧页面不进入本人动态导航。

| 参数 | 中文说明及约束 |
|---|---|
| type | DIRECTORY、MENU、EXTERNAL、BUTTON；EXTERNAL 为本批新增 |
| scope / scope_type | PLATFORM 平台管理员、TENANT 当前有效租户成员、AUTHENTICATED 已登录账号；旧请求缺省 PLATFORM |
| parentId | 可空表示根；父级必须是同域目录，不得指向自身或后代 |
| sortOrder | 0–9999 的相对顺序值，默认 0；同值按 code、id 排序 |
| component | 本地页面构建标识，必须精确匹配 NavigationPages 与前端显式注册表；不允许任意脚本或模糊文件匹配 |
| path | 本地页面固定路径，必须与构建契约一致；目录、外链和按钮保存时为空 |
| permission | 本地页面使用其固定基础权限；外链可引用对应域已启用权限，登录公共外链不能引用业务权限；按钮必填 |
| externalUrl / external_url | 外链必填，最长 2000 字符；仅 HTTP/HTTPS 绝对地址，禁止凭据、控制字符、反斜杠和协议相对地址；其他类型为空 |
| visible | 默认 true；隐藏入口不进侧栏，隐藏本地页面仍可注册并检查访问资格；隐藏目录同时隐藏后代导航 |
| enabled | 默认 true；停用节点及其目录后代不进入快照；不代表后端业务整体下线 |
| version | 更新、删除原样回传的乐观锁版本，冲突须重读；不是权限凭据 |
| contextVersion | 当前会话租户版本，0 表示没有有效租户；用于隔离过期导航响应，不是权限凭据 |

沿用 `/bff/platform/menus` 的 GET/POST/PUT/DELETE；写操作逐次验证 CSRF，保留版本与审计事务。新增 `/bff/platform/menus/pages` 返回受控页面目录，仍要求菜单管理权。

新增 `GET /bff/navigation` 返回本人的 Snapshot（tenantId、contextVersion、items），不接受客户端身份或租户作为权威，不要求菜单管理权。服务端每次复核账号、成员、真实功能权限与页面最低管理约束，返回 no-store。页面注册表延续真实端点能力：平台管理页仍要求平台管理身份，租户角色、授权和字典页仍要求现有 GRANT 能力；组织页使用统一 organization.unit:read 判定，包含现有兼容授权口径。

## 前端与生命周期

复用 vue-pure-admin 应用壳、侧栏、标签页和缓存。前端仅静态注册主页、自助和错误等基础路由，业务路由消费本人快照并通过显式组件映射注册；移除旧空动态路由响应和任意文件模糊匹配加载器。未知组件或重复路径报加载错误，不跳转到其他页面兜底。

进入业务页面重新获取导航；活跃会话每 60 秒及窗口焦点复核时刷新。该频率只影响界面同步，不能替代服务端逐请求撤权。快照变化时移除旧动态路由，重建菜单，清理失效标签与页面缓存；已失权页面跳转无权限页。租户切换清理旧导航和标签；代次标识丢弃旧请求，不把导航或权限写入 localStorage。外链沿用模板链接，增加 noopener noreferrer，不嵌入 iframe。

组件选型沿用原 MenuManagement 的 TreeListTemplate、ManagementTable、ManagedDialog 和 Element Plus。仍采用左树选择范围、右表维护属性，保留刷新、密度、列设置和全屏，不引入新 UI 库或自定义交互组件。新增适用域和顺序列、本地页面选择与外链输入；中英文与主题变量沿用现有公共组件。

## 边界

本批没有租户菜单覆盖、外部应用单点登录、应用开通配置或权限同步；外部链接可见性不代表目标系统授权。菜单禁用不自动停用后端业务。字段、数据范围及此前 BusinessScope 契约仍由其执行链负责，不通过导航放宽。
