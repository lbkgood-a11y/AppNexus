# 单据工作台首批实现与验收

日期：2026-11-12。本文描述本批实际范围，未交付能力不由其他设计草案推断为已实现。

## 已实现

- 独立 document-contracts JAR 与 document-service 模块。业务通过 Provider 登记类型、条件字段及结果能力；单据服务不写业务状态、不执行业务动作。
- 平台“单据管理”：代码目录、契约查看、激活/停用、按类型授予实际存在租户的配置资格。默认不激活、不自动给存量租户授权。
- 租户“单据工作台”：仅租户管理能力且类型已获授权时可维护；兼容已发布流程目录、条件绑定、草稿乐观锁、原子发布及历史版本。复用现有 organization.permission:grant 管理能力，不新增使用资格模型。
- 无流程可跳转设计器并自动选中单据契约，人工设计/发布后返回工作台重新选择绑定。绑定只接受无模型级 matches 的兼容审批流程；节点内条件不受影响，避免两套启动匹配规则。
- 解析通过服务端可信 facts 唯一匹配，固定流程版本；绑定零/多匹配拒绝。中心校验契约版本，工作流重读业务依据并核对解析，已接入单据不允许直接绕过绑定启动。
- 请假业务保留原表状态，新增轮次历史、原文业务快照及配置关联；草稿/驳回/撤回可由本人修改，依据版本递增，审批中冻结。新提交记录新实例，旧结果依据/实例不符不能覆盖新轮次。
- V59 单据配置、V60 请假审批历史及存量实例关联、V61 两个管理导航。迁移不改变已有业务终态、不为存量单据创建新流程。

## 组件及配置

平台及租户平面目录使用标准列表，复用 BusinessWorkspace、ManagementTable、ManagedDialog 及 Element Plus。绑定编辑只是表单组合，无新 UI 库或自定义弹窗。中英文、变量主题、折行布局及表格内部滚动沿用公共能力。

本批无新增环境变量。绑定数量上限 50、每条条件上限 10、名称最长 100 字符、条件值最长 200 字符；条件首期支持 NUMBER/BOOLEAN/TEXT，数值十进制比较，逻辑为条内 AND、条间唯一匹配。无条件是全匹配，不能与其他绑定共存。复杂区间重叠以运行时唯一性兜底，未实现完整静态可满足性证明。

当前使用 doc_resolution 保留非敏感解析记录，不含原因原文；留存/清理作业尚未交付，生产容量治理须另行完成。授权收回禁止维护但保留已发布绑定；目录停用阻止新解析/启动，既有流程结果回写不依赖中心重新解析。

## 验证与限制

新增 DocumentIntegrationTest 使用隔离 MySQL 8.4 与真实 Flowable，通过平台激活/授权、管理角色边界、跨租户拒绝、无绑定回滚、指定旧发布版本启动、重复提交、审批中禁止修改、驳回回写和新轮次重提、绑定多匹配回滚、普通用户解析、同键异依据及解析引用越权检查。前端工作流 3 个测试文件共 9 项通过；单据模块与 admin 类型检查、生产构建通过。

后端全量应用回归 141 项中发现一项旧导航“必须全空”断言与既有公共待办/本人单据导航不符，已改为精确验证组织、角色和单据配置入口不可见；该测试类 8 项重新运行全部通过，其余 140 项原回归通过。架构检查 5 项通过，前端导航测试 8 项通过。验证日志位于本机忽略目录 `.local/document-integration.log`、`document-regression.log`、`document-final-regression.log`、`document-navigation-tests.log` 和 `document-build.log`，不包含凭据。

浏览器工具访问本地地址被审批拒绝，未完成登录后页面操作、深浅主题和移动端视觉验收，不用构建成功替代。实际开发库 V59—V61 已执行并启动组合应用；本次本地进程显式开启 APP_WORKFLOW_WORKER_ENABLED=true 以执行真实结果回写，未改动脚本及生产默认关闭策略。不自动激活单据或授权租户，避免更改存量运行配置。管理员须按页面完成激活、授权与发布绑定后，新请假提交才可进行。

打印绑定、完整流程生命周期事件及 Outbox 治理、远程微服务客户端、跨服务恢复、统一单据中心与公共关联投影不在本批实现。请假仍沿用 POC 的 workflow:start 操作权限，正式业务权限拆分尚未交付；已有公开契约不等于正式请假领域产品完成。

## 验收问题修复（2026-11-12）

用户验收提出页面边距、平台目录归属、图标缺失及授权单据不可见四项问题。

- 单据组件原有多个根节点，导致应用壳 main-content 类及其作用域属性无法继承。改为单一 management-page 根容器，由框架提供 24px 外边距，页面不另写外边距。
- 新增 V62 修复迁移，将平台单据管理归入既有 builtin.navigation.platform 目录，保留菜单权限及路由；不修改已经执行的 V61。
- 将 ri/file-list-line 加入模板本地图标注册，平台与租户两个入口均使用该 SVG。
- 原租户目录将授权和平台启用合并过滤；当前开发库存在已授权但无 doc_type 激活记录的情况，导致空列表。配置资格现只看租户授权，未启用单据仍展示状态并可准备配置；运行解析及启动继续独立检查启用状态，未静默激活存量单据。

新增真实数据库回归覆盖已授权停用类型的可见性与配置读取、未授权过滤、停用禁止解析及启用后可见。菜单回归补充平台父目录、图标标识和路由校验。对应日志为 `.local/document-acceptance-*.log`；浏览器视觉验收仍受此前本地地址访问审批拒绝限制，不将代码修复或构建检查描述为截图验收通过。
