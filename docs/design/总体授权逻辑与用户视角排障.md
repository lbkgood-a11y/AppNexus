# 总体授权逻辑与用户视角排障

本文记录当前实现，不再混用旧直授权迁移阶段的说明。模型与开发约束见《业务服务统一开发规范》，最终证据见《架构重构查缺补漏审查》。

## 管理员的排查顺序

选用户或当前租户成员 → 搜索页面/操作名称或权限码 → 查看权限来源、页面准入、数据范围及字段限制 → 在业务详情检查具体对象。

| 用户反馈 | 检查内容 |
|---|---|
| 看不到菜单 | 账号/成员有效性、正确租户、菜单及祖先显隐/启停、页面登记、基础权限、额外管理身份 |
| 进入页面但按钮不可操作 | 操作权限表达式、角色和权限状态、成员授权快照、有效期及业务条件 |
| 角色已勾选仍不生效 | 成员实际授权是否包含该权限、角色是否移除权限、授权是否过期，不能只看角色模板 |
| 看不到记录或字段被遮盖 | 当前数据范围、同租户组织范围、强制字段展示上限及对象归属 |
| 单据提交/打印失败 | 具体状态、发布配置、唯一条件匹配、审批定义或打印场景/模板/节点/设备依赖 |

## 授权链路

平台：有效账号 → 平台角色关联 → 启用未删除的角色 → 当前启用权限；平台管理业务另复核受控管理身份。

租户：有效账号/租户/成员 → 同租户成员角色 → 有效角色 → 角色当前权限与成员授权快照交集 → 未过期的授权分支。平台管理身份不自动变成租户业务授权。

功能权限、数据范围、字段展示、对象归属及业务状态分别负责不同约束。菜单不参与 API 放行，界面显示的任何准入结果都不能作为写接口凭据。

## 当前诊断实现

主体角色详情支持搜索操作名称、ID、权限码。平台接口为 /bff/platform/users/{account}/operation-diagnostics，租户接口为 /api/access/members/{member}/operation-diagnostics；两者先执行 SubjectRoleManagement 的目标管理授权，租户账号通过限定 tenant_id/member_id 的关系解析，不能客户端冒充。

- permissions：每项功能要求及全部角色来源；没有来源也生成明确缺失项。停用账号不会被解释为有效角色贡献。
- pages：NavigationQuery.inspect 与真实 current 共用 reason，检查身份、成员、页面登记、权限、Gate 与祖先。accessible 和 visible 分开，隐藏菜单仍可有合法隐藏路由。
- data：DataScopeAuthorization 和 FieldProtection 的目标主体结果，展示范围及强制字段模式，不返回字段值。
- unchecked：没有具体记录时明确对象与业务状态尚未检查。FUNCTION_GRANTED 只表示功能表达式满足，不能据此称“可以修改任意记录”。

页面原因包括 MENU_DISABLED、ANCESTOR_DISABLED_OR_INVALID、MENU_OR_ANCESTOR_HIDDEN、PAGE_PERMISSION_MISSING、PLATFORM_IDENTITY_REQUIRED、TENANT_ADMIN_REQUIRED、PAGE_REGISTRATION_MISMATCH、ACCOUNT_DISABLED、MEMBERSHIP_INACTIVE 和 MENU_NOT_CONFIGURED。

## 具体记录与依赖预检

统一入口 /api/operations/{operationId}/objects/{objectId}/diagnostics 只用于当前登录主体；业务提供者先校验对象归属。无提供者返回 NOT_CHECKED，不读取对象，不假装全通过。无权或缺失记录统一 404；存储异常为 503，参数错误为 400，不泄露 SQL/正文。诊断不模拟其他用户登录、不写入任务或业务数据。

请假详情调用该入口，复用服务自己的 availability。检查本人资格、业务状态、平台入口关系、配置启用/租户开放、发布契约及绑定匹配；审批定义和打印场景是固定绑定目标。配置预检与正式解析共享条件匹配函数，不消费幂等键。

打印输出选项窗口使用本人单据的 /api/printing/documents/{id}/preflight。场景/模板/发布契约检查通过后，读取本租户近 120 秒代理队列事实；PREVIEW/PDF 不要求物理设备，SILENT 校验选定设备启用、同租户、站点及队列在线。离线可以作为明确排队提示，缺失必填设备仍阻止提交。预检不保证任务随后必然完成。

## 安全与验收约定

管理诊断不能扩权；修复仍通过原授权表单、审计和乐观锁。对象规则由业务服务负责，不能为了通用化绕过事务、归属或状态机。未知和未检查状态必须显示，不使用“模拟登录目标用户”排查。

已测试菜单隐藏/停用与真实导航一致、普通主体无管理权限、目标主体范围/字段而非操作者范围、过期及撤权、跨租户、对象不存在/无权不可区分、预检无副作用。普通用户登录后的 403 与管理员正向诊断有浏览器证据。新增业务服务按公开 ObjectDiagnostics 扩展自己的记录检查；没有真实实现不注册虚假的检查通过项。
