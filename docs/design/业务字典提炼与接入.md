## 唯一来源与迁移

选项默认值集中于 persistence 模块 `business-value-defaults.tsv`（UTF-8，无配置密钥）。四列分别为：字典稳定编码、字典中文名称、不可变业务值、可维护选项名称；顺序为初始排序。编码遵守现有字典约束；稳定值最长100字符，不接受控制字符。V89 Java Flyway 迁移对该资源计算校验和，后续变更必须新增迁移／资源版本，禁止修改已部署的 V89 内容。前端只保留字段绑定及类型，不再复制选项数组。

V88 允许现有字典及字典项审计账号为 NULL，表达系统预置没有实际账号，不伪造零 UUID 或迁移执行者。V89 对已有租户仅补缺失字典、默认项及既有业务自由文本；名称、排序、启停、原始业务值和原业务审计不被覆盖。客商 BOTH 历史语义按客户兼供应商处理，不另造一条可新选的 BOTH。超出字典100字符限制的历史原文保持不变，继续只读或原值保存，不截断也不静默转换。

存量客商分类、联系人类型、币种、商品单位、人员属性及 JSON 明细的分类文本均会提炼，建立引用以保护历史含义。重复运行初始化不覆盖租户维护或恢复停用、删除项。新租户开通在原事务内调用同一默认资源初始化，并使用真实开通账号；既有租户迁移的系统插入账号为空，时间由数据库 UTC 生成。

本轮复用 tenant_dictionary、tenant_dictionary_item 及 tenant_dictionary_item_reference，没有新增持久化表；仍运行全表四项记录审计门禁。

## 页面与权限

客商详情的类型、性质、等级、人员规模、注册币种、联系人类型、账户币种改为真实字典选择；商品单位改为字典选择；人员基本属性和明细中的性别、证件类型、血型、用工性质、婚姻、学历、技能、民族、政治面貌、证书类型、联系人类型、地址类型、学位等改为真实选项。列表、详情和明细按字典名称显示；历史已失效／未知值保留原稳定值。没有可用选项时不回退前端模拟选项。

业务选项按原对象读取权限提供：客商／商品使用各自列表接口的 options=true（默认false）；人员复用 /options 聚合。字典读取与引用通过配置模块公开 BusinessValueCatalog 端口，领域模块不跨包直接读取配置数据库表；业务用户无需获得字典维护权限。维护继续使用现有业务字典页及独立权限。字典名称属于租户业务数据，按维护原文显示；页面框架、标签和错误提示仍沿用全站国际化。

## 保存与历史

写请求仍由原对象权限、可信租户、CSRF、父版本和事务复核。选项必须是本租户未删除且启用的真实字典项；未知新值／其他租户值／停用新选拒绝。未改变的历史停用值可保留，不要求用户为编辑无关字段重写历史分类。

配置适配器按字典编码顺序锁定父字典，与字典维护共用父锁，避免校验后被并发停用或删除；引用登记与业务写入同事务，失败回滚。引用仅存业务对象及 UUID／父子标识，不存证件、账户等敏感原文。保留历史引用，即使当前记录已改值也不物理清除，字典项被使用后只能停用而不能删除。

在职状态、证书状态、奖惩类型仍受实际状态机集合约束：字典可维护名称、排序和启停，新增未知状态不能通过字典扩展执行语义，业务选项响应将此类未知值置为不可新选。布尔值、权限管理域、审批状态、打印协议、图标或布局偏好不改成自由业务字典。国家地区继续使用真实主数据实体，不复制为第二套国家字典。

## 验证

最终执行记录补充于本节；隔离测试数据库使用真实 MySQL／Valkey 和实际 RBAC，不在共享开发库手工改数据。相关测试覆盖预置幂等、不覆盖重命名／停用、动态新增客商类型、商品单位、跨租户拒绝、历史提炼、业务引用删除保护、人员全明细流程及审计字段扫描。部署后的真实登录浏览器验收与本轮隔离测试分别记录，不将构建通过等同于完整业务验收。


共享工作区同时新增仓库类型与经营模式字典（warehouse_type、warehouse_operating_mode），独立使用 V91 及版本化资源，不回写 V89 清单；新租户开通同时初始化两份资源。当前合并工作区合计25类、114个常用预置项，其中本轮客商／人员／商品清单为23类110项。

浏览器隔离验收使用实际 PartnerEditor：确认字典自定义客商类型名称展示、历史停用性质仍能解析且选项 disabled、新启用性质可以选择并进入草稿。样例未调用共享业务写接口，临时入口已删除；不是管理员／普通账号真实端到端验收。全仓操作绑定仍受既有其他模块条目影响，本轮修改的客商、商品和人员入口无新增门禁问题。
