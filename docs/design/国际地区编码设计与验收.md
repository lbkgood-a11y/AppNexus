# 国际地区编码设计与验收

2026-11-17。国别使用 ISO 3166-1 alpha-2 作为不可变业务编码，alpha-3 和数字码由服务端标准快照补齐并校验匹配；数字码保持三位字符串，例如 AF / AFG / 004。租户可维护本地化名称、启停和英文名称。已有档案不自动改码，历史错配在下次保存时明确拒绝，避免静默改变引用。

行政区划新增唯一对象 Subdivision，使用 ISO 3166-2 完整代码，例如 US-CA、CN-BJ；countryCode、subdivisionType、parentCode 由标准确定。上级是标准代码关系，不要求上级已加入租户目录，不假定统一省市县层级。国别名称不作为关联键。跨国业务可使用 countryCode 区分区域，同国细分使用完整区划代码；尚未把现有人员、仓库、客商自由文本地址迁移成强引用。

ISO 目录快照含 249 个国别和 5046 个区划；2026-11-17 另接入民政部截至 2025-12-31 的 3178 个中国地县级节点，以 CN-MCA- 命名空间区分官方六位代码与 ISO。来源、覆盖边界、格式和校验摘要见服务资源 geography/README.md 与《中国地县级行政区划补充与验收》。不是 ISO 官方实时同步服务，不自行生成 ISO 编码。目录读取复用对应 list 操作，不提供免授权入口；选择标准项只修改草稿，保存仍复核 create/update 权限。

复用 Management、BusinessWorkspace、ManagementTable、ManagedDialog、RecordAuditDetails、Element Plus Select；无需新增组件。新增路由、导航、四个唯一操作及独立 masterdata.subdivision 权限，管理员迁移授权，普通角色必须显式授权。V92 首次建表包含四个审计字段及中文注释，账号 BINARY(16)、时间 TIMESTAMP(6)，可信账号和数据库时间与业务事务写入。租户、CSRF、并发版本沿用原执行器。

检索支持国别名称、二字码、三字码和数字码；区划支持名称、完整编码、所属国别及上级编码。查询值使用绑定参数，不扩大租户范围。维护目录为显式选用模式，不为每个租户自动创建数千条记录。

验证记录：MasterDataServiceTest（标准错配、未知码、前导零、父级代码和无权拒绝），MasterDataMySqlTest（真实 MySQL 建表、跨租户、并发、唯一和启停）通过。admin 类型检查和生产构建通过。全仓 typecheck 在既有虚拟图标类型声明失败，operation-bindings 检查发现其他页面既有未绑定交互，未添加绕过例外。GlobalRecordAuditTest.ownedTablesHaveAllFourColumns 在真实 MySQL 完整迁移至 V92 后通过。尚未完成真实登录会话管理员/普通用户、主题和移动端页面验收；未部署到开发或生产数据库。
