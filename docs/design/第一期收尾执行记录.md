## 本批已实现，继续验证

- Web 会话默认绝对有效期 8 小时，范围大于零至 24 小时。真实密码登录写入认证时间，OAuth 回调不续期；旧会话使用原创建时间，时间证据异常拒绝。两条过滤器链均应用同一策略，Bearer 有效期仍由 OAuth 权威记录校验。
- 本人撤销其他单个会话追加 `SESSION_REVOKED`。既有批量退出其他登录已存在，本批不重复开发。Valkey 删除与 MySQL 审计不构成原子事务，审计失败不恢复已撤销会话。
- `POST /bff/platform/users/{id}/revoke-sessions`：平台管理员、CSRF、禁止本人、目标有效状态复核；账号版本、OAuth 授权删除及平台审计同一数据库事务。旧 Cookie 下一次请求被拒绝，不中断已执行请求。界面复用现有用户列表、Element Plus 确认及统一 HTTP。
- V33：全局账号 TOTP 密钥 AES-256-GCM 加密，账号 UUID 作为 AAD；30 秒步长、六位数字、前后一个窗口。账号锁与因子锁保证验证码和恢复码不能并发重放。绑定待确认 10 分钟；激活返回 10 个 128 位随机恢复码且仅保存 SHA-256 摘要。
- MFA 激活/关闭撤销旧认证；激活时保留已证明密码与因子的当前会话并轮换 ID，供保存恢复码，关闭时注销。登录时已绑定账号必须提供第二因子，失败撤销刚建立的认证。step-up 复核密码和第二因子，轮换 ID，窗口 5 分钟；已绑定账号改密和管理员强制下线入口强制检查窗口。
- 个人中心新增 `MultiFactorSettings`，仅组合 Element Plus 表单、提示与既有设置分区；现有组件没有绑定密钥和一次性恢复码生命周期逻辑，因此新增最小场景组件，不新增 UI 系统。密钥和恢复码仅放组件内存，离开分区释放。登录页保留标准 CSRF 表单 POST，增加不查询账号绑定状态的可选第二因子输入。
- 平台管理写入默认对全部认证主体强制绑定 MFA 及最近 5 分钟认证，涵盖通过自定义角色获得平台能力的主体，不能仅识别旧管理员表；账号安全本人入口仍可进入，不形成绑定死锁。MFA 通过仍由原业务授权门禁复核管理权。密码认证失败与第二因子失败分别追加本人安全事件，不保存提交的凭据。
- V34：支持本人高熵 MFA 恢复码找回，以及管理员核实身份后受权签发凭证。凭证 256 位随机、只存 SHA-256 摘要、有效 10 分钟；新签发覆盖旧凭证，账号版本变化后旧凭证失效。凭证消费、改密、旧 OAuth 授权撤销及审计同事务，重置后仍保留已绑定 MFA。管理员不能为本人或任何平台管理员签发凭证，不提供自动邮件/短信投递。
- 登录找回表单复用原登录壳及 Element Plus；管理员凭证一次性展示复用 `ManagedDialog`，关闭后释放内存。未增加新视觉组件或路由体系。
- 企业 OIDC 身份源隔离 PoC 已通过真实 HTTP 标准换码、PKCE、JWKS 验签、userinfo、issuer/audience/nonce/state/subject 拒绝测试，显式 `(issuer, subject)` 绑定样例不依赖邮箱，不自动授予平台身份或租户成员。具体范围见《技术 PoC 执行记录》；不宣称生产 SSO 管理已完成。

| 接口 | 边界 |
|---|---|
| `GET /bff/account/mfa` | 本人状态，不返回密钥或恢复码 |
| `POST /bff/account/mfa/enrollment` | 当前密码、CSRF、限流；10 分钟待确认密钥 |
| `POST /bff/account/mfa/activation` | 当前密码和 TOTP；一次性恢复码；轮换当前会话、撤销其他旧认证 |
| `POST /bff/account/mfa/step-up` | 当前密码和因子；轮换 ID，窗口 300 秒 |
| `POST /bff/account/mfa/disable` | 当前密码和因子；撤销全部旧认证并注销 |
| `POST /login/recovery` | 高熵恢复码单次消费；不接受六位 TOTP 代替遗失的密码 |
| `POST /login/recovery/completion` | CSRF、限流、密码策略；短时凭证原子消费 |
| `POST /bff/platform/users/{id}/password-recovery` | 平台管理员、近期 MFA、CSRF、本人/管理员保护、平台及本人审计 |

## 配置与部署

| 配置 | 中文说明 |
|---|---|
| `APP_SESSION_ABSOLUTE_TIMEOUT` | Web 绝对期限，默认 `8h`（8 小时），必须大于零且不超过 `24h`；多实例保持一致，收紧后对下一请求生效，与 30 分钟空闲超时独立。 |
| `APP_MFA_ENCRYPTION_KEY` | TOTP 专用加密密钥，Base64 编码的 32 个密码学随机字节；默认空时不开放绑定且已绑定账号不能跳过 MFA。生产由部署密钥存储注入，所有实例一致，轮换前必须受控重加密；禁止与 BFF 密钥共用或随重启重建。 |
| `APP_MFA_REQUIRE_PLATFORM` | 默认 `true`，平台管理员写操作要求绑定 MFA 且最近 300 秒通过第二因子。仅受控迁移或测试可设为 `false`；生产关闭会降低安全基线，不影响本人绑定入口。 |
| `APP_NATIVE_REDIRECT_URI` | 默认空表示不创建原生客户端。非空时必须为精确 HTTPS App Link，无通配、fragment 或用户信息；注册客户端 `appnexus-native`，无客户端密钥，强制 PKCE，授权码与刷新授权。已注册回调变更需迁移。当前访问期限 5 分钟，刷新族绝对 7 天，生产参数待风险和容量验收。 |

`Initialize-Local.ps1` 在既有忽略目录凭据文件中生成并保留 MFA 密钥；严格 JSON 中该参数的说明即上表。不得打印凭据文件。生产先执行 V33/V34，不能修改历史迁移。
