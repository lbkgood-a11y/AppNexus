# 打印设计器自助制作说明

隔离画布主题实时同步：会话每 500ms 对比宿主计算后的语义主题变量，仅变化时向指定 iframe 发送白名单变量；深浅模式、主色、背景、文字、边框和站点字体一起更新。主题更新不重建模板、不改变打印元素样式、不清空历史；销毁会话清理定时器。纸张保持真实输出白底，模板内容颜色由模板自身决定。

面板宽度与字体：桌面元素栏 240px、属性栏 336px，继承宿主计算后的字体族并采用 14px 正文字号；不改变纸张内模板字体。预览明细行数回到预览按钮旁，纸张尺寸浮层去除“纸张规格”标签，采用平台背景色混合透明及 backdrop-filter 模糊。窄屏沿用原内部滚动断点。

居中工具栏：快捷工具、历史操作、旋转、自动排布和预览统一在顶部居中。纸张尺寸及预览样本设置移至画布右上方浮动信息区，避开右侧属性栏，不随纸张滚动；小屏换行并保持可访问名称。浮层只展示信息与预览参数，不改变纸张输出坐标。

自动排布：工具栏旋转旁提供入口；按每面板原有 top/left 阅读顺序逐行排布，边距 24pt、元素间距 12pt，保留内容、字段绑定、字号和尺寸。表格按设计高度占位，运行时分页由引擎负责。超宽、超高、尺寸无效及固定/旋转元素整体拒绝，不部分修改画布。操作先确认且可撤销；不是复杂版式的智能重设计。前端新增换行、内容保留、原模板隔离与失败边界测试。

工具栏顺序：左侧为快捷工具、撤销、重做、同步设计；右侧为纸张尺寸、旋转纸张、预览和示例输入。旋转读取当前引擎纸张宽高并交换，保留元素坐标，复用快照撤销；不会将尚未应用的纸张表单值误用于旋转。仅设计模式且引擎就绪时可用。

整体编辑器第二轮优化：取消常驻长说明，将帮助放到纸张尺寸提示；快捷工具入口与预览、历史操作共用顶部工具栏。浮动工具窗口初始放在右侧属性栏左边（保留 320px），宽 340px，标签在上、输入在下，避免标签挤压文本框；窗口可由用户继续拖动。纸张工作台采用轻点阵并居中，左右标题固定，窄屏仍保留属性栏。该轮仅调整展示与布局，不改变打印内容坐标、模板数据或输出参数。

浮动快捷工具：按用户要求，字段、文字和纸张设置移至画布右侧可打开的非模态工具窗口，不再占用顶部布局。窗口复用 ManagedDialog 的标题栏拖动、尺寸调整和边界限制；为公共组件增加 modal/top 可选参数，其他弹窗默认仍为模态。工具窗初始右对齐，首次定位由样式完成，禁止动画后再跳位；移动端收敛到视口宽度。关闭只清理窗口显示，组件内输入保留至设计器卸载。

快捷配置收敛为“业务字段、添加文字、页面设置”三个切换按钮，初始不展开，仅显示纸张尺寸摘要；同一时间只显示一个工具的表单。纸张预设、宽高和应用按钮仅在页面设置中出现，预览模式不展示编辑表单。使用现有 Element Plus Button/Form，无新增弹层或 UI 库，释放纸张画布高度。

2026-11-11 设计器视觉优化：复用 Element Plus Collapse/Form，顶部快速配置改为紧凑同行输入与操作；提示说明不再占用大块警告区域。隔离画布继承平台语义主题变量，采用元素库—纸张工作台—属性三栏；左右面板与中间画布独立滚动，纸张保留白色实际输出表面，舞台与纸张边界明确。窄屏保留完整三栏并在设计器内部横向滚动，不隐藏编辑能力。未新增 UI 库或改写拖拽逻辑。

2026-11-11 内容布局修正：PrintManagement 使用单一根容器承接应用壳 main-content（24px 外边距），弹窗仍由统一组件 Teleport；业务搜索与数据分区使用 BusinessWorkspace 自带 padding，删除业务页重复的 16px 内边距。不得再通过多个根节点使应用壳样式丢失，或另加页面外边距补偿。

日期：2026-11-11。目标：普通用户无需编写 JSON、字段编码或脚本，即可从业务起始版式制作打印模板。当前为增量实现与测试记录，不代表生产准入已完成。

## 用户流程

1. 在打印管理点击新建，填写模板名称、选择业务契约和出仓单起始版式或空白版式；稳定编码自动生成。
2. 保存后直接进入设计器。展开“快速制作”，按中文名称选择单号、仓库、收货方、制单人、备注或出仓明细，点击添加；明细自动建立绑定列，无须输入字段名。
3. 添加固定标题、说明或签字文字；在原生画布拖动元素、调整列宽和字体。快速工具支持 A4、A5、标签、小票和自定义 mm 尺寸。缩小纸张不会擅自缩放或删除内容；快照检查提示越界元素。
4. 输入 1—100 行示例明细数量，预览检查分页。示例数据与真实业务数据明确区分，不创建打印任务。
5. 保存草稿；关闭、切换路由时比较实际画布快照，保护未保存内容。加载失败可重试，失败保留当前设计。历史发布版本可恢复为草稿，恢复不会自动发布。
6. 有独立发布权限的人员审核并发布。普通设计权限不会扩大为发布或真实业务读取权限。

## 实现与组件选型

复用 vue-pure-admin 应用壳、BusinessWorkspace、ManagedDialog 及 Element Plus Form/Select/InputNumber/Collapse/Alert/Button。物理纸张画布继续使用现有 HiPrint iframe；现有模板组件不提供物理排版、动态表格或字段绑定，因此仅扩展既有专用画布适配，不引入 UI 库。

字段定义由后端 `/api/printing/design-contracts` 提供，要求 `print.template:design`。`warehouse.outbound.v1` 当前 `designOnly=true`，返回字段元数据和合成样本，不访问真实业务。出仓业务读取与 PRINT 字段授权尚未接入，页面明确提示。

平台快速工具的 replace 与原生画布操作共用受控快照撤销历史，最多 30 份、500 ms 检查一次；不会把模板写入浏览器持久存储。恢复基于引擎重建，不能保证捕获同一 500 ms 窗口内的每一步微小拖拽。已保存基线使用初始化后的引擎快照，避免默认值展开导致误报修改。

页码格式限制为 `paperNo`、`paperCount`、数字及简单分隔符，拒绝模板字符串表达式；前后端均执行。HTML、非空 formatter/styler/脚本等执行入口继续禁止。原生上游属性仍存在，服务端保存检查是最终边界；不能将隐藏操作当成恶意模板隔离完成。
