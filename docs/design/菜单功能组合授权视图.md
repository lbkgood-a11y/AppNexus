日期：2026-11-09。

## 交互与组件

授权中心功能权限默认展示「菜单与功能」，保留「按资源查看」。两者使用同一 selected 权限 ID 草稿、变更原因和原子保存接口，不保存菜单授权关系。角色、数据范围、字段限制及离开保护沿用原实现。

复用 BusinessWorkspace、Element Plus Collapse、Checkbox、RadioGroup；新增 MenuPermissionBranch 只递归组合这些组件。原平面 ManagementTable 无法表达任意深度目录、页面与共享操作，因此增加最小递归领域组件，不新增 UI 库或交互体系。

目录下显示页面，页面下列出明确映射资源的真实操作；同一权限出现在多个页面时同步。目录勾选是当前筛选结果中启用权限的批选，不产生目录权限，不授予未来新增操作。无菜单权限显示于「其他功能（未关联菜单）」下按资源分组。没有权限关联的外部链接或页面不生成虚假勾选项。

隐藏和停用菜单仍参与授权定位；菜单显示状态不得导致已授权限无法维护。搜索、仅已选应用于菜单与资源两种视图，筛选外权限不参与批选。筛选结果为空时剪除空目录。同资源多页面共享操作属于显示复用，保存时仍去重。

## 服务端与安全边界

新增 GET `/bff/platform/authorization-navigation` 和 `/api/access/authorization-navigation`，前者复核平台授权管理能力，后者复核可信租户及现有租户 GRANT 管理能力。接口不接受客户端 tenantId，返回 no-store；普通账号或成员不得借此枚举完整授权目录。该目录不按操作者本人可见菜单过滤，不能用 `/bff/navigation` 替代。

NavigationQuery.AuthorizationNode 包含节点 ID、父级、中英文名称、排序值、受控资源列表和基础权限码。节点不包含外部地址。资源关联在服务端明确登记，不根据菜单名、路径前缀或树父子关系猜测。后续新领域必须同时声明页面与功能资源关联；未登记操作仍在其他功能组可维护。

当前映射包括平台租户/成员、账号、菜单、角色、租户角色及组织功能。多个页面可以关联相同资源。现有配置管理页面中无对应功能目录的能力不伪造操作。运行时菜单过滤和业务接口鉴权仍独立执行；本视图不自动建立读取依赖或授予外部系统资格。
