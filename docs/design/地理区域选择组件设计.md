# 地理区域选择组件设计

日期：2026-11-17；状态：选择组件及客商、仓库、人员字段已实现；单据查询尚未接入。

## 1. 目标与边界

提供统一的 GeographyPicker，供单据筛选、客户地址和仓库地址使用。用户可选择“中国”或“中国 / 福建”，返回稳定标识，不以显示名称关联单据。组件不负责保存单据，不授予单据读取权限，不在选择过程中创建或启用主数据。

当前目录包含 ISO 3166-1 国别地区、ISO 3166-2 行政区划，以及民政部截至 2025-12-31 的中国地县级目录。中国省级保留 CN-FJ 等 ISO 编码，下级采用 CN-MCA-350100 等系统命名空间标识，官方代码为 350100；CN-FJ-FZ 等人为拼接 ISO 编码不可使用。市县数据来源与验证见《中国地县级行政区划补充与验收》，不覆盖乡镇街道及官方资料缺失地区。

## 2. 组件选型与归属

已检查 frontend/modules/master-data/src/Management.vue 的地理单选框、@appnexus/ui 公共组件及现有 API。当前单选框仅用于维护档案，不能同时表达国家、区划路径和单据筛选范围；现有公共组件没有该领域选择能力。

在 frontend/modules/master-data 内新增 GeographyPicker，经 @appnexus/master-data 公开入口导出。组合 Element Plus el-cascader，不新增 UI 库、弹层系统或视觉主题。采用 checkStrictly 支持选择任意层级；默认单选，选项按需加载，搜索使用服务端接口。清空、加载、键盘、焦点和弹层交互沿用 Element Plus；重试和错误反馈复用全站能力。

## 3. 用户交互

| 场景 | 交互与规则 |
| --- | --- |
| 订单筛选 | 字段标签“业务区域”，可选中国或福建；选择后显示完整路径。旁边提供“包含下级”复选框，默认勾选；点击查询才触发订单请求。 |
| 地址录入 | 使用同一选择组件；必填与最少选择深度由业务表单决定。详细地址独立输入，不要求所有国家都有省、市、县四级。 |
| 搜索 | 按名称或编码搜索；结果显示完整路径与编码，可直接选择。只搜索已获准目录，不根据中文名称猜测拼音或编码。 |
| 切换与清空 | 选择其他国家时原区划同时清除；清空输出 null，含义为未限定区域，不自动选择中国。 |
| 历史记录 | 停用节点可回显并标注“已停用”，不得作为新地址选项；筛选模式允许选择已授权的停用节点查询历史单据。缺失节点显示快照及不可用状态，不能自动改成上级或其他编码。 |
| 数据故障 | 首次加载、无目录、无搜索结果、无权限和故障分别展示；故障提供重试，不用空结果掩盖 403，不退回硬编码选项。 |

筛选只把所选地理条件提交给业务接口，不由浏览器获取全部单据后过滤。界面文案进入中英文语言资源，兼容浅色、深色、系统主题和移动端；宽度跟随宿主表单。

## 4. 值契约与参数

组件 v-model 为 GeographySelection 或 null。单次选择只表达一个节点，路径信息作为只读展示，不允许客户端提交整棵目录来决定后代关系。

| 字段 | 含义与约束 |
| --- | --- |
| nodeId | 当前租户业务目录节点 UUID，关联的权威标识；服务端校验归属和状态。 |
| kind | COUNTRY_REGION 或 SUBDIVISION，必填，区分两类实体。 |
| countryCode | ISO 3166-1 二字码，如 CN；必填。 |
| codeSystem | ISO_3166_1、ISO_3166_2 或 CN_MCA；必填，CN-MCA- 前缀节点属于 CN_MCA，不可标为 ISO。此为待实现组件契约，现有 DTO 尚无该独立字段。 |
| code | 对应体系中的编码，如 CN、CN-FJ；必填，不以名称代替。 |

| 组件参数 | 含义、默认与边界 |
| --- | --- |
| mode | filter 或 address，默认 address；决定停用节点的可选规则，不决定后端授权。 |
| clearable | 默认 true；业务必填校验由 el-form 决定。 |
| disabled | 默认 false；提交中等宿主状态可设 true。 |
| readonly | 默认 false；true 时仅显示路径文本，不显示禁用输入框。 |
| countryCode | 可选国家限制，默认无限制；改变时不匹配的草稿必须清空并通知宿主。 |
| provider | 必填的已授权目录读取适配器，由应用装配层注入，复用现有 HTTP/会话链。 |

update:modelValue 返回上述值；change 可附带只读的路径名称，供即时展示。后端保存单据时重新解析目录生成地址名称快照，不信任客户端路径、名称或节点归属。

includeDescendants 是宿主筛选条件，默认 true，不属于地址值。单据必须明确区域所指的业务维度，例如收货地区、发货地区或客户注册地区；同一查询不得把多个维度混为“福建订单”。

## 5. 目录接口与授权

现有 standards=true 返回构建时完整 ISO 参考快照，且要求主数据管理读取权限；它不等于当前租户已启用业务目录，不能直接作为业务选择接口。

新增主数据公开的只读地理目录契约，分别支持查询国家、按国家及父节点读取子区划、搜索路径、按标识解析回显。响应包含节点标识、编码体系、编码、名称、状态、hasChildren 和路径。分页限制与搜索长度需在实现接口时同步写入中文参数说明；禁止利用普通列表的默认 20 条构造残缺目录。

主数据维护入口继续使用原有管理权限。业务选择接口通过已登记的主数据引用读取能力授权，由服务端复核可信租户及调用场景所需业务权限；不能为了选择地区而给订单操作员授予主数据维护权限，也不能接受客户端任意 permission 字符串作为授权依据。

目录缓存仅在当前会话及租户范围复用；切换租户、退出和撤权时清理，刷新后重新读取。异步请求采用取消或序号校验，迟到的旧国家或旧租户响应不得覆盖当前选项。

## 6. 单据查询与后续层级扩展

示例：宿主提交“收货地区 = 福建，包含下级 = true”，查询服务先校验订单读取权和区域节点归属，再由主数据公开契约解析福建及其后代范围；最后与原有租户、数据权限及其他筛选条件取交集。区域筛选永远不能扩大数据权限。

单据存储选定节点、编码体系及服务端生成的地址快照；相关字段在具体单据设计中定义，禁止只存“福建”文本。以 nodeId 关联时，编码在同租户和体系内唯一，正常维护不得更换其含义。国家节点覆盖国家本身及所属区划，区划节点覆盖本身及真实后代；includeDescendants=false 仅匹配单据实际记录的节点。

选择福建只能查到已正确标记区域且有读取权限的单据；未填区域的历史单据不会自动归属福建。市县目录已接入，单据关联、历史归属和更名策略仍需在实际业务实现中明确。目录加载已校验无环、同国别归属、缺失父级及重复编码；不得从名称或代码前缀猜测后代。按当前有效目录解释“包含下级”；如需按下单时行政边界统计，另行设计有版本的归属快照。

## 7. 实施与验收

1. 先交付租户业务目录公开读取契约和授权，验证国家归属、启停规则、路径与搜索；补齐已有租户和新租户初始化闭环。
2. 实现 GeographyPicker 并公开导出，先在真实地址录入场景接入；主数据维护的 ISO 标准选择继续保留其独立用途。
3. 订单对象交付时接入区域字段、服务端快照、数据权限和包含下级查询，不提前展示无法执行的“福建订单”入口。
4. 验证国家/区划选择、搜索、切换国家、清空、历史回显、停用、无权、失败重试、迟到响应及跨租户隔离；后代查询覆盖本身、子节点、无父级和环检测。
5. 完成类型检查、构建、操作引用门禁及真实接口验证；在 1440×900、1024×768、390×844 验证中英文、键盘和深浅/System 主题。涉及新表时首次建表直接包含四个中文说明的审计字段，并执行 GlobalRecordAuditTest 全表检查。

## 8. 首批实现与既有字段接入

组件通过 @appnexus/ui 公开导出 GeographyPicker，供主数据及组织领域共用，避免组织包反向依赖整个主数据领域。检查现有组件并实际验证完整 TreeSelect 后发现展开卡顿，最终国家与区划均采用 Element Plus SelectV2 虚拟列表。按真实父级构建完整路径供搜索及展示，只渲染可视选项，不一次渲染八千多个树节点。当前租户约 8473 个摘要一次读取，免除默认分页截断；树索引共用。未引入新 UI 库。此实现覆盖本节与早期方案不同的部分。

首批字段：客商 countryRegion/registeredPlace，仓库 region，人员 nativePlace，以及地址 countryRegion/province/city。详细地址、联系人地址、账单地址仍为详细文本，不把门牌地址误改成行政区划。地理主数据自身维护页仍使用标准编码检索，不以租户已建目录代替创建标准目录。

现有业务字段均为字符串，本次新选择保存稳定 code，缺省或清空为空字符串；不改变现有表结构。历史未知文本原样回显，不自动推断或迁移。只读字段和明细按目录路径显示名称，缺失时显示原值。国家或省份改变清空旧下级，先选地区时回填所属国别。省/城市分栏只是既有字段适配，不假设所有国家都有相同层级；统一 region 允许选择真实任意层级。未实现订单关联及地址快照，不宣称本次已可递归查单据。

Geo­graphyCatalog 是 platform-configuration 公开读取端口，由主数据实现访问自己的表。客商/仓库复用各自 list 的 geography=true 分支，人员复用 Person.options 的 geography=true；参数默认 false，仅返回当前可信租户的节点摘要，保留原业务读取权限，不需要主数据维护权限。接口复用原操作声明，不新增重复操作；客户端不能传租户、账号或权限码。全目录不持久化到浏览器存储，页面卸载即释放，沿用应用切租户重建机制。停用节点保留用于回显，停用祖先的下级不可新选；残缺父级或环不伪装成可用根节点。

保存继续沿用各对象真实权限、CSRF、版本、事务和审计。历史自由文本字段仍接受其既有后端契约；本次组件限制不等于新增了服务端强引用约束，未来单据引用应按第 6 节单独交付。

验证记录：公共层级测试 3 项通过，覆盖福建路径、省市限制、错误国别、环、未知历史和停用祖先；前端类型检查及生产构建通过。MasterDataServiceTest 10 项及真实 MySQL GeographyMigrationTest 通过，包含宿主读取权拒绝和目录跨租户/停用状态验证。执行输出位于 .local/geography-picker-*.log。本机后端更新并成功启动，监听 8080。

### 标准目录分页（2026-11-17）

国别与行政区划标准选择复用 Element Plus Select 的远程检索和 footer 中的 Pagination，不新增组件。标准接口 standards=true 返回 rows、total；keyword 按编码或名称不区分大小写检索，page 默认 1（最小 1），size 默认 20（1–100），非法分页返回 400。先筛选再按编码排序分页，保留原对象读取鉴权。列表加载不再预取标准目录；新增弹窗只读取第一页，每页 20 条，搜索回第一页，翻页替换选项，过期响应不覆盖新结果。空结果使用现有国际化空态，失败走统一浮层；提交仍由服务端复核标准编码。

本次验证：后端编译通过；分页测试、前端类型检查及构建结果见交付说明。真实浏览器交互、深浅主题和移动端尚未验收。
