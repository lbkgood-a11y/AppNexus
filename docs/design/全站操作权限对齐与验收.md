# 全站操作权限对齐与验收

日期：2026-11-10。本批针对已交付页面的真实操作、目录权限码、按钮状态、后端拦截和授权中心映射统一修复，不替代一期其他未交付功能。

## 修复原则

页面使用 `NavigationPages.operations` 的明确操作集合，不按资源整组展开。同一业务操作可以有多个按钮，例如根节点/下级新增共享 create；启停若由编辑保存执行就使用 update，不虚构不存在的独立权限。平台角色与授权中心分别登记真实使用操作，共享读取按权限 ID 去重。

`EndpointOperationInterceptor` 现在覆盖 `/api/**` 与 `/bff/platform/**`。平台身份只是既有管理准入，不表示拥有全部操作；每次请求必须通过方法操作码，平台代管租户以 `platformPermission` 显式检查 `tenant.role:*` 平台能力，不能跳过或拿租户码作为平台码。目标账号、租户、成员、角色、最后管理员保护、MFA、CSRF、乐观锁、行/字段权限继续由原用例独立验证。

本人平台资格探测 `/bff/platform/access` 仅返回本人资格，不要求 tenant:read，以免只有账号权限的管理员无法进入账号页。本人资料/密码/MFA/会话/接受邀请、导航和租户选择继续执行本人身份契约，不伪造可以分配给他人的管理权限。合作方 API 继续固定租户 Client Credentials 与 scope，不复用用户操作快照。

## 敏感操作拆分与迁移

V45 停用无独立执行点的菜单 enable/publish，编辑含启停使用 update。V46 新增账号 enable/revoke_sessions/reset_password，租户 enable，成员 create/enable/remove，邀请 read/create/revoke，集成客户端 read/create/update/rotate_secret，平台任务 read/retry，平台审计 read，以及平台代管租户角色 read/create/update/delete/grant。

迁移只将原宽权限角色的对应能力逐角色复制到新码，不对其他角色默认赋权；既有范围原样保持。迁移之后可以单独撤销新操作，不会因仍持有 update 自动恢复。历史授权不删除，所有新定义有中文用途及默认拒绝边界。没有修改已发布迁移。

组织类型/单元/关系/岗位/任职/负责人沿用已发布组织 CRUD 语义；明确对应创建、修改、读取、删除。特别修正 POST 移动组织的过滤器判断为 UPDATE，不能因 HTTP POST 要求 CREATE。固定聚合 summaries 也进入 read 操作门禁，普通有效成员不能调用聚合推断无权计数。

## 前端状态

沿用模板的自定义指令注册入口新增最小 `v-operation`：已有 auth/perms 读取的是展示角色/静态权限，不能满足权威能力重读和租户切换隔离，因此增加薄适配，继续使用现有 Element Plus 按钮，不新增 UI 组件体系。

统一快照 `/bff/operation-capabilities` 和 `/api/operation-capabilities` 只返回当前主体有效操作。初始/故障/切租户默认隐藏，30 秒及焦点恢复复核；授权类写入成功后立即失效重读。注销清空快照，旧账号在途响应不得恢复新账号按钮。后端逐请求鉴权保证撤权立即影响请求，不能把按钮刷新间隔当作安全宽限。

账号、租户成员、邀请签发、集成客户端、角色与授权保存/模板、组织、字典和租户参数写入已接通统一门禁或原精确 capabilities。查询/重置/刷新/取消、表格密度/列设置/全屏只属于展示操作，不增加虚假的业务权限。邀请与直接添加分别检查 invitation:create 与 member:create，提交按钮根据实际模式选择。

## 验证与限制

自动枚举测试会逐个调用全部已登记平台管理端点及租户业务端点，使用真实 MySQL/Valkey 建立有效平台身份或租户成员、但不给任何操作权限，要求逐个 403；同时检查所有权限码有效且管理域一致。另验证授权后能力快照出现、撤销后下一次查询移除。架构测试要求全部平台路径登记权限，以及代管租户必须登记平台权限，避免新 Controller 漏入。

前端测试覆盖异步证明前隐藏、撤权事件后隐藏、读取故障不扩大权限、租户角色启停映射 update、注销后旧账号响应不恢复按钮。全部最终检查结果见任务记录。

真实 Windows 浏览器工具无法可靠确定当前 URL，已自动停止 UI 操作；没有继续控制该窗口、改动真实管理员凭据或改写真实角色。登录后完整按钮/撤权、深浅主题、英文和三视口浏览器验收不能标记为已完成。
