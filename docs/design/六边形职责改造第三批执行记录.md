# 六边形职责改造第三批执行记录

日期：2026-11-19。状态：实现与验证中。覆盖商品主档创建、编辑、启停和归档，工作流任务办理，以及打印模板发布；不代表整个商品、工作流与打印服务已完成改造。

## 用例归属

| 用例 | 应用及公开类型 | 输出适配与原子边界 |
|---|---|---|
| 商品创建、普通编辑 | api.product.ProductMainData；application.product.ProductMainService、ProductMainPort；domain.product.ProductMainRules | ProductV1Service 暂提供固定操作的过渡输出适配；保留引用校验、属性写入、完整性、父 CAS、审计与事件的原事务 |
| 商品启停与归档 | ProductLifecycleService、ProductLifecyclePort；原 ProductLifecycle 规则 | 先实际授权，再父行锁与原版本校验；审批冻结、启用审批依据、完整性通过后才写状态、版本、审计及事件 |
| 任务暂存及完成 | workflow.application.TaskCompletionService、TaskCompletionPort | WorkflowRuntime 原 mutate 幂等事务包裹；先锁实例再重读锁任务，复核当前任职、候选、提交依据及输入，业务执行成功后推进引擎 |
| 模板发布 | printing.application.TemplatePublicationService、TemplatePublicationPort | PrintRuntime.publish 保留事务装饰器；行锁固定草稿与版本，字段契约验证成功才追加不可变发布版本及推进指针 |

本轮不新增迁移，不修改 HTTP URL、JSON 字段或原错误码。商品稳定输入类型从混合 Service 嵌套类型迁至公开 API，调用点同步调整；不通过核心技术构造器获取实现。复杂协作者尚未完全拆出，过渡适配仍位于原运行时并在说明中明确，不把应用提取等同于全部存储职责纯化。

商品 ProductMainRules 保留原文本长度、控制字符、编码及 UUID 校验。values=null 保留属性，空列表清空；启用记录修改后不完整必须回滚。普通编辑不能更改分类、结构、固定配置和基础单位。

工作流应用不依赖 Flowable、JDBC、Spring 或 JSON；端口使用已锁事实与不可变发布节点。原任务幂等键、业务快照重读、pending 拒绝、SAVE 不推进、拒绝结束实例与取消非终态作业、任务对账保持。任务重分配、超时维护和可靠交付尚未在本批迁移。

模板草稿保存、历史恢复、目录列表及 JSON 字段遍历仍在原技术实现。应用只协调发布准入、版本、快照验证和追加，不扩大 publish 权限为 design/read；发布失败不得推进版本。其他模板用例继续列入后续范围。

## 验证与包说明

新增 ProductMainData 使用已有公开 API 包；新增商品应用测试包提供中文 package-info.java；商品、工作流和打印应用包说明同步更新。架构门禁要求主档、生命周期、任务办理和模板发布类型实际存在，应用不得依赖技术框架。

测试包括主档无权不访问输出端口、启用商品不完整不提交事件、草稿不能停用、审批完整性先于写入、失效任务不执行业务、审批依据变化不完成引擎、模板版本冲突不生成历史、契约验证先于发布。真实数据库沿用 ProductCatalogMySqlTest、FlowableMySqlTest、PrintingRuntimeTest 和 ProductApprovalWorkflowIntegrationTest。

第一轮增量 test 的业务检查执行后，架构检查因平台业务对象迁包产物缺失及空扫描失败，不视为通过、不放宽门禁。随后使用顺序 clean verify 验证最终源码。最终命令和结果待完成后填写。

主档输入类型迁移后的干净构建发现 Controller 旧静态导入已失效，已显式导入公开 ProductMainData，保留原 JSON 协议。此编译失败轮不计为通过。
