# 单据服务集成契约设计

日期：2026-11-12。状态：架构边界及统一契约要求已确认，以下接口划分、协议及字段为详细设计草案，未实施。

完整调用与一致性语义见[单据业务接入闭环协议](单据业务接入闭环协议.md)，补充提供者定位、审批轮次、可信绑定、远程提交恢复、打印历史语义及来源对账。

## 1. 已确认的架构

单据模块为能力配置与关联中心，与实际业务解耦。平台决定系统有哪些单据及每个租户具备哪些单据配置权限；租户在授权范围内维护单据与流程、打印等通用服务的关系。配置管理权限不等于业务操作或数据访问权限。

后端提供统一契约供未来业务服务集成，不允许业务直接查询配置表或依赖单据服务内部实现。建议建立 document-contracts 和平级 document-service，首期组合启动；独立部署不作为前置条件。

业务服务拥有单据内容、状态、授权、校验、事务、幂等和行为执行。流程及打印服务拥有各自任务和权威状态。单据服务不读取业务数据库，不接收完整业务实体，不向业务服务下发任意命令。

## 2. 契约包和协议

document-contracts 提供不依赖 Spring、MyBatis、Flowable 或具体业务的身份、声明、绑定请求/结果、关联事实和错误模型。Java 接口用于同进程装配；面向未来独立业务服务同时维护 OpenAPI 和事件 Schema，以协议实现跨语言接入，不能仅靠共享 Java 包宣称支持远程集成。

同进程与远程适配遵守同一语义，但不承诺同一事务。HTTP 暴露范围遵循现有 API 命名与生命周期规范，不因属于业务服务集成就自动开放为合作方 API。具体路径及服务认证方案在接口详细设计中确定。

## 3. 对外能力

| 契约 | 调用方 | 职责 |
| --- | --- | --- |
| DescriptorRegistration | 获平台授权的业务服务/部署发布流程 | 提交不可变类型、投影、行为及支持能力声明，形成待审核候选；不能自行激活系统目录 |
| DocumentCatalogQuery | 获授权管理端或业务服务 | 查询可见类型、契约版本、依赖及目录状态；不返回业务原文 |
| TenantConfigurationGrant | 平台管理端 | 按单据类型授权给租户；授权后租户管理角色可维护关系配置，首期不拆分能力使用资格和逐能力配置资格 |
| BindingConfiguration | 获授权租户配置人员 | 管理草稿、校验、发布流程/打印绑定；不能修改代码契约或扩大平台授权 |
| BindingResolution | 已认证业务服务 | 按租户、类型、行为、用途及可信条件解析固定绑定，返回可追溯结果 |
| RelationReporting | 已认证业务/流程/打印服务 | 上报自身拥有的关联事实，幂等更新关联投影 |
| RelationQuery | 获授权调用者 | 查询有限关联与来源，不以关联存在授予原文访问权 |

单据模块不提供通用 submit、approve、print 执行契约；这些能力使用业务及专业服务已有公开端口。系统支持哪些单据由平台审核激活目录决定，服务自动发现或部署声明只是登记来源。

## 4. 绑定解析输入与输出

| 字段 | 语义和约束 |
| --- | --- |
| context | 由可信身份链建立租户、调用服务和实际操作者/委托；服务凭据不意味着可任意选择租户 |
| requestId | 必填、无默认值，UUID 请求键；租户、服务、单据、行为范围内幂等，同键异输入拒绝 |
| documentReference | 类型、对象 UUID；首次创建前无实例的行为首期不接入绑定解析 |
| actionCode / purpose | 必填、无默认值，仅接受已登记且平台开放的行为及用途 |
| basisVersion | 流程依据版本，非负整数；需要审批时必填，由业务服务读取，不接受浏览器自由声明 |
| contractReference | 条件投影契约编码与版本，必填、无默认值；不得以最新版隐式代替 |
| facts | 业务服务授权后从存储取得的有限非敏感标量；仅接受声明字段、类型及比较器，不传完整实体 |
| resolutionId | 服务端返回 UUID；关联本次解析及规范化输入摘要，不作为授权凭证 |
| configurationVersion | 返回实际发布版本，供业务执行及关联记录固定使用 |
| target | 返回流程定义及具体发布版本，或打印场景与兼容契约引用；不包含任意目标 URL |
| resultHandlers | 流程绑定返回已声明处理动作及其固定映射；由业务侧处理结果，单据服务不调用处理器 |

流程零匹配、多匹配分别拒绝。打印场景内部模板选择由打印服务负责；解析得到场景不意味着模板已确定或打印已获授权。返回值表示配置解析成功，不表示业务行为执行成功。

解析结果固定后重试返回原结果；调用方持久化解析关联，业务失败后的重试使用稳定键，主动发起新业务尝试才使用新键。已解析配置不能绕过执行时身份、业务版本、依赖停用及紧急安全限制检查。配置解析记录不保存敏感字段原值；留存期限及清理策略在实施前明确。

## 5. 关联上报与一致性

关联事实至少包含 eventId、producer、tenantId、documentReference、relationId、relationKind、目标资源标识、用途、配置解析引用、来源版本和发生时间。必填身份属性由认证校验，不直接信任事件中的 producer 或 tenantId。时间使用 RFC 3339；不以时钟先后作为唯一事件顺序。

来源服务拥有权威关联，单据模块仅保存查询投影。业务来源可声明单据与流程的关联，流程来源才能更新流程执行事实，打印来源才能更新打印状态；跨来源字段不能相互覆盖。每条来源关联有独立单调版本，重复 eventId 去重，旧版本不覆盖新版本；版本缺口记录并触发查询核对，不编造缺失事实。

发布者在本地业务事务中保存关联与 Outbox，异步投递、重试和对账。消费者确认以本地持久化为准；投影延迟不回滚业务事务。首期未完成单据级查询授权时，不提供面向普通用户的跨单据关联检索，仅开放受控服务查询或管理诊断。

单据模块不可用时，首次需要解析的新行为失败并返回明确错误；既有流程办理、可信结果回写和已创建打印任务直接依赖已固定关联继续运行。关联事件可积压补发，不能成为业务完成的同步前置条件。

## 6. 权限、目录和配置生命周期

已确认简化规则：平台控制系统单据目录，按单据类型授权给租户；授权后租户管理角色具备该单据关系配置的查看、编辑和发布权限，不另建逐能力配置授权或独立配置角色分配。租户已有独立创建审批流程和打印场景的能力，工作台直接选用本租户已有且兼容的资源，不再要求平台逐项批准流程或场景。登记新契约不自动纳入平台目录，版本仍须校验兼容。授权收回后的旧绑定处置另行细化，当前不增加复杂治理流程。

不在单据模块增加独立能力使用资格、额度或订阅检查。普通用户使用配置后的审批和打印仍沿用现有业务、工作流及打印权限；业务服务解析绑定不要求该用户具有管理角色。租户隔离、资源归属、契约兼容和系统行为可信来源继续校验，管理角色不能因此读取全部业务原文。

错误模型至少区分未登记/未激活、调用方越权、配置未发布、契约不兼容、未匹配、匹配冲突、依赖失效、幂等冲突、版本冲突和暂时不可用。对未授权调用者合并资源存在性提示；结构化错误不得回显敏感条件值、凭据或完整业务对象。

## 7. 请假接入示例

1. 请假模块部署 LeaveRequest 声明，平台审核并纳入目录，将该单据授权给指定租户。
2. 租户管理角色选用本租户流程和打印场景维护并发布关系；打印绑定仅在真实提供器和场景可用后发布。
3. 用户提交请假时，请假服务复核权限、组织、状态和依据，从存储读取 days，调用 BindingResolution。
4. 请假服务固定解析结果，调用工作流精确版本启动接口，在支持的本地事务内保存单据状态及权威关联。
5. 工作流将可信结果交付请假服务，后者复核并幂等回写；各来源通过 Outbox 上报关联事实。
6. 用户打印时，请假服务独立授权取数，解析打印场景，调用打印服务；打印结果关联异步汇入单据模块。

当前 WorkflowStarter 尚无精确版本启动参数，打印契约也未提供完整业务提供器桥接；上述是目标接入设计，不表示已经支持。

## 8. 接入交付门槛

统一契约需提供中文参数文档、OpenAPI/事件示例、版本兼容规则、错误码、同进程示例和远程认证约定。至少覆盖平台未激活登记、租户超范围配置、无配置权但有业务权、伪造租户/来源、同键异参数、契约升级、乱序重复关联、断线补发及中心不可用时的历史执行。

下一步形成接口 Schema 与数据库模型；SDK 只封装协议、错误和关联上报，不接管业务事务，不引入业务领域依赖。当前仅更新设计，未新增服务、接口或默认配置。
