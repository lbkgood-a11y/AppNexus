## 实测问题及修复

- 租户切换动态路由暂时删除时，旧 SidebarLinkItem 仍按旧 name 解析，抛出 No match 并中断渲染。改为站内稳定 path 解析；浏览器双向切换无需刷新，导航重建正常，增加路由删除回归测试。
- 工作台表单采用循环数组 ref，在重开或重载中容易残留表单，且保存缺少持久反馈。改为按绑定 ID 管理在场表单、失败明确反馈，并保留成功 Alert；浏览器保存后确认数据重载并再次打开保留。
- 关系移除按钮误用“移除条件”，已改为“移除关联”。
- 请假 DATE 返回为 UTC 时刻，列表/原文显示前一日 16:00，编辑截断存在减一天风险。业务层将 SQL DATE 转为 ISO YYYY-MM-DD，不改变存储与自然日计算；添加创建及列表返回日期断言，继续回归。
