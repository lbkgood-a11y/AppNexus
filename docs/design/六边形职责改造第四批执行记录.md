# 六边形职责改造第四批执行记录

日期：2026-11-19。状态：实现与验证中。本批覆盖复杂属性准备、商品聚合快照查询、结构迁移执行协调、工作流任务重分配和模板草稿编辑；不宣称整个服务或全部技术协作已完成迁移。

## 归属与边界

| 范围 | 应用/公开类型 | 输出实现与约束 |
|---|---|---|
| 复杂属性 | ProductAttributePreparation、ProductAttributePreparationPort | 原固定配置定义及选项查询由技术端口提供；应用校验项数、唯一性、精度、类型、枚举互斥和自定义项；白名单规则JSON解释器仍在旧技术协作 |
| 聚合快照 | JdbcProductSnapshot | 从 ProductV1Service 提取完整固定查询，父记录经 ProductRecords；明细仍按可信租户与父ID限定，字段、顺序、完整性和四审计投影保持 |
| 结构迁移 | api.product.ProductStructureData；ProductStructureService、ProductStructurePort | 原入口保留授权、输入校验、预检摘要、十秒事务与技术异常映射；应用协调锁后重放、源匹配、目标验证、证明、退出项、完整性及原子写入 |
| 任务重分配 | TaskReassignmentService、TaskReassignmentPort | 原 mutate 包裹权限、原因和幂等；先锁实例再重读锁任务，按当前任职/固定节点候选复核并拒绝重复OPEN分支；引擎、任务与审计共同提交 |
| 模板编辑 | TemplateEditingService、TemplateEditingPort | 先设计授权再JSON安全验证，标识与字段验证后新增或CAS编辑；不发布，不改变原读取权限及事务边界 |

结构迁移继续保持成功重放不重新验证旧token，首次执行必须父锁后重查幂等。MySQL外键下先撤值、改父配置、再写新值的顺序、原创建审计保留、规格退出、组件失效、历史事件与七天回执保持。SQL、锁与JSON写入仍在固定输出适配中，不把迁移写入拆成多个事务。

快照没有引入任意表名查询，也没有新增未授权全局读取入口。JdbcProductSnapshot 内使用原完整性计算回调，后续可进一步细化为类型化事实；不能仅因查询迁包就宣布快照业务规则全部纯化。

模板编辑应用不依赖JsonNode。输入DTO仍在原HTTP技术边界，通过端口保持原PrintJson脚本/可执行扩展拒绝。publish与design/read权限关系不变，不为方便测试扩大权限。

## 测试与门禁

本批使用已有职责包，同步更新中文package-info.java，无空包或新UI。架构测试新增真实生产类型存在性，既有应用无技术依赖规则自动覆盖新增用例。

新增反向测试覆盖：小数超精度拒绝、外租户/修订或停用选项拒绝、结构重放无重复写入、失效预览无写入、任职失效与同节点重复任务拒绝、模板无权不解析内容、CAS失败不返回成功。

计划以顺序干净Maven验证新增应用测试，并执行原真实商品MySQL、Flowable、打印模板/回执、商品审批和架构检查。命令与最终结果完成后填写。未部署或重启共享实例，未改数据库迁移、表结构或前端。
