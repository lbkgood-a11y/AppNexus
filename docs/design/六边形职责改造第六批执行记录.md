日期：2026-11-19。状态：实现与验证中。范围为商品属性白名单规则解释、分类/配置/单位引用读取及候选与固定配置查询。

| 范围 | 归属 | 边界 |
|---|---|---|
| 规则解析 | 原ProductAttributeRules技术协作 | 仅解析JSON对象，保留字符串、数值、整数标志与原转换语义，未知键不丢弃；语法及解析异常映射原错误码 |
| 规则判定 | domain.product.AttributeRulePolicy | JDK标量视图上校验白名单、整数长度、枚举数量、精确十进制和自然日上下限，不依赖Jackson、Spring或JDBC |
| 引用及目录读取 | ProductCatalogReads / JdbcProductCatalogReads | 固定分类、配置、模板、单位、选项SQL；可信租户条件、分类→模板→单位锁顺序、预检不加写锁保持 |
| 目录查询用例 | ProductCatalogQueryService | 每次先复核masterdata.product:read，候选、配置列表和配置详情不得探测无权记录；原参数及分页门限保持 |

原ProductV1Service不再包含这三条目录查询和引用读取的SQL，作为组合入口注入应用及固定适配。参数校验仍由目录适配保留，后续可进一步提取类型化查询；不把本批当所有商品列表/过滤查询已迁移。公开HTTP协议、字段、错误码及历史配置可读语义不变。

规范执行：沿用已有domain、application与adapter/jdbc包，更新中文package-info，架构门禁检查新增真实类型存在及应用/领域不引用技术实现。未新增UI、依赖、迁移或数据库表。

测试计划包括原规则解释用例、JSON类型反向验证、读取权限先于所有输出调用，以及真实商品MySQL、商品审批与架构门禁。首轮纯领域提取遗漏JsonNode方法名替换导致编译失败，已修正为JDK规则视图，不计为通过。最终结果待完成后填写。

剩余：商品列表动态属性过滤、完整性事实查询、JSON规则解析技术协作的物理归包仍可继续收敛；本批未修改功能授权或数据范围标准，未部署共享实例。
