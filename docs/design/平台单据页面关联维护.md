# 平台单据页面关联维护

> 当前接入与契约规则以[数据契约与单据接入收敛](数据契约与单据接入收敛.md)为准；下文人工页面接线规则保留为历史记录。

当前交互协议见 [统一交互契约模型](统一交互契约模型.md)。页面关系只从平台保存数据读取，已删除代码默认关系回退。

日期：2026-11-13。范围：平台显式维护行为与页面关系，不动态生成业务接口或改变执行处理器。

## 操作入口

平台管理 → 单据管理 → 打开请假单 → 页面操作关联。点击添加关联，先选择单据行为，再从业务已经接入的兼容页面操作中选择入口，可关联列表与详情别名，保存页面关联后立即生效。关联表展示页面名称、操作标识、真实业务处理接口及权限引用。

平台维护的是全量关系集合，可以新增、移除和重新建立关系。修改行为会清空旧入口，必须重新选择兼容操作；提交不能关联打印接口。不存在的页面/API 无法通过手工填地址接入，必须由业务开发先实现。权限体系与页面业务接口都不因保存关系自动扩权。

租户工作台继续维护“行为 → 直接/审批/打印策略”，其页面选项来自平台已建立关系；平台关系与租户策略的保存按钮、版本和权限分别独立。配置页面仍采用 ManagedDialog、Element Plus Select/Table/Button/Alert，不新增 UI 库或平行布局。

## 实际执行

新增 V66 doc_page_relationships 保存类型级关系集合、乐观锁 revision、更新人及时间，变更追加 doc_audit。初次未维护的类型不开放页面入口；平台保存后以完整集合为唯一依据；显式保存空集合表示关闭所有页面入口。新增部署页面不会自动加入已有自定义集合。

首次保存 revision=-1，后续原样回传读取版本；并发覆盖返回 DOCUMENT_VERSION_CONFLICT。未知或重复入口、跨动作错绑返回 DOCUMENT_PAGE_RELATION_INVALID。保存关系立即影响新页面命令，不需要重发租户策略。

租户目录基于代码声明生成有效关系投影：未关联规范入口的 pageOperation 为空，未关联别名从 aliases 移除，业务动作和权限元数据保持不变。租户原草稿仍可读取，以便管理员修复已撤销引用；保存/发布不能继续使用撤销页面关系。

公开 DocumentBindings.verifyPageOperation 供业务页面命令执行前调用，服务端每次重新检查平台关系，不依赖按钮是否隐藏。请假提交和两个打印入口均已接入，actions API 返回各入口独立 allowed；详情打印不再由列表打印的授权展示结果推断。

历史工作流结果回写不检查新的页面关系，避免平台调整入口使已批准单据无法完成。远程服务的纯后台动作解析不等于页面命令，不因移除页面入口隐式关闭已登记业务服务能力。关系管理是配置中心职责，业务数据授权、状态与事务仍由业务服务负责。

## 验证

真实 MySQL/Flowable 测试覆盖未维护关系为空、平台保存和重读、非平台操作者拒绝、错绑拒绝、首次保存冲突、仅保留详情打印、列表入口执行拒绝、租户目录过滤、空集合关闭全部入口、旧草稿可读及撤销引用不可发布。已有直接/审批/打印链路继续回归。

本机日志使用 `.local/document-platform-relations-*.log`。浏览器实际点击、主题与移动端视觉验收尚未完成，自动测试不替代页面验收。不自动替用户保存实际关系或改动租户策略。

本次真实数据库/业务入口 4 项测试、前端已有 6 项测试通过，admin 类型检查、生产构建及后端组合包构建通过；本地 V66 已执行，组合服务成功启动。未维护的类型不授权任何页面入口；候选声明只用于平台选择，不能替代已保存关系，未替实际租户保存任何新策略。
