# 原生客户端认证接入与验收

日期：2026-11-10。本文说明服务端公开 OAuth 客户端、Refresh Token 重放边界和第一方 API 的租户绑定。仓库没有 iOS/Android 应用工程，系统浏览器、App Link 和安全存储需要调用方按本文完成真机验收。

## 部署与注册

先执行 V35，设置 `APP_NATIVE_REDIRECT_URI` 为客户端所有者控制的精确 HTTPS App Link。默认空不创建注册；无通配、fragment 或 URL 用户信息。注册标识 `appnexus-native`，认证方式 `none`，授权类型仅 `authorization_code` 与 `refresh_token`，强制 PKCE，要求授权同意。启动检查已持久化回调、认证方式、授权类型、PKCE 和禁止刷新复用，不随重启静默覆盖注册。

Access Token 默认 5 分钟；Refresh Token 族绝对 7 天，每次刷新轮换且不延长绝对时间。参数仍须在目标部署风险及容量验收中确认。配置注释位于 `application.properties`，无客户端密钥可分发给 App。

## 标准登录

1. 使用 iOS `ASWebAuthenticationSession` 或 Android Custom Tabs 访问 `/oauth2/authorize`；请求 `response_type=code`、`client_id=appnexus-native`、精确 `redirect_uri`、`scope=openid profile`、不可预测 `state`/`nonce`、`code_challenge_method=S256` 和 PKCE challenge。
2. App 校验回调 `state`，通过 `/oauth2/token` 使用 `authorization_code`、原始 verifier 和相同回调换取凭证；禁止密码模式和 Implicit Flow。
3. OIDC ID Token 验证 issuer、audience、nonce、有效期与签名。Access Token 是不透明凭证，不由 App 解码为业务授权。
4. Refresh Token 放 Keychain/Keystore 支撑的加密存储，Access Token 优先内存。不得放 WebView、URL、日志或普通持久存储。

## 租户上下文

- 使用 Bearer 访问 `GET /api/tenants`，只返回该账号当前有效租户成员关系；Cookie 不认证此端点。
- `POST /api/tenant-context` 提交 `tenantId` 选择意图和 `expectedVersion`，首次版本为 0。服务端锁定账号和设备授权，复核租户、成员及当前版本，返回可信 `tenantId/memberId/version/refreshRequired`。
- 上述绑定或切换使当前 Access Token 失效；客户端必须通过标准 `/oauth2/token` 的 `refresh_token` 授权取得新 Access/Refresh Token。绑定接口不签发自定义 Token，也不把客户端 tenantId 直接当数据边界。
- 新访问凭证带服务端可信上下文版本。业务 `/api/**` 每次复核 Token 与授权版本，以及成员/租户仍有效；旧 Token 不得重新解释为新租户。切换后写请求沿用 `X-Tenant-Context-Version` 陈旧请求保护，值必须等于绑定响应版本。
- 平台 BFF 不接受该 Bearer 身份；原生 API 采用独立无状态链，不从 Cookie 补充认证，也不要求 Cookie CSRF。租户业务功能、数据及字段权限继续使用既有统一管线。

## 刷新和撤销

刷新请求向 `/oauth2/token` 提交 `grant_type=refresh_token`、`client_id`、当前 Refresh Token。服务端保留 Token 历史摘要，按账号/授权固定顺序锁定权威行，框架继续校验客户端、scope、授权和 Token 状态。相同 Token 并发使用最多一条成功，另一条视为重放并撤销对应设备授权；首次响应即使成功，其 Token 也会因随后检测重放而失效。

旧 Token 重放撤销和审计必须先提交，再返回 `invalid_grant`，避免异常使撤销回滚。未知摘要、其他客户端提交或已过期历史不允许撤销另一设备。账号停用、改密、MFA 变更或管理员强制下线拒绝旧授权。`REFRESH_TOKEN_REPLAY` 不记录 Token 原文。

V35 只新增历史摘要；框架标准 JDBC OAuth 仓储仍管理协议 Token，不宣称全库 OAuth Token 均已哈希保存。摘要清理、完整设备信息和统一设备目录还需后续后台任务增量。

## 验证状态

`NativeRefreshTest` 6 项通过：公开客户端 S256 授权码换取刷新凭证、轮换保持族绝对到期、旧 Token 重放撤销、跨客户端/未知 Token 隔离、账号停用拒绝、并发刷新，以及租户绑定后旧 Access Token 失效、刷新后进入业务权限管线、停用成员拒绝和平台 BFF 拒绝。Web 登录 HTTP 与租户切换回归通过。

服务端测试不代替真机系统浏览器、Universal/App Link 所有权、安全存储及端侧 nonce/state 校验验收；当前没有相应真机证据。
