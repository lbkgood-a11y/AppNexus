# 统一交互契约模型

> 当前接入与契约规则以[数据契约与单据接入收敛](数据契约与单据接入收敛.md)为准；下文人工页面接线规则保留为历史记录。

日期：2026-11-13。开发阶段采用唯一运行协议，不保留旧版解析分支。

## 唯一声明与专业投影

业务提供者登记 Descriptor → Action → InteractionContract。契约身份为 code/version；objectType/actionCode 必须与所属单据行为一致。页面别名和授权码不是契约身份。

| 层次 | 权威数据 | 责任 |
| --- | --- | --- |
| 单据目录 | Descriptor | 平台决定可用类型及租户配置资格 |
| 行为交互 | Action.interaction | 定义触发来源、专业服务协议及输入结果 |
| 平台页面关联 | PageRelationship | 真实页面操作与行为关系 |
| 租户绑定 | Binding.service | 选择已声明服务、条件及具体发布目标 |
| 执行解析 | Resolution | 固定依据、配置版本及服务目标，供幂等重放和复核 |

触发来源、目标服务和完成方式是不同维度。当前页面驱动支持 USER_ACTION。BUSINESS/SYNCHRONOUS 由业务同步执行，WORKFLOW/CALLBACK 由审批结果回调业务，PRINT/CONFIRMATION 由打印输出端口提供任务及结果确认。MESSAGE、BUSINESS_EVENT、SERVICE_RESULT、SCHEDULE 是协议类型，目前没有相应通用驱动器，不开放虚假的执行绑定。

工作流的 WorkflowBusinessProfile 是只读设计投影，由相同交互能力生成；不再提供 WorkflowBusiness.configuration 独立声明。按业务入口精确匹配，不取同单据第一个审批动作。打印目录由统一能力的 reference/fields 生成，业务不再独立维护打印字段 Bean。

## 运行链路

页面提交 operationKey → 业务验证权限和平台页面关系 → 重读业务依据 → resolveAction 指定行为 → 唯一租户发布绑定 → BUSINESS 执行业务状态变化，或 WORKFLOW 用解析引用精确启动，或 PRINT 授权取数后创建输出请求。业务拥有原单据状态，通用中心只保存关系和非敏感执行依据。

共享的是交互身份和驱动协议；工作流节点、打印模板及未来消息模板仍由专业服务管理。工作台不能将任意服务配置成动作未声明的能力，也不承担任意服务编排引擎职责。

## 开发期协议收敛

删除 Descriptor 的 entry/purpose/outcomes、Action 的独立 supportedModes/approval/printing 存储、默认 submit 的 resolve/options 重载、缺字段的 Binding 构造器、请假提交的空绑定旧启动路径及打印 Input 旧构造器。approval/printing 方法仅从 interaction 生成内部读取投影，没有第二份可写数据。

V67 将草稿、当前发布及配置历史 JSON 的 mode 转为 service，删除 mode，统一 DIRECT→BUSINESS、APPROVAL→WORKFLOW；执行快照列同步重命名。历史配置版本和流程实例身份保持可追溯。迁移是一次性数据转换，运行时不接受旧协议；已执行的 Flyway 历史脚本保持校验和。

## 管理交互

复用平台单据管理及租户工作台，不新增平行管理入口。单据详情集中显示契约编码、版本、触发来源，展开显示目标服务、完成方式、引用、用途、输入及结果。契约来自业务代码，只读；平台维护页面关系和授权，租户维护目标绑定；无关系记录时不从代码候选自动授权。使用已有 BusinessWorkspace、ManagementTable、ManagedDialog 和 Element Plus，无新增视觉组件。

## 边界

专业服务可以有自身平台通用能力目录，例如打印内置设计样例及租户排版契约；已登记业务单据的服务投影只能来自统一交互契约。远程 SDK 提供解析及打印输出，跨服务审批回调驱动尚未实现。新业务仍须实现业务命令和结果处理，本方案不生成业务功能。

## 本批验证

后端真实 MySQL/Flowable 回归覆盖提交、主管/HR 审批、驳回、撤回、直接受理、任意单据行为、打印和 OAuth SDK；V67 隔离数据库夹具验证旧 JSON 转换及旧键删除。前端页面绑定 6 项测试、admin 类型检查和生产构建通过。

本地数据库已由 Flyway 从 V66 升到 V67。浏览器使用 POC 管理账号读取现有配置，显示提交和打印的统一契约、原审批 v2 与打印场景；就绪检查中类型启用、页面关系、发布策略、流程版本、打印场景、在线客户端均通过。该轮没有新发出实体打印。

消息执行、事件订阅、调度执行以及跨服务审批回调适配器不属于已完成范围。
