# 业务字典功能授权

日期：2026-11-09。

业务字典不再要求租户 GRANT 管理能力，改用 configuration.dictionary 的 read、create、update、delete、item_create、item_update、item_delete 七项稳定权限。read 同时允许查询字典和字典项；update 与 item_update 分别包括相应对象的启停；删除继续执行非空、引用和版本约束。业务下拉 lookup 保持原租户公共读取契约，不提供维护能力。

追加 V28 登记权限并关联现有业务字典菜单；页面准入绑定 read，授权组合视图在「系统配置—业务字典」展示七项操作。已有系统租户管理员补齐权限及授权快照，推进成员授权版本；普通角色不自动扩权，角色新增权限也不绕过已有快照。新租户初始化沿用当前系统角色目录初始化逻辑。

管理用例逐操作执行 AccessAuthorization，写操作锁定有效成员后再鉴权，租户仓储仍复核服务端可信租户，保留版本与审计事务。不接受客户端租户或权限声明。新增 GET /api/configuration/dictionaries/capabilities 返回本人操作列表，前端读取失败时清空能力；按钮按能力显示，后端接口仍独立检查。查看者不能因页面可见取得创建、修改或删除权。

前端复用原 TreeListTemplate、ManagementTable、ManagedDialog 与 Element Plus，不新增布局体系。异常页面静态导航隐藏，403/404/500 路由保留。
