# 业务人员审批配置

本次在现有流程设计器内增加默认“业务配置”视图，复用同一草稿、版本、撤销重做、校验、预演和发布入口。后台应用壳、BusinessWorkspace、ManagedDialog 和 Element Plus 不变，不增加 UI 库。

## 组件选型

已检查 WorkflowDesigner、WorkflowCanvas、BusinessWorkspace、ManagementTable 和模板表单。原设计器适合技术人员编辑受控图，未提供业务单据目录、按姓名选人及结果动作说明。新增 BusinessWorkflowConfiguration 仅组合 Element Plus 表单和已有画布，负责单据绑定、审批规则和结果动作；businessConfiguration.ts 负责最小图变换，不重写引擎或建立平行数据模型。

## 业务操作

1. 在“流程中心 → 流程设计器”新建流程，默认进入业务配置。
2. 选择后端已接入的业务单据（当前请假单）。类型、用途和业务适配器自动绑定，选定后不可通过表单跨业务切换，以免原条件与结果动作失配。
3. 设置步骤名称及审批人：单据所属组织负责人、指定成员、单据所属组织岗位。成员和岗位按真实名称选择；多人规则、自审约束明确展示。可以追加顺序审批或按条件追加审批，也能移除可安全识别的步骤，至少保留一个审批步骤。
4. 从单据目录选择条件字段、比较符和常量。数值条件使用十进制比较，不使用浮点或用户脚本；业务规则如“请假天数 > 3”直接配置，不再强制业务代码预计算阈值。
5. 选择通过、驳回的业务结果动作，可启用业务已声明支持的撤回。页面说明节点校验和完成顺序、结果可靠交付及版本生效范围。
6. 样本预演查看路径，校验后保存/发布。发布权独立，正在运行的实例保留原版本。

复杂图中尚未提供表单重排、任意删除、并行或自动动作编辑；使用保留的高级编排。切换视图共享同一模型，不丢失数据，不对不识别的图做静默转换。

## 服务契约与安全

- `GET /api/workflow/configuration`：workflow:read，能力目录仍按各能力功能权限过滤。返回业务单据、条件字段类型、结果动作及当前租户有效成员/组织/岗位名称；不含凭据、联系方式或任意接口地址。
- `WorkflowBusiness.configuration()`：后端代码注册元数据；历史适配器默认 null，仍可使用高级编排。
- `WorkflowBusinessProfile`：定义 objectType/purpose、双语名称和说明、NUMBER/BOOLEAN/TEXT 字段、结果到能力的白名单映射、可选撤回能力。字段必须对应业务公开输出；目录不是可由浏览器编辑的业务对象定义。
- `WorkflowPlatform.configurationOptions()`：当前租户且有流程查看权时才能读取配置选项，指定成员存储账号标识，岗位存储岗位标识，负责人按单据组织运行时解析。
- 请假单新增组织选项接口，仅展示当前成员有效任职组织；创建时后端再次校验组织归属，不能靠请求参数选择任意组织。
- 通过、驳回动作必须匹配当前业务声明，启用撤回时必须同时绑定业务校验和 WITHDRAWN 结果动作。校验及发布均复核，不以页面隐藏代替授权。
- 当前成员名称目录作为流程配置的非敏感最小目录，仅 workflow:read 可访问；不授予账号管理或完整原文读取权限。

## 条件参数

| 参数 | 用途、缺省与约束 |
| --- | --- |
| edge.operator | 缺省 EQ 保持旧版本文本等值；EQ/NE 为文本比较，NUM_EQ/NUM_NE/GT/GE/LT/LE 为数值比较；未知操作符拒绝发布 |
| edge.field | 当前单据注册的非敏感输出字段；数值操作符必须声明为 NUMBER，禁止任意属性路径 |
| edge.value | 常量，最长 100 字符；数值为带可选负号的普通十进制，不接受指数、NaN、Infinity 或表达式 |
| edge.defaultEdge | 每个条件节点恰好一个默认分支；无匹配条件走默认分支 |

运行时和预演共用 WorkflowCondition。缺失字段或非法数值不匹配，包括 NE；多条成立按配置顺序取第一条。函数名、脚本、SQL、URL 和 Java 类名都不能由业务人员注入。新增业务运算需开发人员注册受控字段或扩展固定比较器并补验证。

请假撤回只校验本人、原实例和审批中状态；校验阶段不更新业务终态，Worker 随后按稳定 invocationId 幂等交付 WITHDRAWN。已批准单据撤销不在此入口实现。
