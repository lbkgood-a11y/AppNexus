# 出仓单验证与跨平台交付

日期：2026-11-11。按用户要求，首个验证场景为出仓单，打印机由客户端指定，目标系统覆盖 Windows、Linux、macOS。

## 数据契约与当前边界

仓库尚无出仓业务模块，当前 `printing/agent/src/outbound.fixture.ts` 仅是测试样本，不注册生产模板、不保存测试业务数据。正式接入时出仓业务服务必须按当前租户、对象和 PRINT 用途校验字段权限，并提供固定快照；浏览器填写的 JSON 不应冒充已授权业务快照。现有通用提交接口的业务数据授权适配仍需完成。

建议生产契约 `warehouse.outbound.v1` 包括：单号、业务日期、仓库、收货方、明细数组（物料编码、名称、规格、数量、单位）、按单位分组的数量合计、制单与复核人员及签收栏。数量和金额由业务层以精确值/格式化字符串提供，打印层不重算，不合并不同单位。测试样本当前为固定两行文本，仅证明中文与坐标渲染；动态明细、跨页表头、长品名和合计不属于本轮已验收能力。

## 本轮实现

- 代理配置从启动入口读取；HTTPS、绝对程序路径、正整数上下文版本、有限整数轮询间隔均启动前校验；Token 与任务请求禁止重定向，并设 30 秒网络超时。
- 独立 Chromium 上下文拦截网络、禁用 Service Worker/下载，60 秒渲染期限；本地打印 CSS、字体就绪、任务结束清理。上游仍需要脚本求值，网络隔离不等于完整恶意模板隔离。
- Windows / Linux / macOS 队列发现及显式队列命令；系统打印调用 30 秒超时。启动后异常为 UNKNOWN，不自动重打。
- 服务端模板发布加租户模板行锁；回执校验领取代理和租约，限制状态流转，同状态同结果允许重放，终态不得覆盖。
- 服务端模板拦截 styler、HTML、合并回调等执行扩展，允许空的上游回调默认值；JSON 最多 40 层，阻止原型污染键；普通数据字段不会因名称以 on 开头被误拒。

## 尚未完成的交付项

客户端目前可命令行发现队列，平台已有登记设备；网页内直接自动发现/选择本机打印机仍需经过受认证的客户端桥接，浏览器自身不能读取系统队列。本轮不开放无认证 localhost 打印接口。

正式 PDF 下载存储与租户授权、DOCX/XLSX 保样式转换、出仓业务授权快照及动态明细、真实设备与三系统实机验证、签名安装包、依赖许可准入仍待完成。当前 PDF 类型任务尚无下载产物闭环，不能把内部 PDF 渲染等同于用户可下载的正式输出。
