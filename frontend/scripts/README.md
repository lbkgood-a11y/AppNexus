# 操作绑定门禁

从仓库根目录运行 `node frontend/scripts/check-operation-bindings.mjs`。脚本通过 Vue 模板 AST 读取操作引用，检查后端显式接口登记；新增未绑定的点击、确认及提交必须明确登记为界面交互例外，否则失败。

operation-ui-exclusions.json 是代码审查清单，不是运行时或系统配置，无默认放行作用。每项 key 为文件、控件、点击、提交、确认及文案的精确组合，reason 为必须审查的中文排除原因。只允许纯界面编辑、导航、取消、复制、读取刷新、公共组件事件委托，以及认证系统自身的登录/恢复流程；涉及业务写入必须引用真实操作，不可用例外逃避绑定。行号变化不会使例外失效，事件或控件文案变化会要求重新核对。

例外清单必须逐项人工审查，不提供批量自动放行；`--write-exclusions` 已禁止。动态表达式及其每个可能操作在 operation-dynamic-bindings.json 显式列出，字段 file/expression 定位表达式，operations 列出所有分支，sources 定位实现，reason 说明中文审查结论。新分支不允许通过权限码或旧控制器身份兜底；组织动态保存有逐类型正反向测试。

静态检查不执行真实请求；处理函数副作用仍需审查和接口回归。登录/恢复、登出和租户切换属于认证上下文操作，由既有安全链处理；刷新和纯草稿编辑不创造独立权限，写入保存仍必须绑定操作。
