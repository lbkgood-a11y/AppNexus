# 打印服务

当前包含独立核心模块、公开平台契约以及 JDBC/HTTP 适配器，并由平台应用组合装配。V51 迁移提供租户模板、不可变发布版本、设备、打印任务、角色权限和动态导航；API 提供模板设计/发布、设备登记、任务提交、代理领取、回执和人工补打。代理使用固定租户的 Client Credentials 与专用 `print-agent:operate` scope，不能进入人员业务 API。

租户和实际账号只来自宿主认证链，写请求要求 CSRF/受信 Bearer 与幂等 UUID；模板禁止脚本和外部资源，发布版本及数据快照固定，结果未知不自动重打。详细结论见 [打印服务设计与选型记录](../../../docs/design/打印服务设计与选型记录.md)。
