# 审批公共契约

本模块只依赖 JDK，禁止引用平台或审批服务实现、Spring、Flowable、数据库实体。
当前仅提供 ApprovalContext，表达调用声明，不构成认证凭证。

| 参数 | 中文说明 |
| --- | --- |
| tenantId | 租户唯一标识，必填、无默认值；接收入口必须检查操作者的租户成员资格 |
| actorId | 实际操作者账号标识，必填、无默认值；由可信认证入口提供 |
| requestId | 请求幂等标识，必填、无默认值；后续写入口须按租户和操作类型持久化去重 |

发起、处理、撤回和事件契约在业务状态、授权范围、幂等及失败语义确定后补充。
目前未实现身份验证、幂等存储、事件投递或可远程调用的审批接口。
