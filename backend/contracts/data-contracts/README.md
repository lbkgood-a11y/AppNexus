# 公共数据契约

DataContract 是无框架依赖的结构与校验协议，不读数据库，不定义执行结果。code/version/purpose 与字段结构共同确定语义；TEXT 最大 2000 字符，NUMBER 必须为有限数值，BOOLEAN 仅接受布尔值。字段路径使用点分对象路径，不执行表达式。required=true 缺失拒绝；false 缺失保留缺失，没有隐式默认值或类型转换。未知字段拒绝，错误只携带字段路径及稳定码。

业务模块在授权取数后负责映射，打印和工作流入口再次校验。`project` 从已授权对象数据选取契约字段并返回深度不可变投影；`encode/decode` 统一处理工作流的路径键字符串传输，严格按契约转换数值与布尔，不增加第二份字段定义。未知传输字段拒绝，投影源中的非契约字段不输出；字段不能同时声明为标量及嵌套对象。投影不能代替功能、记录及字段授权。

具体接入见 docs/design/数据契约与单据接入收敛.md。该包不包含运行时系统配置。
