# 公共数据契约

DataContract 是无框架依赖的结构与校验协议，不读数据库，不定义执行结果。code/version/purpose 与字段结构共同确定语义；TEXT 最大 2000 字符，NUMBER 必须为有限数值，BOOLEAN 仅接受布尔值。字段路径使用点分对象路径，不执行表达式。required=true 缺失拒绝；false 缺失保留缺失，没有隐式默认值或类型转换。未知字段拒绝，错误只携带字段路径及稳定码。

业务模块在授权取数后负责映射，打印和工作流入口再次校验。具体接入及历史兼容规则见 docs/design/数据契约与单据接入收敛.md。该包不包含运行时系统配置。
