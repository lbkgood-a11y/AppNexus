# 工作流公共契约

只依赖JDK，不暴露Spring、Flowable、数据库实体、业务单据或服务实现。

| 契约 | 职责 |
| --- | --- |
| WorkflowContext | 显式租户、实际账号、幂等请求标识，声明本身不构成认证凭证 |
| WorkflowPlatform | 复核有效成员与功能权限，按单据归属组织及有效任职选人 |
| WorkflowBusiness | 代码注册业务能力；读取可信审批依据、保存办理内容、执行自动业务动作及撤回校验 |
| WorkflowStarter | 由可信业务入口发起并自动匹配流程，返回实例ID |
| WorkflowResults | 经业务适配器认证的异步结果入口，不直接暴露浏览器成功回调 |
| WorkflowTaskAccess | 业务端校验当前任务的受限字段读写，任务结束后拒绝；不绕过强制限制 |

| 参数 | 中文说明 |
| --- | --- |
| tenantId | 租户标识，必填无默认值；必须来自认证和有效成员校验 |
| actorId | 实际操作者账号，必填无默认值；不接受浏览器身份声明 |
| requestId | 写请求UUID，必填无默认值；同租户同账号持久化去重，相同键不同操作拒绝 |
| invocationId | 稳定业务执行ID，必填；重试不改变，由业务端持久化幂等，不能仅在内存去重 |
| objectVersion | 非负审批依据版本；普通节点填写可维护独立版本，不能通过增补静默修改已审核依据 |
| organizationId | 单据组织，必填无默认值；业务端必须从自身存储复核，防止伪造组织改变选人 |
| operation | SNAPSHOT/SAVE/SUBMIT/APPROVE/REJECT/WITHDRAW/EXECUTE，业务端须区分暂存与正式提交 |
| workflow | 实例ID、定义ID、发布版本、当前节点、流程模式及终态结果的公共关联；首次发起前为空，不含引擎内部ID，也不是认证凭证 |
| workItemKey | 人工分别填写按任务隔离，共享填写按实例+节点关联；业务端用此键维护内容及并发版本，不能仅以操作者推断配置 |
| values | 仅已声明输入，最多100项，键最长64字符、值最长2000字符；禁止凭据和敏感原文落入流程变量 |
| inputs/outputs | 字段标识1—64位，以字母开头；输出只允许非敏感流转标量。业务原文保持在业务服务 |

snapshot默认拒绝，接入方必须实现。发起及每次人工处理重读审批依据并校验版本；snapshot仅返回固定审批依据，正常评分/评价填写不混入此快照。
任务人员无整模块权限时，业务端可通过WorkflowTaskAccess校验特定对象和字段，再应用强制访问/脱敏规则。读取原文和修改仍须业务端自身校验。
实现真实业务接入前不得注册生产模拟能力。异步结果必须由服务端可信适配器认证并绑定能力，不能把tenantId或jobId当作回调凭证。
